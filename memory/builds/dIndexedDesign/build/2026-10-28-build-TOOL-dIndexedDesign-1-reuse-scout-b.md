## Where a spec or record disagrees with the source, or with another spec

1. **Two scout-return grammars are specced, and neither parent wins by default.** TOOL-aScoutedSeam-1 (SPECCED; aScoutedSeam is not a parent of this build) specs `## reuse` with MUST/SHOULD lines and caps the section at 10 seams. TOOL-dLinkedLibrary-2 S5 (a parent) specs `## Matches` with no binding field. The clause asks for twelve seams, which is M1c's return cap. Unit 13 should widen dLinkedLibrary-2's `## Matches` using aScoutedSeam-1's line spelling, and file an ask so aScoutedSeam-1 does not land a third grammar. TOOL-aScoutedSeam-1 S1 also extends `reuse-lookup.agent.md`, which TOOL-dLinkedLibrary-3 S1 deletes.
2. **The body-size figure in TOOL-dLinkedLibrary-2 §4 is wrong.** It says the scout's body is "1057 bytes against a 1536-byte ceiling". 1057 bytes is the whole file. `check_roles.py:221-222` measures only the body, which is about 647 bytes, so there are about 889 bytes of room, not 479.
3. **The INDEX.md table has more than one line per class.** It carries Kind, Anchors, Universal and Description columns, and it also lists notes, invariants and superseded records. The scout must keep only `kind: class` rows, and leave out gated classes once TOOL-dLinkedLibrary-24 S5 lands.
4. **TOOL-dFurnishedOrders-4 is not an ancestor of dIndexedDesign.** It is dScopedBuild's parent, and it owns the `### Bug classes` field and `--for-names`. Unit 14 depends on both and cannot assume they have landed. This needs a parent edge or a moved clause.
5. **The ownership record and the spec that lands the research-return kind disagree.** The record (:515) says dTotalRecall owns it; TOOL-dLinkedLibrary-13 S2 lands it.
6. **The night pass's experiment shape includes a blind judge.** dBoundRoles-16's table takes exactly one of `scorer` or `judge`. Unit 14's replay needs only a scorer, which is consistent with that.
