The carriers probe, written to the run's scratchpad as `carriers5.py`, reads each file at two
revisions. Per file it prints four things: whether the whitespace-squeezed text is the same, the
squeezed count of the full phrase, the count of lines holding it whole, and the longest line of the
second revision that is not a line of the first. Its squeeze is unit 4's, which folds a `#` comment
continuation:

```python
import re, subprocess, sys
P = "a `workflow`-driver harness of the workflow table"
def squeeze(t):
    return re.sub(r"\s+", " ", re.sub(r"[ \t]*\n[ \t]*(?:#[ \t]?)?", " ", t))
def show(rev, f):
    out = subprocess.run(["git", "show", f"{rev}:{f}"], capture_output=True, check=True).stdout
    return out.decode("utf-8")
base, head, files = sys.argv[1], sys.argv[2], sys.argv[3:]
for f in files:
    a, b = show(base, f), show(head, f)
    whole = len(re.findall(r"(?<![A-Za-z])" + re.escape(P), squeeze(b)))
    lines = sum(P in l for l in b.splitlines())
    longest = max(len(l) for l in b.splitlines() if l not in a.splitlines()) if b != a else 0
    print(f, "same" if squeeze(a) == squeeze(b) else "moved", whole, lines, longest)
```

Run as `2ac25483 2ac25483` over the five carriers on 2026-10-19, it printed `same 1 0 0` for
`help/roles.md` and `tools/roles/adopt-roles.sh`, `same 0 0 0` for `tools/roles/adopt-roles.test.sh`,
and `same 1 1 0` for the README and the library. Its liveness was checked over `340be90b 2ac25483`,
unit 4's range. Every file printed `moved`, with longest lines from 99 to 112.
