# aUnmannedHelm — the unattended-run kit: a mandate on disk, not a block of chat

Node `a` · opened 2026-08-10 · streams tooling+kickoff+playbook+deployer.

The owner's unattended sessions are launched today by retyping a protocol block into chat. It has
already drifted between runs, and nothing in the product records it. This build turns it into a kit:
a run-state file that survives compaction and process death, a protocol document, a driver script,
and a merge-bar leg — plus the kickoff hand-back, the agent-cap matcher and an adopter path.

The master scope lives in `spec/2026-08-10-spec-aUnmannedHelm-1.md`, at rev-2. All five forks were
ratified on 2026-08-10. The charter's explicit-ask rule is amended narrowly to accept a committed
mandate. The agent-cap half of S7 folds into `TOOL-aNumeralWarden-1`. The protocol travels with
project-owned phase and DoD declarations. `--close` blocks with a named, recorded override. The
seven units stay one build with a sub-spec each.

This build DEPENDS on `TOOL-aNumeralWarden-1` reaching rev-3 and landing, because the fold moved the
agent-cap edits there.
