### H2. 81: a capability probe that fails reads as "feature absent" and takes the parent exemption (id 24)

- **Where:** 2026-10-24-spec-TOOL-dDeclaredLoop-81.md, §2 S1 and S2; §4 "The grade, restated".
- **What is wrong:** S1 answers "supported" only when the `git merge-tree -h` text names `--write-tree`, and has no arm for a probe that fails. The stream S1 reads is not named: git 2.54 prints the usage on stdout with exit 129 and nothing on stderr. The spec rejects branch_reconcile's self-merge probe for exactly this fail-open (81.md:122-123) but leaves its own probe open. - **Consequence:** With git broken in the environment, every two-parent merge in the range is graded `uncomputable`, and a merge whose policy blob equals one parent's is skipped untrailered: the AC1 orphan scenario, reached by another failure. Add plant `push-merge-probe-failed`, where the probe twin raises OSError and the run exits 1 with `the clean re-merge failed`. Add a plant for the old-git case: usage on stderr only, exit 129, must read `unsupported`.
