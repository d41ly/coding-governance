## HIGH

### H1. `read_tree_conf` is outside the `no-own-conf-read` plant's reader set (ids 1, 11, 19)

- **Where:** 95 §2 S2/S3 and §4 Write set; the rule text it leaves untouched is 76 S2 (and 76's sketch) and 82 S10 (and 82's conf-read sketch).
- **What is wrong:** 95 S2 mints `read_tree_conf(tree)` as "the loop kit's one reader of `.memory-tree.conf`", the same kind of function as `read_driver_conf`. The `no-own-conf-read` rule (`derive_conf_reads`, 76 S2, alias resolution from 82 S10) counts a call only when its callee resolves to `parse_conf` or `read_driver_conf`, or when a conf-name string or 82's module-level conf constant is present. `loop_lib.read_tree_conf(tree)` has none of these. 95's write set amends only 41, 90, 92 and 94. No sibling adds the name to the callee set; it appears in 41, 76 and 79 only as hands-off edge bullets. 87 and 89 defer function readers to 82's `reader call` kind, which does not cover it.
- **Consequence:** after 95, budget.py or breakpoints.py can read `ll.read_tree_conf(tree)["MEMORY_ROOT"]`, bypass `resolve_memory_root` and its `confs-disagree` refusal (72 AC3), and the plant (76 S3) stays green. It would certify "no own conf read" (72 S3) over a file that reads one. The path needs someone to write that call, hence high, not blocker.
- **Fix (judged sound by the skeptic):** add an S6 to 95 that puts `read_tree_conf` into `derive_conf_reads`' `reader call` callee set beside `read_driver_conf`, alias resolution included. Make it rev bumps of 76 (S2 and sketch) and 82 (S10 and sketch), and add 76 and 82 to 95's write set and edges. Better, state the set as a class: every loop_lib conf-reading function, listed in one tuple that the rule and the readers share. Add a criterion with a staged break: in a scratch copy, budget.py gains `loop_lib.read_tree_conf(tree)`, and `python budget.py --fixture --plant no-own-conf-read` must exit non-zero naming `<file>:<line> reader call`.
- **Left-shift gate:** derive the plant's reader-call set from a declared tuple in loop_lib (every public function that opens a conf), and have the definition fixtures fail when loop_lib defines a function that reads a `*.conf` path and is not in that tuple.
