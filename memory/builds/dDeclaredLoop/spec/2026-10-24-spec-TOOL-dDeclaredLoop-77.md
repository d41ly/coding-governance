## 1. Goal

The round-4 spec audit (`memory/builds/dDeclaredLoop/reviews/2026-10-24-review-TOOL-dDeclaredLoop-68-spec-audit.md`)
confirmed finding **id 8 at HIGH**, its item **H2**. Its https half is item M16 at medium (id 36),
batched into `TOOL-dDeclaredLoop-79`. `TOOL-dDeclaredLoop-74` S1 keeps a `FETCH_HEAD` line only when its
URL, spelled by `derive_fetch_url`, equals the spelling of `git remote get-url <remote>`, and that
function strips one trailing `/` and one trailing `.git`. git writes that URL without the user part, so
over an scp-form or `ssh://user@` remote the two never match. Every successful fetch of an SSH adopter
is skipped; with the default branch unmoved no tracking-ref reflog entry is written either, and the
engine reads `stale-remote` above `act` indefinitely. 74's AC2 fetches from a local path, which has no
user part, so it cannot see this.

This unit makes `derive_fetch_url` spell a URL as git writes it into `FETCH_HEAD`. It repairs
`TOOL-dDeclaredLoop-74`.

## 2. Scope (IN)

- **S1** — `derive_fetch_url(url)` in `tools/loop/position.py`, which `TOOL-dDeclaredLoop-74` S1 mints,
  spells a URL as git writes it into `FETCH_HEAD`: first the user part is cut, then every trailing `/`,
  then one trailing `.git`. The user part follows git's own rule. Where the URL holds `://` and every
  byte before it is a letter, a digit, `+`, `.` or `-`, it is the bytes from just after `://` through
  the first `@`, when no `/` after `://` comes before that `@`. Where the URL holds no `://`, it is the
  bytes through the first `@`, when a `:` follows that `@` and no `/` comes before the URL's first `:`.
  Any other URL, a local path among them, keeps every byte up to its trailing `/` and `.git`. Both sides
  of 74's line match already pass through this one function, so its body is the whole change.

### The normaliser

```
derive_fetch_url(url):                                    # 74's, its body extended
    if "://" in url:
        scheme, rest = url.split("://", 1)
        at, slash = rest.find("@"), rest.find("/")
        if re.fullmatch(r"[A-Za-z0-9+.-]+", scheme) and at >= 0 and (slash < 0 or at < slash):
            url = scheme + "://" + rest[at + 1:]
    elif "@" in url:
        after = url[url.index("@") + 1:]
        colon, slash = url.find(":"), url.find("/")
        if ":" in after and not (0 <= slash < colon):
            url = after
    url = url.rstrip("/")
    if url.endswith(".git"): url = url[:-4]
    return url
```

A Windows path, `C:/...` or `C:\...`, holds no `:` after its first `@`, so the scp test leaves it whole;
a path with a `/` before its first `:` is git's other local form.
