## 4. Design

### Evidence

- `grep -c breakpoints tools/gate-legs.json` prints 0 at base `ed497191`, and `tools/loop/` does not
  exist there.
- A leg row carries `name`, `argv`, `guard`, `chunk`, `subject` and `ceiling` (`tools/gate-legs.json`, the
  `measure-legs selftest` row); `ceiling-evidence.txt` is generated by `derive-ceilings.py --write`, whose
  `--observed '<leg>=<seconds>' --how '<how>'` form admits a reading taken outside the runner (its header).
- `TOOL-dDeclaredLoop-13` §4 lists, for its one new leg, `subject-pins.tsv`, `ceiling-evidence.txt` and
  `memory/map/features/loop.md`, the set `memory/gotchas/a-new-leg-trips-a-growing-set-of-meta-gates.md`
  records.

### Files touched (estimate)

- `tools/gate-legs.json`
- `tools/loop/kit.toml`
- `tools/loop/breakpoints.py`
- `tools/govkit/subject-pins.tsv`
- `tools/run-gates/ceiling-evidence.txt`

### Alternatives rejected

- **Moving 64's plants into `selftest.py`.** It covers 64 but not 67 AC31's plant, written after this
  pass, and leaves a fixture entry point that no leg runs.
- **Folding `breakpoints.py --fixture` into the `loop selftest` leg.** That leg is minted by 67 at order
  38, after this pass, and would make one leg's verdict hide which module failed.

## 5. Production-readiness checklist

- security — none: a read-only fixture run as a leg.
- perf / scale — one fixture run of scratch repositories, a few seconds, measured into the ceiling.
- error / empty / loading states — S4: a failed plant is a named red, never a silent pass.
- observability — the leg prints the failing plant's name.
- risks — the guard's three paths miss a change elsewhere in the loop kit; `GATE_FULL=1` runs it
  unguarded, and the guard is stated so a builder can widen it.
- testing — AC1 to AC3 as probes; the arm under §7, observed at the close.
- migration — none.
- user docs — none: the leg is internal.
