`TOOL-dDeclaredLoop-86` rev-8 S13 defines `derive_conf_constants` by listing value shapes: an `Assign` or
`AnnAssign` whose value is a str `Constant`, a `JoinedStr`, a `BinOp` over such values, or a `Path(...)`
or `PurePath(...)` call over one. The repo binds a conf path mostly as `root / ".memory-tree.conf"` and

name. A `loop_lib.py` binding `CONF = HERE.parent / ".unattended.conf"` is then no `conf constant`, and a
loop module reading `ll.CONF` is certified as reading no conf of its own. 86 AC13 plants only the listed
shapes, so it stays green.

observes an aliased from-import of a class-only binding. It builds alone at order 43, over the
`derive_conf_constants` 86 lands at order 42. Re-grounded at rev-6, three items build: S1, S3 and S5.
