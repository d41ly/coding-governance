## 2. Scope (IN)

- **S1** — The build folder is resolved through `MEMORY_ROOT`, read from the tree root's
  `.memory-tree.conf` through the memory-tree kit's `parse_conf`, reached by `resolve_kit_dir("memory-tree",
  "tree_lib.py", here)`: a row's folder is `<MEMORY_ROOT>/builds/<build>/README.md`, never a literal
  `memory/`. Observed by AC1.
- **S2** — A row naming a build this tree does not hold is graded only by the tree that declares the
  chain: where `.memory-tree.conf` sets `DESIGN_RECORD`, an absent folder is refused as
  `TOOL-dDeclaredLoop-5` S3 says; anywhere else the row prints `actor-witness: <site> <witness> —
  foreign build <build>, not graded` and is not refused. With no memory-tree kit or no conf, every row
  prints that line. This supersedes `TOOL-dDeclaredLoop-5` S3's absent-folder refusal outside the
  declaring tree. Observed by AC1, AC2.
- **S3** — `DOD_EXTRA` is exempt from the shipped list: an adopter's entry whose class word maps to
  `actor` is admitted by the unattended leg's arm and printed `actor-witness: DOD_EXTRA <item> —
  adopter-declared, not on the shipped list`; an entry with no class word, or a word outside the alias
  words, is still refused, as `TOOL-dDeclaredLoop-5` S5 says. The shipped list grades `DOD_CORE` alone.
  This supersedes S5's refusal of an unlisted `DOD_EXTRA` `agent` item. Observed by AC3.
- **S4** — `TOOL-dDeclaredLoop-5` §4 Migration's sentence is rewritten in `tools/loop/README.md`: append
  `:machine` or `:agent` to an unclassed `DOD_EXTRA` entry; an `:agent` entry is admitted and printed,
  because the adopter owns its own items. Observed by AC4.

## 4. Design

### Evidence

- The two seeded builds exist in gov (`memory/builds/dWellOiledMachine`, `memory/builds/dShippedRelease`,
  listed 2026-10-24) and in no adopter.
- `DESIGN_RECORD` is set in gov's `.memory-tree.conf` (:1016) and is a gov-only key that design_lib
  reads (`tools/memory-tree/design_lib.py:126`, `DESIGN_KEYS`); an adopter's conf leaves it blank, so it
  is the derivable mark of the tree that owns the chain's build names.
- Gov's own `DOD_EXTRA` is empty (`.unattended.conf:290`), so S3 changes no gov verdict.

| `DESIGN_RECORD` set | absent | refused, naming the build |

- **Shipping an empty list to adopters.** The two `DOD_CORE` rows ship with the driver, so the list must
  ship with them or the driver's own declaration is refused.
