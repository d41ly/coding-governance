## 1. Goal

The round-2 spec audit (`memory/builds/dDeclaredLoop/reviews/2026-10-24-review-TOOL-dDeclaredLoop-36-spec-audit.md`)
confirmed finding **id 19 at HIGH**, its item **H3**, alone in that item: the budget reader drops draws
stored in rotated run records. `TOOL-dDeclaredLoop-48` built the reader's run-state population, and it
reads part of what the driver rotates. `tools/loop/budget.py#read_budget_rows` reads a build's own
`RUN.md` and the archives beside it that `ROTATED` names, `RUN.LANDED.*.md`, and it reads the
` · budget <slug>` rows from each build's live `RUN.md` alone. `--preflight` retires a finished record
to the name `tools/unattended/unattended.sh#archive_name_of` derives, `RUN.<phase>.<blob8>.md`, its
phase the record's recorded one: `ABORTED` as well as `LANDED`, and a non-terminal phase for a record
`--settle` ended as abandoned. So a build holding no transition log record loses an aborted run's draws
when its next run starts, its freeze row with them, and its next draw freezes again and counts from one.
A patch build's draws on its origin leave the origin's count once the patch build's own record rotates.
This unit reads the driver's whole archive population. It repairs `TOOL-dDeclaredLoop-48`.

  slug compared whole, as `read_budget_rows` compares it at the tip. Observed by AC3.
