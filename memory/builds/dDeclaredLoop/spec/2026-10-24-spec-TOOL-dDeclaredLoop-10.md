## 1. Goal

A move back, Test to Build, Build to Design, Design to Plan, is recorded through the same writer, in
the same channels, trailer grammar and log fields as a move forward, with no branch on direction and
no new mechanism. The walkthrough found the record written only forward (H10,
`memory/builds/dClosedLoop/build/2026-10-14-build-PLAY-dClosedLoop-1-session-model.md:260`), and today a
fix pass or a divergence leaves only an overwritten `phase:` fact in a run's RUN.md
(`tools/unattended/unattended.sh:6192`). Direction is derived from the step order, never typed, so a
reader can count routes back without a second record.

## 4. Design

### The direction

```python
def derive_direction(row, steps):
    """'forward', 'backward' or 'lateral' for one resolved move, from the [[step]] order alone."""
```

A state's step is the `[[step]]` row whose `state` it is; `paused`, `parked` and `none` have none, so
a move touching them is `lateral`. A terminal `to` has no step either, and a move into one is
`forward`, the build ending. The function reads `read_steps` from `TOOL-dDeclaredLoop-1`'s
`loop_lib.py`, so a reordered step changes every derived direction at once, and nothing is stored to
go stale.

### Recorded like forward

The writer's steps (`TOOL-dDeclaredLoop-3` §4, "The writer, in order") run unchanged for every row.
This unit adds no code to `write_transition` or `check_transition_channels`; it adds the derived
`direction` to `read_transitions`' output and to the printed lines, and plants that prove the absence
of a branch:

- `backward-rows`: one fixture build moved forward to Test, then through B13, B8 and B6 in turn, every
  channel selected; each backward commit carries a trailer with the same field set as the forward
  ones, a log record and a printed line.
- `skip-backward`: the same fixture with the log record of the B8 move deleted; `check` reds it.
- `direction-order`: a fixture definition with `step.test` ordered before `step.build`, which flips
  B7 to `backward`, proving the direction is read from the order and not from a table.
