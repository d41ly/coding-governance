## 1. Goal

A witness that decides a route is computed, never typed by the agent it judges (P2, v2:852-853;
`gap-flow-14`). Three witnesses the clause names become computed: a unit's acceptance, re-run at its
commit by a command that writes `record-kind.acceptance`; a probe's commands, re-run at the probe's
pinned SHA and compared by output hash; and a red's attribution, joined to the run's own claim that a
red is inherited. The attest door refuses every item whose witness is computed. The executor that
owns `build.acceptance` is outside this build (v2:2014), so this unit declares the record and the
witness kinds and arms the stand-ins the executor replaces (I22).

## 4. Design

### The acceptance record

```
**Serves:** journal TOOL-dExample-3

**Unit:** TOOL-dExample-3
**Sha:** 3f9c2a71
**Writer:** stand-in

run · 0 · 9b1f04c2e7aa · python loop_table.py check
run · 1 · 41d2c0b9f310 · python loop_table.py --fixture --plant missing-row
```

The factory's kind row declares `Unit`, `Sha` and `Writer` required, `Writer` closed over `executor`
and `stand-in`, and at least one `run` line. The record says what ran and what came back; whether
exit 1 was the expected answer is the criterion's, which the record keeps the command for.

### The re-run

```python
def run_witness_commands(repo, sha, commands, timeout=600):
    """[(command, exit, hash12)] for each command run in a detached worktree of `sha`."""
```

The worktree is added with `git worktree add --detach <tmp> <sha>` under `tempfile.mkdtemp()` and
removed with `git worktree remove --force` in a `finally`, so a crashed command leaves no worktree
registered. Each command runs through the platform shell with the worktree as its directory and no
inherited `GIT_DIR`. A timeout kills the command and records exit `timeout`. Output is hashed raw,
so a command whose output carries a timestamp is `refuted` on every re-run, which the stand-in
reports rather than normalises.

### The red-attribution join

In `run_hold`, after the vocabulary check (`tools/unattended/unattended.sh:6871-6874`):

```bash
if [ "$code" = inherited-red ]; then
  check_inherited_override "$rel" "--hold --code inherited-red" record-only || return 1
fi
```

`record-only` is the tie `--handoff` passes (:10429): the run commits the record `gates-green` staged
before it may hold, which moves `HEAD` off the bar's head by exactly that record
(`check_bar_tied`'s comment, :10327-10332). Without the join the code is a sentence the run types; with
it, the runner's attribution decides it.

### The attest door

`verb_attest` (`tools/unattended/unattended.sh:12573-12592`) today refuses an item whose `checker_of`
is not `agent`. After `TOOL-dDeclaredLoop-5`, `checker_of` maps a DoD class onto I5. This unit makes
the door read both facts the loop kit holds: the class must be `actor`, and the item must be listed in
`tools/loop/actor-witnesses.txt`. A `history`, `hook-record` or `remote-verdict` item is refused,
the message naming the class and, from `[[computed-witness]]` or the DoD set, what computes it. The two
listed items, `keepalive-reaped` and `parked-decisions-surfaced`, keep the verb until their builds
remove the rows.

## 5. Production-readiness checklist

- security — the re-run executes caller-named commands in a detached worktree of a committed SHA; it
  runs nothing the caller could not run, writes only its temporary worktree and the record, and passes
  no secret; the attest and hold changes only narrow what a run may assert.
- perf / scale — one worktree per call, each command bounded by `timeout`.
- error / empty / loading states — an unresolvable SHA is `inconclusive` for `rerun` and exit 2 for
  `acceptance`; no `--cmd` is exit 2; a missing attribution record refuses the hold with fail 83.
- observability — every run line names the command, its exit and its hash; every refusal names the
  item or the condition that failed.
- risks — the caller still chooses the commands, so an acceptance record proves what ran, not that it
  was the spec's; the stand-in writer is labelled until the executor replaces it.
- testing — the plants of §6 under the new leg; the hold and attest arms by a fixture run-state, the
  unattended suites being waived.
- migration — none.
- user docs — `memory/guides/UNATTENDED-VERBS.md`, through its template.
