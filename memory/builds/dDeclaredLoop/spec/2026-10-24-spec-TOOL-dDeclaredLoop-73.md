## 1. Goal

The round-3 spec audit (`memory/builds/dDeclaredLoop/reviews/2026-10-24-review-TOOL-dDeclaredLoop-57-spec-audit.md`)
confirmed finding **id 39 at HIGH**, its item **H6**, alone in that item. `TOOL-dDeclaredLoop-57`'s
`demand_claimed_requires` grades the `descs` that `tools/govkit/govkit.py#_cmd_update` builds with
`tools/govkit/govkit.py#read_descriptors`, which parses each descriptor from the working tree, while
`to_commit` is any commit `--to` names. When `--to` names a fetched tip whose `roles` kit requires
`loop` and the working tree's does not, the refusal does not fire and the roles-without-loop install
57 exists to stop goes through. The reverse refuses an update to a vintage that needs no loop. 57's
criteria run with `--to` at the checkout's own tree, so neither sees it.

This unit makes the refusal read each selected kit's `requires` at `to_commit`, through the registry
gov holds at that commit, as `tools/govkit/govkit.py#derive_default_gained` already reads the default
set there. It repairs `TOOL-dDeclaredLoop-57`.

## 4. Design

### Evidence

Read at HEAD `0d9bdeb4`, 2026-11-14.

- `tools/govkit/govkit.py#read_descriptors` builds `descs[eid]` from `root / dpath` in the working
  tree, `dpath` repo-relative after `resolve_prefix_token`.
- `tools/govkit/govkit.py#_cmd_update` resolves `to_commit` with
  `git rev-parse --verify <to_rev>^{commit}`, any commit of the gov checkout, and passes `gained`
  alone to `derive_unsatisfied_requires` in its `while True` loop. `demand_claimed_requires` is not in
  the tree: 57 is unbuilt, and its spec places the call directly after that loop.
- `tools/govkit/govkit.py#derive_default_gained` builds the registry's repo-relative path from
  `derive_tool_root`, reads it at both vintages through `blob_at` and parses with `tomllib`, returning
  `([], why)` on a miss or a parse failure. No assertion in `tools/` spells either reason string.
- `tools/govkit/upgrade_steps.py#blob_at` reads `git show <commit>:<path>` and answers `None` on a
  miss; govkit binds it as the module name `blob_at`, which `check_roles_default` stands in for with
  a three-argument lambda.
- `tools/govkit/govkit.py#read_descriptor_at` reads a descriptor at a commit through `blob_at`,
  answers `None` where the blob is absent, and raises `Refusal` naming the path and commit where it
  does not parse. Its one caller is the `TOOL-dSafePassage-65` role re-resolution in `_cmd_update`.
- `tools/govkit/govkit.py#main` catches `Refusal`, writes `govkit: <text>` to stderr and returns 2.
- The registry at HEAD declares 30 entries, PINNED, measured 2026-11-14. At the release-0 pin
  `60d90cb7` the registry does not declare `loop`, and `tools/loop/kit.toml` does not resolve there.

### The read

```python
def read_registry_at(root, commit):
    tr = derive_tool_root(root)
    rel = "/".join(([tr] if tr else []) + [GOVKIT_DIR.name, REGISTRY_NAME])
    blob = blob_at(root, commit, rel)
    if blob is None:
        return None, f"{rel} does not resolve at {commit[:8]}"
    try:
        return tomllib.loads(blob.decode("utf-8")), ""
    except (tomllib.TOMLDecodeError, UnicodeDecodeError) as e:
        return None, f"{rel} at {commit[:8]} does not parse ({e})"


def read_requires_at(root, commit, ids):
    reg, why = read_registry_at(root, commit)
    if reg is None:
        return {}, {e: why for e in ids}
    tr = derive_tool_root(root)
    paths = {e.get("id"): e.get("descriptor") for e in reg.get("entry", [])}
    out, unknown = {}, {}
    for eid in ids:
        if eid not in paths:
            out[eid] = ({"requires": []}, "")
            continue
        dpath = resolve_prefix_token(paths[eid] or "", tr)
        try:
            desc = read_descriptor_at(root, commit, dpath)
        except Refusal as e:
            unknown[eid] = str(e)
            continue
        if desc is None:
            unknown[eid] = f"{dpath} does not resolve at {commit[:8]}"
            continue
        out[eid] = ({"requires": list(desc.get("requires") or [])}, dpath)
    return out, unknown
```

### Alternatives rejected

- **Re-reading every descriptor at `to_commit` for the whole update.** It moves paths and adopters'
  reads this finding does not name; the refusal's input is the only one it does.
- **Refusing a `--to` that differs from the working tree.** `update --to <fetched tip>` is the
  documented route; refusing it removes the feature to dodge the defect.
- **Passing `unknown` into `demand_claimed_requires`.** A new parameter changes the signature 57's
  own arm calls with five arguments; the refusal at the call site leaves 57's function and its arm
  as built.
- **A second registry read beside `derive_default_gained`'s.** It would copy the path rule and both
  reasons; S1 shares one.
