## 1. Goal

The round-1 spec audit (`memory/builds/dDeclaredLoop/reviews/2026-10-24-review-TOOL-dDeclaredLoop-1-spec-audit.md`)
confirmed finding **id 35 at HIGH**, its item **H12**, alone in that item: the roles kit `requires`
`loop`, and nothing puts `loop` in `[selection] default` of `tools/govkit/registry.toml`.
`TOOL-dDeclaredLoop-1` has landed since, so the defect is live at `804ef34a`. `tools/roles/kit.toml`
declares `requires = ["kickoff-manifest", "memory-tree", "loop"]`, the registry holds a `loop` entry, and
its default list holds `roles` and not `loop`. `apply` refuses a selection whose `requires` is unmet
and never widens it (`tools/govkit/govkit.py#_cmd_apply`, its ARM B), so every default `govkit apply`
refuses with `'roles' requires 'loop'`. This unit puts `loop` in the default list and states the
migration where an adopter reads it. It repairs `TOOL-dDeclaredLoop-1`.

## 4. Design

### Evidence

Each line below was read at `804ef34a`.

- `tools/govkit/govkit.py#derive_unsatisfied_requires` is the one predicate `apply` refuses by, `plan`
  prints by and selfcheck 7b fails by. Called over the default set with no receipt it returns
  `[('roles', 'loop')]` today, PINNED, measured 2026-11-13 by AC1's probe.
- `tools/govkit/govkit.py#derive_install_order` places a kit after everything it `requires` inside
  the selection, so `loop` installs before `roles` wherever the line sits in the list.
- `tools/loop/kit.toml` declares `requires = []` and one `[[files]]` rule, `include = "**"` at role
  `engine`. The kit adds no seed, rendered or project-owned row to a default plan.
- `tools/govkit/govkit.py#derive_default_gained` returns each id the default holds at the to-commit
  and did not hold at the receipt's `gov_commit`, less the ids the receipt claims.
  `tools/govkit/govkit.py#_cmd_update` calls it only when no `--kits` scope is given, leaves out a
  gained id whose `requires` the receipt and the gained set cannot satisfy, prints one
  `default-gained` line per id it keeps, and appends the kept ids to the receipt's `kits`.
- The default list at `ed497191` holds `roles` and not `loop`, and `tools/roles/kit.toml` there
  requires only `kickoff-manifest` and `memory-tree`. A receipt of that vintage is the migrating
  adopter.
- `tools/govkit/matrix.py#main` builds its default-install shape from the registry's own default
  list and its aged-update shape by a line-wise text replace of named ids, so neither types the
  default set and neither needs an edit.

### Migration

An adopter whose receipt predates S1 gains `loop` at its next unscoped `update`: the registry's
default holds it at the to-commit and did not at the receipt's vintage, and `loop` requires nothing,
so the gained-only filter keeps it. The same run moves `roles` to the version that reads the loop
definition. A `--kits`-scoped update gains nothing. The paths this leaves uncovered are
`TOOL-dDeclaredLoop-57`'s. Reversal is reverting S1's line: a target that already gained `loop` keeps
a kit nothing then requires it to have, which is harmless.

### Files touched (estimate)

- `tools/govkit/registry.toml`
- `help/loop.md`
- `help/upgrade-steps.md`
- `tools/playbook-kit-waivers.txt`

No kit ships any of the four, so no kit version moves. No registry entry, usage row, subject pin,
kickoff watch-list line or generated map file changes: the unit adds no file, no leg, no command and
no symbol.

### Alternatives rejected

- **Dropping `requires` `loop` from the roles kit.** `tools/roles/kit.toml` records that its
  catalogue checker and its adopter read each workflow's order from the loop definition, so the
  dependency is real and hiding it would install a roles kit whose adopter refuses.
- **Letting `apply` widen a selection by `requires`.** The owner ruled a selection is the operator's
  statement of intent, as ARM B's comment in `tools/govkit/govkit.py#_cmd_apply` records.
- **A second requires arm in selfcheck, rev-2's S3.** Check 7b already calls the predicate; a second
  call would be one answer asked twice.
- **Observing AC1 by a real `apply` into a hand-made target.** A default apply needs a deploy file
  carrying every answer the renderer asks, which `tools/govkit/matrix.py#main` already builds for its
  default-install shape. The probe reads the predicate `apply` refuses by, and the matrix runs the
  real install at the close.
