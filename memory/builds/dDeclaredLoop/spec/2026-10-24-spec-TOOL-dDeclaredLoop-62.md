```
# The loop kit's transition records (TOOL-dDeclaredLoop-49 S3): a record only gains rows, so two
# worktrees drawing on one build's budget each append a row at its end, where a text merge
# conflicts. `union` is git's built-in driver and needs no per-node config: it keeps both sides'

# `parallel-append-uneven` observes each draw keeping the record's bytes before it as a prefix,

memory/builds/*/build/*-transition-*.md merge=union
```

The widest line is 98 columns PINNED, inside the file's 100. The comment names no cause for the
