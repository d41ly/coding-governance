## 1. Goal

A new kit, `tools/loop/`, holds the loop's definition: the gov steps keyed by their stage tags, and
for each roles workflow its order, the step it serves and the reach word its work orders load
practices under. The roles kit's `stage` integers and its `step` words move into it in this same
unit, and every reader of either is re-pointed here, never waiting for a live build's close
(`gap-spine-01`: no kit declares the stage it serves, and the loop exists only implicitly). The loop
kit owns WHAT runs and in which step; the roles kit keeps WHO (walkthrough.md:119-125, S1b).

## 2. Scope (IN)

- **S1** — The kit `tools/loop/`: `kit.toml` (`id = "loop"`, `layer = "layer.flow"`, `requires = []`,
  its version from `loop_lib.py`'s `KIT_LOOP_VERSION`, in the shape of `tools/policy/kit.toml`),
  `README.md`, the adopter `adopt-loop.sh` with `--check`, and its `[[entry]]` row in
  `tools/govkit/registry.toml`. Observed by AC1 and AC8.
- **S2** — The definition `tools/loop/loop.toml`: one `[[step]]` row for each of `step.plan`,
  `step.design`, `step.build`, `step.test` and `step.deploy`, each with `order`, its build `state`

  with `name`, `order` (the moved `stage` integer, 0 for an any-time workflow), `step` (a step tag or
  `none`) and, only where its work orders load practices under a word that is not its step's, `reach`
  (`entry` or `review`). Observed by AC1 and AC6.
- **S3** — `tools/loop/loop_lib.py`, the definition's one reader: `load_loop(kit_dir)`,
  `read_steps(kit_dir)`, `read_workflow_order(kit_dir)` and `read_workflow_reach(kit_dir)`, refusing
  with `LoopError`, a `ValueError`, a definition whose gov steps are missing, repeated or out of order,
  a workflow row named twice, an order that is not an integer at or above 0, a `step` that is absent
  or is neither a declared step tag nor `none`, or a `reach` outside `REACH_WORDS`; and
  `loop_lib.py --check` and `--fixture --plant <case>`. Observed by AC1 and AC6.

  as they do today with no roles kit.

## 4. Design

### Data model

```toml
# tools/loop/loop.toml — the loop's definition, read only through loop_lib.py
[[step]]
tag = "step.plan"        # a `step` namespace member (TOOL-dDeclaredLoop-18's extract_step)
order = 1
state = "planning"       # shared interface I3
exit = "item.plan.exit"  # the step's exit item, a tag in the `item` namespace

[[workflow]]             # the roles kit's stage and step, moved
name = "spec-review"     # a roles workflow, the join key to tools/roles/workflows.toml
order = 4                # the moved `stage` integer, 0 for an any-time workflow
step = "step.design"     # the step the workflow serves, or "none"
reach = "review"         # optional: the reach word, where it is not the step's own
```

|---|---|---|---|
| `step.plan` | 1 | `planning` | `item.plan.exit` |
| `step.design` | 2 | `designing` | `item.design.exit` |
| `step.build` | 3 | `building` | `item.build.exit` |
| `step.test` | 4 | `testing` | `item.test.exit` |
| `step.deploy` | 5 | `deploying` | `item.deploy.close` |
