## 1. Goal

`.githooks/pre-commit` names five gates by hand, each behind a trigger typed beside it
(`.githooks/pre-commit:179-260`), so a leg that should run at commit time does so only if someone
edits the hook (gap-test-07; the class `memory/gotchas/hand-named-gate-list-green-while-the-bar-reds.md`
names). Cost evidence is one node's: every one of the 119 rows of `ceiling-evidence.txt` names node `a`,
23 of the 142 legs have none, and no whole-bar wall time is committed (gap-test-08; PINNED at
`cdfbd1cf`). This unit derives the commit-time list from each leg row's `precommit` argv and its
`guard`, keys ceiling evidence by leg and node, and commits each node's whole-bar wall time.

## 4. Design

### The five

| Leg | `precommit` argv | Trigger at commit | Today's trigger |
|---|---|---|---|
| `memory hygiene` | `bash {prefix}/memory-tree/check-memory-hygiene.sh --staged` | every commit (no guard) | `memory/**` staged |
| `kickoff-manifest ratchet` | `bash skills/session-kickoff/manifest-check.sh --staged` | every commit (no guard) | every commit |
| `unattended skill wiring` | `bash {prefix}/unattended/adopt-unattended.sh --check` | every commit (no guard) | `.unattended.conf`, a skill template or the render staged |
| `template size <=48KiB` | `bash {prefix}/check-template-size.sh` | every commit (no guard) | the charter template staged |
| `codebase-map coverage + freshness` | `python3 {prefix}/codebase-map/test_codebase_map.py --precommit` | every commit (no guard) | `.codebase-map.conf` present and a `.py` or `.js` staged |

The trigger is the row's `guard`, read with the guard semantics the runner and
`check-spec-tokens.py`'s `check_guard_trips` share: the staged path equals the guard or sits under it
as a directory. All five legs are unguarded at base, so each runs at every commit; the cost is §8 F1's.

### The derivation

`precommit.py` reads the manifest the runner reads (`{prefix}/gate-legs.json`, or `--legs <path>` as
`measure_legs.py` takes it), resolves `{prefix}` through the `resolve_prefix_token` block the runner
inlines, lists the staged set once (`git diff --cached --name-only --diff-filter=ACMR`), and for each
row carrying `precommit`, in manifest order, either prints `pre-commit: <name> not tripped` or runs the
argv and prints `pre-commit: <name> ok` or `pre-commit: <name> FAILED (rc <n>)`. A row whose argv names
a file absent from the tree prints the hook's announced-skip sentence and is not a failure, as
`print_kit_miss` is today. `--list` prints each row's name, argv and trigger and runs nothing. Held
legs are not special here: `precommit` is declared per leg, and a held leg declares none.

### Evidence keyed by node

The row keeps its six fields, `<leg>`, `<max seconds>`, `<readings>`, `<node>`, `<date>`, `<source>`;
the key moves from `<leg>` to `(<leg>, <node>)`. `read_evidence` returns `{(name, node): row}`;
`--write` raises or holds only rows whose node is `GOV_NODE`, carrying every other node's rows
byte-identical; `--check` takes each leg's maximum over its rows, so the headroom rule is unchanged,
and prints `ceiling-evidence: <k> of <n> legs evidenced on one node only`, a report, never a failure.
The runner's prior read already takes the maximum per leg over every row (`run-gates.sh:2766-2773`),
so it needs no change. A merge of two nodes' writes now touches different rows.

### The wall record

`bar-wall-evidence.txt`, generated, `#` header then one TAB-separated row per node: `<node>`, `<date>`,
`<sha8>`, `<wall seconds>`, `<legs run>`, `<width>`. `profile_bar.py --record` reads the last record of
the profile log, refuses one taken with `--scoped` (a guarded run is not the whole bar), and replaces
the node's row with it: the latest reading, not a maximum, because a wall time is a measurement of a
bar and not a bound.

### Inventory

Minted: the row key `precommit`; `tools/run-gates/precommit.py` with `--legs` and `--list`; the runner
flag `--precommit`; `test_codebase_map.py --precommit`; `profile_bar.py --record`;
`tools/run-gates/bar-wall-evidence.txt`. Naming cells: each function and flag is asked of
`python tools/lexicon/lexicon.py --suggest <name>` at the pass.

### Migration

Existing evidence rows are `(leg, a)` rows already, so the file needs no rewrite. An adopter's hook is
re-installed by its next update and reads the adopter's own manifest; a leg the adopter's manifest
does not carry is not run, which is today's skip.
