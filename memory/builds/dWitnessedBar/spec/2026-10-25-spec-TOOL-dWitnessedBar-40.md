## 4. Design

### Evidence

- The retired writer's declines, as unit 4's pass deleted them: the floor's advisory red, then
  `bar_record = stub`, then `GATE_DOCS_BASE` set, then `RUNLOG_DECISION = scoped` with `inh_sha` set
  (`.githooks/pre-push@176f5913:2615-2625`); its comment says a doc-only bar "ran fewer legs than a
  scoped bar from the same base, which the record cannot say".
- The runner unsets `GATE_DOCS_BASE` after resolving `DOCS_BASE`
  (`tools/run-gates/run-gates.sh@86758a96:592-600`), so the runner alone knows whether docs mode was on.
- The hook exports `GATE_BASE=$scoped_base` in both scoped branches
  (`.githooks/pre-push@100bfdc7:2314`, `.githooks/pre-push@100bfdc7:2331`), and
  `scoped_base=$inh_sha` when the base is inherited (`.githooks/pre-push@100bfdc7:2083`); the runner
  cannot tell the two apart from `GATE_BASE`.
- `.githooks/pre-push#check_green_reuse`, `<label> <reused> <reused_cache>`, forces on a non-zero
  `reused_cache`, and on a non-zero `reused` with no `reused_cache`; both empty force nothing.
- The per-tree writer's comment states what it does not check: "which legs a scoped run skipped, or
  whether a run reused a cached verdict" (`tools/run-gates/run-gates.sh@86758a96:5856`), and
  `tools/run-gates/README.md`'s section "The verdict per tree" says the same.

### The write rule

```
write the per-tree record when the tree started clean, did not move and its fingerprint was read
(unit 4 S2), unless
  DOCS_BASE is non-empty                       -> "run-gates: no gate-verdict written — docs mode"
  scoped and GATE_BASE_FROM = inherited        -> "run-gates: no gate-verdict written — scoped on an inherited green"
keys: unit 4's, plus  reused <n>  reused_cache <n>
```

The two lines keep their minted words, which `TOOL-dWitnessedBar-62` S15 greps from the kit page,
beside unit 4's `no per-tree verdict written` lines. A full run under docs mode cannot occur:
`DOCS_BASE` is set only when `GATE_FULL` is empty (`tools/run-gates/run-gates.sh@86758a96:593`).

### Inventory

Minted: the env knob `GATE_BASE_FROM` and its two values; the per-tree keys `reused` and
`reused_cache` (spelled as on the full-green stamp); the two decline lines. Naming cells: the knob is
asked of `python tools/lexicon/lexicon.py --suggest GATE_BASE_FROM` at the pass.

  doc-only GREEN as a verdict.
