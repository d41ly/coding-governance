## 1. Goal

Gate legs are declared twice (gap-tool-01): every leg has a row in `tools/gate-legs.json`, and the same
leg is declared again as a descriptor `[[gate_leg]]` row or a `tools/govkit/registry.toml`
`[[exempt_leg]]` row, joined both ways by govkit `selfcheck` 7h. This unit makes each leg's declaration
its one spelling: a factory generates the manifest from the declarations, a `new` verb writes a
conforming declaration, the leg kind's conformance gate grades the whole population both ways, and
every leg names in `enforces` the principles and practices it enforces, as P16 requires of every
extension kind (v2:967-971, NP-22 16/19 "Generated manifest").

## 2. Scope (IN)

## 4. Design

### The declaration

```toml
# tools/gate-lint/kit.toml
[[gate_leg]]
name = "shell hygiene (a fork spent on builtin work)"
subject = "repo"
argv = ["python3", "{kit}/sh_hygiene.py", "--spawn-idioms"]
guard = []
chunk = "product"
tag = "leg.gate-lint.spawn-idioms"
purpose = "catches a fork spent on builtin work in a shell file"
enforces = ["practice.portable"]

[gate_leg.gov]
argv = ["python3", "{kit}/sh_hygiene.py", "--spawn-idioms", "memory/project/spawn-idiom-sites.txt", ".", ":!*.test.sh", ":!memory/"]
ceiling = 120
```

The base row is what an adopter receives, through the emitter's existing keys and floors; the
`gov` sub-table is gov's own run and never travels. The values above are illustrative; the pass writes
the measured ones.

### What the factory renders

For each declaration, in order of its declaring file's path and then its row order, the registry's
`[[exempt_leg]]` rows last:

1. Take the base row's manifest keys, the members of `LEG_KEYS` (I1, unit 12); a descriptor-only
   key such as `history_depth` or `red_after_land` is not one and never reaches the manifest.
2. Overlay each key of `[gate_leg.gov]`.
3. Resolve `{kit}` to `{prefix}/<home>` and `{memory_root}` to gov's memory root, the two tokens
   gov's own run fixes. Any other target token left in the row (`{gate_file}`, `{playbook_path}`,
   `{manifest_path}`) is a refusal naming the leg, because the `gov` sub-table must spell gov's value.
4. Write the list as JSON, two-space indent, UTF-8, one trailing LF (`.gitattributes:8` pins the file
   LF).

The order is new. The runner reads it only as the dispatch tie-break among legs with equal priors
(`tools/run-gates/run-gates.sh:2764`, `:2783`), which a leg with any timing, evidence or ceiling never
reaches.

### The gate

`--conform` grades the population both ways and every declaration's fields:

| Arm | Red on | Was |
|---|---|---|
| fresh | the manifest differs from the render, naming each leg added, dropped or changed | 7h's both-ways join |
| one declaration | a name declared twice, in any two of the descriptors and the registry | 7h's "claimed by both" and "exempted AND claimed" |
| exempt reason | an `[[exempt_leg]]` row with an empty `why` | 7h |
| subject | absent, or outside `kit` and `repo` | 7h, both paths |
| ceiling | not a positive integer, a bool included | 7h |
| reads | a class outside `history`, `base`, `clock`, `remote` | the runner's reader (`tools/run-gates/run-gates.sh:2791`) |
| name | a digit-bearing parenthetical | 7h's AC1b |
| purpose | unit 19's shape arm | 7h, unit 19 |
| token | a target token left unresolved in gov's row | new, S2 step 3 |
| enforces | an empty `enforces` on a leg that is no `leg` row of `core-pending.txt`; a tag no principle or practice row holds | new; PLAY-dOrderedCharter-7 S3 grades the same pair from the registry's side |

The agreement arms of 7h (descriptor against manifest on `subject`, `doc_reads`, `impure`, `reads`,
`ceiling`, and the `tag`, `tests`, `enforces` and `purpose` arms units 12, 22 and 19 add to it) have
nothing left to compare: one declaration renders the row, and a difference
gov means is spelled under `gov`, where a reviewer reads it. That is the fold, and the `fresh` arm is
the both-ways join it leaves.

### The kind row

### The enforces rule

For each leg, in order, every step that reaches it contributes:

1. A `principle.p<n>` whose v2 `[enforcement]` row (v2:1813) names a clause carried by the unit whose
   commit introduced the leg (the leg's name in `git log -S`), found through that unit's spec's
   `**Carries:**` lines.
2. A `practice.<name>` of `tools/playbook/practices.toml` whose line states the rule a red of this leg
   reports broken, read from the leg's `purpose` (unit 19) and its gate script's header.

A leg neither step reaches is put to the owner (S6). The review record holds one row per leg: name,
tags, the step and the `path:line` each tag came from; and a "Put to the owner" section, or `none`.
What no probe sees: whether a tag names the rule the leg actually enforces; the closing review reads
the rows against their cites.

### Migration

One commit. For each of the 68 claimed legs (PINNED at `19d6aae6`, `selfcheck`'s 7h note), every
manifest key whose value the descriptor row does not already render goes under its `[gate_leg.gov]`
sub-table: measured at `19d6aae6`, `chunk` on all 68, `ceiling` on 64, `argv` on 10 and `guard` on 18,
with `guard = []` read as absent (PINNED, 2026-10-25). For each of the 74 exempt legs, the manifest row
moves whole onto its `[[exempt_leg]]` row. The base rows are untouched, so an adopter's emitted manifest
is byte-identical; `--write` then renders gov's manifest, whose rows equal the pre-pass rows as a set
(AC2). Hand-editing `tools/gate-legs.json` ends: a red names the declaration to edit.

### Alternatives rejected

- **Generate the descriptors from the manifest.** The adopter's row is the descriptor's and gov's
  differs from it on 28 measured legs; the manifest cannot say which values an adopter receives.
- **A gov-only overlay file beside the descriptors.** Two files per leg is the defect this unit
  removes; the sub-table keeps gov's difference on the row it differs from.
- **Keep 7h's agreement arms beside the factory.** They would compare a rendered file with its own
  source and can never fail, which is a gate never seen red.

## 5. Production-readiness checklist

- security — the factory writes one generated file and appends to a named descriptor under `new`;
  no new write path outside the tree.
- perf / scale — one TOML read per descriptor and one JSON write; `--check` runs in regen's stage 1.
- error / empty / loading states — an unparsable descriptor is a refusal, exit 2, naming it; an empty
  population is refused, never rendered as `[]`.
- observability — `--conform` prints `legs: <n> declared · <c> claimed · <e> exempt · <p> enforces-pending`.
- risks — a govkit arm that walks every `[[gate_leg]]` value may meet the `gov` dict; the pass runs
  `selfcheck` over the converted tree. Dispatch order among equal-prior legs changes (§4).
- testing — `--selftest` plants every gate arm; the arm in §7 is observed RED then GREEN by the main
  loop at the close.
- migration — §4, one commit, adopters unchanged.
- user docs — `tools/run-gates/README.md` says the manifest is generated and names `new`; no page under
  `help/` documents the manifest.

## 6. Acceptance criteria

- **AC1** — When `python leg_factory.py --check` runs on the landed tree, it exits 0; in a scratch
  clone with one manifest row hand-edited, and in one with a declaration added and no `--write`, it
  exits 1 naming the leg as changed or as added.
  Red when: `--check` compares row counts, so an edited row of equal count passes.
  fixture: a clone of the tree under `%TEMP%/<short-name>`, none in the tree today.
- **AC2** — When the pass compares the rows of `tools/gate-legs.json` before and after its `--write`
  with `python -c "import json,subprocess,sys; p=sys.argv[1]; a=json.loads(subprocess.run(['git','show',sys.argv[2]+':'+p],capture_output=True,text=True,encoding='utf-8').stdout); b=json.load(open(p,encoding='utf-8')); f=lambda r: sorted(json.dumps(x,sort_keys=True) for x in r); print(f(a)==f(b))" tools/gate-legs.json <start>`,
  it prints `True`.
  Red when: a `gov` value is lost in the move, so gov's row for that leg changes.
- **AC3** — When `python tools/govkit/govkit.py apply --target <scratch> --all` runs into one scratch
  adopter at the pass's start and into another at its end, `cmp` of the two emitted `gate-legs.json`
  files exits 0.
  Red when: a gov-only value such as a measured `ceiling` sits in the base row, so it travels to every
