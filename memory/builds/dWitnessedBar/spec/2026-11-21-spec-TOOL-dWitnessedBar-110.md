### The nonce

`secrets.token_hex(8)` gives sixteen hex characters, so `vp-<hex>` is a valid run directory name
beside `gate-run/<ts>-<pid>`, and no two candidates or runs share one. A run that wrote the slot
before verify-peer's bar, during it or after it never writes the nonce, so `after != nonce` refuses
each; the re-read refuses a rewrite between `after` and the publish. A bar that wrote nothing leaves
`after` as the earlier record's id or `None`, refused as today. The tag's `run_id` is the nonce.

WHAT IT DOES NOT CHECK: a process on the same node that reads the nonce from the runner's
`gate-run/current` file and writes it into the slot itself.
