### B1 — the memory-tree kit's backlog row refuses every default adopter at load (ids 5, 9)

- **Where:** [tools/memory-tree/kit.toml:424](../../../../tools/memory-tree/kit.toml), against `resolve_shared_records` (tools/unattended/lib-unattended.sh:506) and `.unattended.conf.example:377`.

Make the backlog rows conditional on the memory-tree conf's `BACKLOG_MODE=builds`, for example with a `when` key that `resolve_generated_indexes` evaluates and govkit 6c grades. As a fallback, have `resolve_generated_indexes` skip any kit row whose index overlaps the effective `SHARED_RECORDS`, and say so on stderr.
- **Left-shift gate:** Add a suite arm whose fixture tracks the real memory-tree and codebase-map `kit.toml` files and loads the shipped `.unattended.conf.example`. Assert that the driver loads (rc 0) and that check 38 is clean. That arm is the class gate: a kit row that collides with a shipped default reds it.

## MEDIUM

### M1 — `--check-commit` reads the Pass trailer differently from the close (ids 1, 21)

- **Where:** [tools/unattended/unattended.sh:9720](../../../../tools/unattended/unattended.sh), with the `none` exemption at 9730.
- **Defect:** The commit-time step reads the trailer with a case-sensitive `sed -n 's/^Pass: *//p'`. `pass_commit` and `log_attribution_tokens` use `%(trailers:key=Pass)`, which matches the key case-insensitively. A message ending `pass: TOOL-x-3`, whose subject does not name the unit, therefore passes the commit-time step unchecked, and the close then attributes it to TOOL-x-3. Separately, any `none` value exempts the whole commit, while `pass_commit` still attributes a commit carrying both `Pass: none` and `Pass: TOOL-x-3` to TOOL-x-3. Both cases lose the repairable moment the verb exists for. The close still grades the commit, which is why this is medium.
- **Fix (judged sound, both ids):** Read the trailer with the same `%(trailers:key=Pass,valueonly)` semantics `log_attribution_tokens` uses, or with a case-insensitive key match. Treat `none` as an exemption only when it is the sole value, and refuse a message that mixes `none` with a unit id.
- **Left-shift gate:** Add one arm per spelling: lowercase key, mixed `none` plus unit id, and the canonical form. Put the trailer read in one shared library helper so the three readers cannot drift again (see L2).

### M2 — check 23's ambiguity test still reads the subject (ids 6, 10)

- **Where:** [tools/unattended/check-unattended.sh:3770](../../../../tools/unattended/check-unattended.sh).
- **Defect:** `pass_commit` now selects a pass commit by its Pass trailer alone (lib-unattended.sh:736), but the ambiguity test still reads `%s`. A commit carrying `Pass: TOOL-x-1` whose subject names a same-group sibling is reported as "one commit names two passes" and skipped with `continue`, so its writes are never graded or counted. `--check-commit` mitigates this unless the commit used `--no-verify`. The skeptic found the finder's second case (a multi-unit trailer reds the close) weak, because `--check-commit` requires every staged path to be covered by each named unit. Only the first case is confirmed.
- **Fix (judged sound, both ids):** Derive the ambiguity set from the shared producer: `log_attribution_tokens -1 "$dshit" | cut -d' ' -f2-`. A trailer-carrying commit is then tested on its trailer ids, and a commit with no trailer falls back to its subject, as `pass_commit` and `build_commit` do.
- **Left-shift gate:** Add an arm with a trailer naming one unit and a subject naming a same-group sibling, bound beside an overlapping sibling, that asserts the pass is graded.

### M3 — `--check-commit` sees only a rename's destination (id 7)

- **Where:** [tools/unattended/unattended.sh:9742](../../../../tools/unattended/unattended.sh).
- **Defect:** Porcelain `git diff --cached --name-only` applies rename detection, so after `git mv out/f.txt in/f.txt` it lists only `in/f.txt`. Check 23 grades with `diff-tree -r --name-only` (check-unattended.sh:3797), which lists both paths. A move out of an undeclared path passes at commit time and is counted at the close, when it can no longer be repaired.
- **Fix (judged sound):** Use `git diff-index --cached --name-only HEAD`, or `git diff --cached --name-only --no-renames`, so the staged set is the one check 23 will grade.
- **Left-shift gate:** Add an arm that `git mv`s a file from an undeclared directory into a declared one and asserts the refusal names the source path.

### M4 — the RUN.md subtraction has no arm that can fail (id 15)

- **Where:** [tools/unattended/unattended.test.sh:5761](../../../../tools/unattended/unattended.test.sh).
- **Defect:** The AC3 arm appends only a newline to RUN.md. `check_gen_region_only` compares `$(GIT show ...)` captures, and command substitution strips trailing newlines, so RUN.md passes as gen-region-only even with the run-state subtraction deleted. The same capture also forgives any change made only of trailing blank lines. That forgiveness was already in check 23 at the base and is new only for `--check-commit`.
- **Fix (judged sound):** Append a real authored line to RUN.md, for example `printf 'note: x\n' >>`, and stage RUN.md alone in its own arm so only the subtraction can let it through.
- **Left-shift gate:** Observe that arm red with `[ "$p" = "$rel" ] && continue` removed before landing it (§7: a gate is not landed until its failing case has been observed).

### M7 — govkit check 6c misses tokens the shell reader drops (id 20)

## LOW

### L1 — `--check-commit` skips the GIT pin and leaves paths unquoted (id 4)

- **Where:** [tools/unattended/unattended.sh:9742](../../../../tools/unattended/unattended.sh), the loop at 9754, and the printed command at 9766.
- **Defect:** The verb uses bare `git diff --cached`, not the kit's `GIT` wrapper (lib:54), so it skips the replace/graft pin. It then iterates `for p in $st` with globbing on and pastes unquoted paths into the suggested `--dispatch` command. This is reachable only with a `git replace` of HEAD or with glob or shell metacharacters in filenames, and the close re-grades through the pinned `GIT`.
- **Fix (judged sound):** Use `GIT diff --cached --name-only -z` read with `while IFS= read -r -d ''`, or put `set -f` around the loops. Quote each path in the printed command with `printf %q`.
- **Left-shift gate:** Extend the kit's existing bare-`git` scan, if there is one, to `verb_check_commit`. Add an arm staging a path named `d*/x` beside a declared `d1/x`.

### L2 — the three trailer readers tokenise values differently (id 8)

### L3 — commit time and the close forgive different path sets for a narrowed unit (id 11)
