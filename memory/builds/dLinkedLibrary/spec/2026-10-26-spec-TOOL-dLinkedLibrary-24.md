## 1. Goal

A bug class says whether a gate guards it in free prose: `DECLARES_RE` (`tools/memory-tree/gotchas.py:74`)
admits "gated by", "gated in", "gated at" or "no machine gate" anywhere in the body, and nothing checks
that a named gate exists or refuses anything. At base 64 class records say they are gated and 7 of them
name a leg of the manifest. The night pass two's point 6 settled the shape (the owner's NT-25): a class is
`gated` only where it names a leg of the leg manifest and a planted case of the class that leg is seen to
refuse, `partly-gated` or `ungated` otherwise; a gated class leaves every checklist, the review's among
them; a syntactic class becomes a gate at its second occurrence; and a class's anchors are marked as
where it bit, never what triggers it (gap-mem-14, gap-mem-45). This unit derives that status and acts on
it.

## 4. Design

### The derivation

| `gate:` | leg in the manifest | `planted:` tracked | `observed:` at current blob and argv | status | check |
|---|---|---|---|---|---|
| absent | — | — | — | `ungated` | clean |
| present | no | — | — | `ungated` | red: the leg is absent |
| present | yes | no | — | `partly-gated` | announced |
| present | yes | yes | none, or stale | `partly-gated` | announced: observe it |
| present | yes | yes | `unobservable` | `partly-gated` | announced: the leg is red without the plant |
| present | yes | yes | `passed` | `partly-gated` | red: the planted case passes the leg |
| present | yes | yes | `refused` | `gated` | clean |

The observation carries the plant's blob and a hash of the leg's argv as the manifest spells it, so an
edited plant or a moved leg makes it stale, and stale reads `partly-gated` until `--observe` runs again.
What the derivation does not check: that the plant stages the class's mistake rather than any break the
leg refuses, and that `observed:` was written by the verb and not by hand; the first is the record's
reviewer's question, the second is the record diff's.

### An observation

```
$ python gotchas.py --observe node-check-is-not-a-syntax-gate
observed — node-check-is-not-a-syntax-gate · workflow script syntax · refused
```

```yaml
gate: workflow script syntax
planted: memory/gotchas/planted/node-check-is-not-a-syntax-gate.patch
shape: syntactic
observed: refused 3f9c2a71 8e01b4c2 2026-10-30
```

### Migration

`DECLARES_RE`'s prose stays in each record as history; nothing reads it after S4. An adopter's
catalogue loses check 18's prose demand and gains nothing it must write: a class with no `gate:` is
`ungated`, which is the honest reading of a record that names no observed gate. The INDEX is
re-rendered in the same commit.

### Rollout

The fields, the derivation and the check first; the cut and the tiers next; the backfill's plants and
observations last, so each class turns `gated` only once it is seen to refuse.

### Files touched (estimate)

- `tools/memory-tree/gotchas.py`: S1 to S7, the inline `resolve_prefix_token` block
- `memory/gotchas/*.md`: S8's fields
- `memory/gotchas/planted/`: S8's planted diffs
- `memory/gotchas/INDEX.md`: re-rendered
- `tools/memory-tree/HYGIENE.template.md`, `memory/HYGIENE.md`: S9
- `tools/memory-tree/check-memory-hygiene.sh`: `KIT_MEMORY_TREE_VERSION`

### Alternatives rejected

- **Derive at every checklist by running the legs.** A review's checklist would run every gated class's
  leg twice; the observation pays that once per plant and leg change.
- **A status column typed into each record.** It is the declaration the clause retires.
- **Anchors read only from `## Where it bit`.** It drops the product paths a record names in its fix,
  which order a review's list today, and the research found the selector's failure was noise, not recall
  (`2026-10-19-build-PLAY-dClosedLoop-1-research-gotchas.md`, "Conclusion").

## 5. Production-readiness checklist

- security — `--observe` runs a leg's argv from the tracked manifest in a scratch clone under the temp
  root, never in the working tree, and applies only a tracked diff; it writes one front-matter line.
- perf / scale — `--check` and the checklist read blobs and the manifest, no leg run; `--observe` costs two
  runs of one leg per class.
- error / empty / loading states — a plant that does not apply records `unobservable` with git's reason;
  an absent manifest key keeps `load_leg_names`' announcement.
- observability — the cut's header line, the `partly-gated` lines, the report's `left-shift owed` lines.
- risks — a plant can stage a break the leg refuses for another reason; §4 states it, and the record's
  diff is where it is read.
- testing — AC1 to AC11 by a pass; the arm of §7 at the close.
- migration — §4.
- user docs — no page under `help/` covers bug classes.
