4. **Point names are spelled two ways.** PLAY-dOrderedCharter-16 uses `point.<layer>.<seg>` (e.g. `point.memory.record-home`); TOOL-dWellOiledMachine-59 uses `point.cadence-items`.
5. **The run record misses runs and anomalies.** Under `per-run`, a run with no spec unit (any Maintain run) gets no run record (`record.py:1183`). `ANOMALY_KINDS` has no "ceiling breach" or "dead probe", which layer-expansions:252 counts as anomalies.
6. **`defer dormant` has no proposer yet.** TOOL-dRankedPlan-4 S2's `--dormant` is not in `gen_build_index.py`. Unit 3 depends on that build landing.
