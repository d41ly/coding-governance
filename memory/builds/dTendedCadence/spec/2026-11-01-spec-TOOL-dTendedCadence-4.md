## 1. Goal

None of drift-audit's 27 signals carries an owner, and a report-only signal with no pin is legal by
design (`tools/drift-audit/drift_report.py:4323-4326`), so a detector can stand that no layer answers
for and that nothing bounds (gap-maint-02). This unit adds the admission rule: every registered
reading derives its owner from its record kind and resolves a pin, or under
`maintain.reading-admission: refuse-unowned` it is refused at registration, and under
`report-unowned` it is admitted and reported unowned, with nothing filed for it until an owner is
derived (layer-expansions:200-205).

- **S1** — The owner, `derive_reading_owner(row, kinds)` in `tools/drift-audit/drift_report.py`. `kinds`
  is `read_record_layers(root)`: `{name: layer}` over the `[[record-kind]]` rows of
  `record-kinds.toml`, found through the inline `resolve_kit_dir("memory-tree", "record-kinds.toml",
  …)` (`drift_report.py:55-56`) and parsed with `tomllib`, never by importing the memory-tree kit.
  The owner is the `layer` of the row the reading's `kind` names; a row with `scope = "node"` and no
  `kind` derives `layer.runtime`, since node state is Runtime's (layer-expansions:201). Anything
  else derives `None`: a `kind` the registry lacks, a kind whose `layer` is empty, or no registry at
  all. The owner is derived on every run and typed nowhere. Observed by AC1 and AC4.
- **S2** — The pin. A reading resolves a pin when its row's `pin` names an entry of the pins, or, with no
  `pin` on the row, when its record's own `tolerance` is not `None`: the derivation the engine already
  applies (`drift_report.py:4327`). A `pin` naming no entry is no pin, never a fallback to the
  tolerance. Observed by AC3.
- **S3** — The verdict, `check_reading_admission(rows, records, kinds, mode)`, one per reading:
  `admitted` with its owner; under `report-unowned`, `unowned` with its reason when either S1 or S2
  fails; under `refuse-unowned`, `refused` with its reason. `mode` is read once per run as
  `read_policy_value("maintain.reading-admission", root)` (S6). It runs in `main` where each record
  is paired with its pin (`drift_report.py:4321-4327`), after that join and before the table, the JSON, the
  offender keys and the history write, as the `BASELINES` refusal there runs (`:4332-4337`). The
  `assert` at `:4326` stays: a gateable record with no tolerance is a code defect, not a registration.
  Observed by AC1, AC2 and AC3.
- **S4** — What each verdict does.
  - Every record gains `owner` (a layer tag or `null`) and `admission` (`admitted`, `unowned` or
    `refused`) beside the `pin` the engine already adds; the signal functions' own record shape (I4) is
    unchanged.
  - `refused`: the table's status reads `REFUSED AT ADMISSION — <reason>`; `--check` prints
    `drift-report: reading admission refused — <name>: <reason>` on stderr and exits 1; `--offenders`
    prints `admission\t<name>`, so the bar's attribution sees a refusal its base already carried.
  - `unowned`: the status gains the suffix ` · unowned, nothing filed`, and `--check`'s verdict is
    unchanged by it. The `unowned` verdict is the hand-off: TOOL-dTendedCadence-14 sends every record
    not `admitted` down the log band, a journal line and a count with nothing filed, so no ask, patch
    or fix starts from it.

  Observed by AC1, AC2 and AC3.
- **S5** — Every registered reading carries a pin at this unit's landing (§8 F1). The five records

- **S6** — The policy read: drift-audit's adapter `read_policy_value(key, root, rev=None)` and

## 4. Design

### Evidence

At this base the 27 functions of `SIGNALS` (`drift_report.py:3521-3538`) return records that carry
no owner: `owner` occurs in the file only in comments (`:1741`, `:2398`, `:2431`). `main` pairs each

reverses that: a reading with no pin is refused or reported unowned. The design's admission entry is
"no reading without an owner and a pin", and its gates row lists reading admission
(layer-expansions:210, :216).

### Migration

The policy file at this base sets no `maintain.reading-admission`, so the default `refuse-unowned`
holds from the landing commit. The landing commit therefore carries S5's tolerances and gov's pin
entries, and any `kind` a row of TOOL-dTendedCadence-8 left unresolved is set in that row to the
record kind whose rows its offenders are, so AC6 holds at the tip. An adopter's update brings the
tolerances; an adopter whose `record-kinds.toml` lacks a kind its rows name reads those readings
refused, and its remedies are the row's `kind` or `maintain.reading-admission = "report-unowned"`,
both named in the help page.

### Alternatives rejected

- **A static check over the rows alone, as a new leg.** Rejected by S2's test: whether a row with no
  `pin` has one depends on its record's `tolerance`, which only the signal returns, so a row-only check
  calls every tolerance-bound reading pinless or none.
- **Admission in Maintain's read step only.** Rejected: the clause refuses at registration, and a step
  that runs after landing lets the refused row land.
- **An `owner` column on the row.** Rejected: the design says the owner is derived, never typed
  (layer-expansions:200), and a typed column beside the registry's `layer` is one fact twice.

## 6. Acceptance criteria

The admission fixture is a clone of this repository at the build commit under `%TEMP%/adm`, its remote
removed so the policy reader reads the local default branch (`tools/policy/policy.py:24-27`), with one
planted `[[reading]]` row per case committed on that branch, and, where a case names a value,
`.governance/policy.toml` committed with `maintain.reading-admission` set to it. Each command runs with
the fixture as its working directory and `tools/drift-audit/` as the path to the engine.

- **AC1** — When a row `planted_ownerless` with `kind = "no-such-kind"` is committed and no value is set,
  `python drift_report.py --check` exits 1 printing `reading admission refused — planted_ownerless: no
  owner derives from kind no-such-kind`, and `--offenders` prints `admission\tplanted_ownerless`.
  Red when: the planted ownerless reading is admitted, or `--check` exits 0.
  cost: a full report over this repository, under the `drift-audit records` leg's ceiling of 540 s
  (PINNED, `tools/gate-legs.json:1067`).
- **AC2** — When the same row is committed with `maintain.reading-admission = "report-unowned"`,
  `python drift_report.py --json` gives its record `"admission": "unowned"` and `"owner": null`, the
  table's row ends `· unowned, nothing filed`, and `--check` prints no admission line.
  Red when: an unowned reading is refused under `report-unowned`, or reported admitted.
- **AC3** — When a row `planted_pinless` names a real kind and `pin = "no-such-pin"`, `python
  drift_report.py --check` exits 1 naming `planted_pinless: no pin: no-such-pin names no entry` under the
  default, and under `report-unowned` its `--json` record reads `"admission": "unowned"`.
  Red when: a pin that names no entry falls back to the tolerance, or the pinless reading is admitted.
- **AC4** — When `python drift_report.py --json` runs in the fixture with no planted row, every record
  whose row names `kind = "build-readme"` carries the `layer` the registry's `build-readme` row declares,
  and a `scope = "node"` row with no `kind` carries `"owner": "layer.runtime"`.
  Red when: an owner differs from its registry row's `layer`, or is read from anywhere but the registry.
