## The habit this build never fully broke

Four rounds, and three of them were dominated by one class: **a sentence asserting what a sibling spec
says, written without opening it — or written correctly and then falsified when the sibling moved.**

This round attacked the mechanism rather than the instances. Thirteen cross-spec citations pinned a
sibling by REV NUMBER, and every one of those labels had already rotted. Eleven were rewritten to cite
the id alone or to mark the read as historical; two survive inside revision logs, which is the one
place a historical read belongs. Two carried substance that was outright false by the time it was
read: a claim that a sibling still owed a sentence it had already written, and a grep result asserted
in the present tense about a file that had since changed.

**The rule that comes out of it: cite the id, never the rev.** A spec's rev number is a moving
reference to a document under concurrent edit, and pinning it converts a true statement into a false
one on the sibling's next commit — silently, and in a document nobody re-reads.
