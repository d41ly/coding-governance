# Build brief — TOOL-dSweptBranches-3

**Serves:** journal TOOL-dSweptBranches-3

Built INLINE by the main loop, on units 2 and 4.

`--write` prints the report, writes the recovery manifest under the git common directory and flushes
it, then removes the deletable worktrees through unit 4's remover, prunes, and deletes the
deletable local branches no kept worktree still has checked out. `--remote` deletes the deletable
remote branches in one push. The default branch is excluded by name before any verdict is read. The
tool never merges, commits, checks out or pushes the default branch, and passes no hook-bypass
flag. The arms run `main` in-process where a seam must stage a failure or a busy row, and read the
module's `WRITE_TRACE` for the order. Unit 4's arms carry three helper names the lexicon refuses;
this pass renames them. No merge bar.
