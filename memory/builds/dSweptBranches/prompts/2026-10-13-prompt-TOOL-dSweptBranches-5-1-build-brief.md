**Serves:** journal TOOL-dSweptBranches-5

Built INLINE by the main loop, last, on unit 3's write flags.

The skill is a template the adopter renders with the kit's directory, `--check` re-renders and
compares, and the kit's `[[regenerate]]`, `[check]` and wiring leg carry it to adopters the way the
runlog kit's do. The template names the CLI only through the kit-dir token. Attended: fetch, report,
surface `UNMERGED-LIVE` and `UNKNOWN` first as decisions, `--write` on a yes and `--remote` on its own
yes, and the offer to merge the default branch into a live branch in its own worktree. Unattended:
the report and `--write`, never `--remote` without its own grant, never a merge. No merge bar.
