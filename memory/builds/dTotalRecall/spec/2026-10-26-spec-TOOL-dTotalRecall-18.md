## 4. Design

### Columns

| Column | Values | Graded |
|---|---|---|
| `home` | a tracked glob, `refs/gov/<glob>` or `<git-common-dir>/<glob>` | non-empty; a tracked glob of a `fields` kind matches at least one tracked file |
| `lifecycle` | `append-only` · `current-state` · `frozen` · `generated` · `out` | in the closed set |
| `readers` | read keys `<family>:<field>`, or `[]` with `readers-none = "<reason>"` | each key in `READ_KEYS` and read by some role, or the reason non-empty |
| `layer` | a `layer.<name>` tag | non-empty, of that shape |

The view's columns become `Kind`, `Tag`, `Home`, `Writer`, `Read by`, `Written by` and `Check`, a
derived cell's names each backticked and comma-joined, `—` where none.

### The pockets

The memory plan's `[pockets]` table gives each pocket outside the tree a family. Each family is one
witness row, `lifecycle` `out` for a cache or mechanic and `append-only` for a store a reader needs.
