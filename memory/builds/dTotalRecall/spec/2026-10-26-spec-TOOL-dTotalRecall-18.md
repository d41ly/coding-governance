| Column | Values | Graded |
|---|---|---|
| `home` | a tracked glob, `refs/gov/<glob>` or `<git-common-dir>/<glob>` | non-empty; a tracked glob of a `fields` kind matches at least one tracked file |

### The rename

```python
RECORD_KIND_TOKENS = ("spec-audit", "diff-review", "log", "research") + TYPED_RECORD_KINDS
KIND_ALIASES = {"journal": "log"}      # read-only: never written, read as its target
def canonical_kind(token): return KIND_ALIASES.get(token, token)
```

`read_bindings` admits a token in `RECORD_KIND_TOKENS` or `KIND_ALIASES` and records it as written, so
the `gen:spec-records` tables keep their `journal` cells and no generated region churns. A comparison
by value goes through `canonical_kind`. The hygiene ledger's `awk` (`check-memory-hygiene.sh:3141`)
matches `\*\*Serves:\*\* *(log|journal)`. Writing `journal` in a new record is legal and graded as
`log`; no writer of this repo emits it after this unit.
