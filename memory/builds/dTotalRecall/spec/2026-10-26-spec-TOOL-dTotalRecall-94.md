## 4. Design

### The census

```bash
# run from the repository root, with TOOL-dTotalRecall-93 §4's has_deviation sourced
census() {  # folder · probe function -> one census line per unit a record's file stem names, and a red where they differ
  local u a b s
  for u in $(ls "$1" | sed -n 's/^[0-9-]*-build-TOOL-dTotalRecall-\([0-9]*\)-deviation-[0-9]*\.md$/\1/p' | sort -un); do
    a=$("$2" "$1" "$u")
    b=$(ls "$1" | grep -c "^[0-9-]*-build-TOOL-dTotalRecall-$u-deviation-[0-9]*\.md$")
    s=$(cat "$1"/*-deviation-*.md | sed -n "s/^- \*\*Supersedes:\*\* \`\{0,1\}\([0-9-]*-build-TOOL-dTotalRecall-$u-deviation-[0-9]*\).*/\1/p" | sort -u | wc -l)
    echo "census $u probe $a files $((b - s))"
    [ "$a" = "$((b - s))" ] || echo "red census $u"
  done
}
census memory/builds/dTotalRecall/build has_deviation
census memory/builds/dTotalRecall/build has_deviation_90
```

The file count is an independent reader: `ls` and `sed` over names and Supersedes lines, never
`read_record`. A unit whose records are all superseded reads 0 on both sides. `has_deviation_90` is the
fence of unit 90 §4 "The write-once probe" with its first line's name changed and nothing else.

```bash
scan_foreign() {  # folder -> red census <n> for every unit with a live record that departs from no revision of its own unit
  local f b u
  for f in "$1"/*-deviation-*.md; do
    b=${f##*/}; b=${b%.md}; u=${b#*-build-TOOL-dTotalRecall-}; u=${u%-deviation-*}
    grep -qs "^- \*\*Supersedes:\*\* \`\{0,1\}$b\`\{0,1\}$" "$1"/*-deviation-*.md && continue
    grep -q "^- \*\*Departs from:\*\* \`\{0,1\}TOOL-dTotalRecall-$u@" "$f" || echo "$u"
  done | sort -nu | sed 's/^/red census /'
}
scan_foreign memory/builds/dTotalRecall/build
```

The red set of unit 90's probe is taken from the records' own text by `grep`, so AC2 compares two
readers that share no parse.
