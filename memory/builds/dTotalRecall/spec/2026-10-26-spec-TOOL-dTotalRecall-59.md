### The case

`GOV_DEFAULT_BRANCH`. Its AC3 group already proves a one-population `gained` under `shrink-only`

fixture's `tools/govkit/registry.toml`, `fx-merged`, key `record`, fields `"path", "section", "check"`,

`fx-merged (shrink-only): gained b.md<TAB>-<TAB>causes`, then resets and holds it to `rc=0` with no
`gained`. A table appended to the registry changes no other population's reads: `read_registrations`
reads each table by its own name.
