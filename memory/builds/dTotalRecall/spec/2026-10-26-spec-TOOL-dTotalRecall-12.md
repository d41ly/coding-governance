## 1. Goal

This build moves memory reads into sliced work orders, `record show` and `record find`, and a measure
that counts Read calls alone would pass that move by construction: Read carried 40.0% of today's
memory bytes, shell commands 59.5% (systems.md:683-685, the `[ms2-instrument]` third run). This unit
ships the acceptance re-measure counted over every read channel, the work order's inlined slices, Read
results on memory paths and the output of shell commands that name a memory path or call `record
show`, `record find` or `gov tag`, and its verdict, passing only if thirty days after landing the
median memory bytes per agent that reads memory are below 33 KB (systems.md:549-556). Today's median
under that measure is 57.2 KB over 3,073 agents (PINNED, 2026-10-17, systems.md:557).

## 4. Design

### Data model

```python
READ_CHANNELS = ("slice", "read", "shell")
READ_VERBS = {("record", "show"), ("record", "find"), ("gov", "tag"),
              ("gov_record.py", "show"), ("gov_record.py", "find"), ("gov_tag.py", None)}
TARGET_BYTES = 33000          # systems.md:550, a KB of 1,000 bytes (v2:1370)
WINDOW_DAYS = 30

derive_read_channel(name, tool_input, memory_root) -> "read" | "shell" | None
derive_project_dirs(projects_root, main_worktree) -> [Path]
measure_agent_memory(path, memory_root, read_slice) -> {"slice": int | None, "read": int, "shell": int}
read_slice_bytes(agent_path) -> int | None            # the stand-in; None is unarmed
derive_memory_verdict(totals, now, window, slice_armed) -> (word, exit_code)
```

`None` in `READ_VERBS` means any verb. A segment's program word is the first word after any wrapper or
interpreter that `extract_segments` and `_derive_program` (:479) already skip, read by basename.

The report, every figure derived at the run:

```text
memory: window 2026-11-02T00:00:00Z .. 2026-12-02T00:00:00Z · sessions 41 · agents 1,206 · reading memory 517
memory: agent type          agents  reading  median B   p90 B  read B  shell B  slice
memory: gov-builder             38       38     31,204  88,112  12,004   19,200  unarmed
memory: all, pooled          1,206      517     28,930  91,377
memory: verdict unarmed · median 28930 B · target 33000 B · agents 517 · slice unarmed
```

### The fixture

`--fixture --plant <case>` writes a scratch transcripts root under the run's temp path with one
session directory named as S5 encodes a scratch main worktree, plants the case's agent transcripts
through the same JSON-lines shape `write_transcript_lines` writes (`tools/runlog/selftest.py:1462`),
and prints the measure's lines for it. Cases: `read-memory`, `read-other`, `grep-memory`,
`shell-path`, `record-show`, `gov-tag`, `shell-other`, `foreign-dir`, `outside-window`,
`median-under`, `median-over`, `not-due`, `unarmed`, `empty`, `privacy`. Only the fixture may hand
`measure_agent_memory` a slice reader that returns bytes, so `median-under` and `median-over` can
reach a verdict; the CLI always passes the stand-in.

### Rollout

Live at landing. The verdict waits on the window and on the slice channel; until both are armed the
verb is a report, which is the honest state of the measure rather than a pass.

## 5. Production-readiness checklist

- security: transcripts hold the owner's and agents' text; the measure keeps no path, command or result
  text, prints counts only, and writes no file (S10). The transcripts root is resolved as the kit's
  other verbs resolve it, and a project directory resolving outside it is not read.
- perf / scale: one pass over each agent transcript in the selected directories; the window filters by
  the first timestamp before the walk. Measured at the build run over this node's transcripts.
- error / empty / loading states: no transcripts root, no session in the window and no agent reading
  memory each print their state; `empty` and `unarmed` are never `pass`.
- observability: every line opens `memory:`, and the verdict line names the window, the agent count
  and the slice channel's state.
- risks: the shell channel is an upper bound, since a command naming a memory path may print more
  than memory, held the same before and after (the `[ms2-instrument]`'s own caveat). The harness's
  project-directory encoding is observed, not documented; a change to it reads as `empty`, never
  `pass`.
- testing: AC1 to AC10, each on the fixture or the real tree.
- migration: none; a new verb and a new module.
- user docs: `help/memory-measure.md` (S11).

## 6. Acceptance criteria

- **AC1** — When `python tools/runlog/runlog.py memory --fixture --plant read-memory` runs, the read
  channel carries the planted result's bytes; `--plant grep-memory` counts a `Grep` under the memory
  root the same way; `--plant read-other` counts zero.
  Red when: a Read outside the memory root is counted, or one inside it is not.
- **AC2** — When `python tools/runlog/runlog.py memory --fixture --plant record-show` runs, the shell
  channel carries the planted `gov_record.py show` result's bytes and the Read-only total is zero;
  `--plant gov-tag` and `--plant shell-path` each count their result; `--plant shell-other` counts zero.
  Red when: a `record show` read goes uncounted, or a shell call naming no memory path is counted.
- **AC3** — When `python tools/runlog/runlog.py memory --fixture --plant unarmed` runs, every report
  line shows the slice channel as `unarmed`, and the verdict line reads `unarmed` with exit 3.
  Red when: the slice channel reads as zero bytes counted rather than as unarmed.
- **AC4** — When `python tools/runlog/runlog.py memory --fixture --plant foreign-dir` runs, the
  agent planted under another project's directory is not counted; `--plant outside-window` excludes an
  agent that started before the window.
  Red when: a foreign session or an agent outside the window enters the population.
- **AC5** — When `python tools/runlog/runlog.py memory --from 2026-10-01T00:00:00Z --to
  2026-10-08T00:00:00Z` runs over this node's transcripts, it prints one row per agent type with its
  agents, its agents reading memory, and its medians and p90s, then the pooled row.
  Red when: an agent type is missing, or a row prints no figure.
  cost: reads every local transcript of the window, seconds to minutes.
  figure: DERIVED at the run.
- **AC6** — When `python tools/runlog/runlog.py memory --fixture --plant median-under` runs, the
  verdict reads `pass` with exit 0 over a planted median of 32,000 B; `--plant median-over` reads
  `fail` with exit 1 over 34,000 B.
  Red when: a median at or above 33,000 B passes, or one below fails.
  figure: PINNED, the planted totals and the 33,000 B target (systems.md:550, v2:1370).
- **AC7** — When `python tools/runlog/runlog.py memory --fixture --plant not-due` runs, with the
  planted landing ten days before the fixture's clock, the verdict reads `not-due` with exit 3; `--plant
  empty` reads `empty` with exit 3.
  Red when: a verdict passes before the thirty days close, or over no agent.
- **AC8** — When `git grep -n "runlog.py memory --landed" -- memory/builds/dTotalRecall/BACKLOG.md`
  runs after the pass, it finds one open ask whose accept clause is the verdict line reading `pass`.
  Red when: the thirty-day verdict is carried by nothing.
- **AC9** — When `python tools/runlog/runlog.py memory --fixture --plant privacy` runs, with a planted
  command and result each carrying the marker `TOTALRECALL-12-MARKER`, the output does not contain it.
  Red when: a path, command or result text reaches the output.
- **AC10** — When `git grep -n "memory-measure.md" -- help/README.md` runs, it finds the page's line.
  Red when: the verb ships with no help page.
