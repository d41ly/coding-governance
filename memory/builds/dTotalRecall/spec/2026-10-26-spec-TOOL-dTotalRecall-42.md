## 4. Design

### The rows, after this unit

```toml
[[record-kind]]
name = "shape-run"
home = "memory/builds/*/build/*-build-*-shape-run-*.md"
id-rule = "<date>-build-<unit id>-shape-run-<n>.md"
unarmed = "no writer calls gov_record.py new shape-run yet"

```

Every other cell is the landed row's. `unarmed` joins `record_kinds.py#LATER_COLUMNS`, the columns
`render_row` does not write and their owners grade, and the registry's header comment and the kit
README's column list name it. `new` writes no key: a row gains it by hand, as `cardinality` is.

### The unarmed line

`render_unarmed_line(row)` returns `<name>: unarmed — no record yet`, followed by `; <unarmed>` where
the row carries the key. At HEAD the stream-plan line reads
`stream-plan: unarmed — no record yet; its writer is dIndexedDesign's planner`
(`record_kinds.py#check_fence_records`), and after S3 the same bytes come from the row.

### The directory probe

Under `:(glob)` a directory glob matches no file: `memory/builds/*/build/` and `memory/builds/*/build`
each list none, and appending `/**` lists 5841 files (DERIVED 2026-11-22, `read_tracked` at HEAD).
The predicate holds for none of HEAD's 42 tracked-path globs with no `**` (DERIVED 2026-11-22),
each row's `derive_home_globs` probed; `memory/archive/**`, the one `**` glob, is outside it.

### The grading rule

`derive_record_kind` reads the Serves kind through the binding grammar's own names: the first
`**Serves:**` line `tree_lib.BIND_RE` matches in the first `tree_lib.BIND_HEAD_LINES` lines of
`tree_lib.unfenced(text)`, its first token when that token is a member of
`tree_lib.RECORD_KIND_TOKENS` or a `tree_lib.KIND_ALIASES` key, read through `resolve_kind`. A glob
admits a path segment by segment under `fnmatch.fnmatchcase`, the segment counts equal, which is
`read_tracked`'s `:(glob)` reading of a glob with no `**`.

| A tracked record at a path | Graded against |
|---|---|
| on a typed kind's name grammar | that typed row alone (unit 1 §8 F8, unchanged) |
| under untyped `fields` homes, its Serves kind's row among those admitting it | that row alone |
| under an untyped `fields` home, its kind's row another that admits it | not this row; counted `other-kind` |
| no Serves kind, or its kind's row admitting no path of it | every untyped `fields` row whose home admits it, as today |

The count line gains the count per untyped row: `<kind> <n> graded <m> legacy <k> other-kind`. The
empty-home red reads the paths the home admits, before S5 narrows them, so a row whose every record is
another kind's reds nothing. At HEAD the rule moves three rows, each count DERIVED 2026-11-22 by
running it over `scan_legacy_records`' population:

- `spec-audit`, 806 graded to 459, 347 other-kind (DERIVED)
- `diff-review`, 806 graded to 369, 437 other-kind (DERIVED)
- `design-record`, 3 graded to 0, each of its records serving `research` (DERIVED)
- `log` and `research` keep 4032 and 2941 (DERIVED)
