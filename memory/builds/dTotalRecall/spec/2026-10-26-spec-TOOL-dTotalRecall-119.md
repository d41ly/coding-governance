### The reader

```python
def read_claim_slugs(root) -> set:
    """The slugs of the build claims this clone's cache holds, `gen_build_index.CLAIM_CACHE_NS`, which the claim
    CLI's fetch and its own writes fill; never an ask counter's nested name."""
    import gen_build_index   # noqa: E402  the cache namespace's one spelling
    ns = gen_build_index.CLAIM_CACHE_NS + "/"
    p = run_git(root, "for-each-ref", "--format=%(refname)", ns)
    return {r[len(ns):] for r in p.stdout.splitlines() if r.startswith(ns) and "/" not in r[len(ns):]}
```

`record_causes.py` already reaches `gen_build_index` at call time.

### The plant

After its commit, the plant makes a bare repository beside `repo`, adds it as the fixture's one remote under a name
of its own, pushes `HEAD` to `refs/heads/main`, points the bare `HEAD` there and calls
`gen_build_index.run_claim_cli(str(root), "slug", "fClaim", "--claimant", <twelve hex digits>)`. A non-zero exit raises
the fixture's ValueError with the CLI's line. `run_fixture`'s `set_fixture_env` already sets a caller's remote and
branch variables aside. It prints one line naming the ref the clone then holds.
