## 4. Design

### The form

```text
.md   **Serves:** log TOOL-x-1            .sh / .py   # **Serves:** log TOOL-x-1
      **Caused-by:** TOOL-x-1                         # **Caused-by:** TOOL-x-1
.js   // **Serves:** research TOOL-x-1
      // **Caused-by:** TOOL-x-1
```

`HEAD_EDGE_RE` is `BIND_RE`'s shape with the key set `Made-by|Caused-by`, both compiled from
`BIND_PREFIX`, so the two prefixes cannot drift. Every caller reads `BIND_RE` by the names `key` and
`rest` (`tree_lib.py#read_bindings`, `tools/playbook/edge_grammar.py#read_header_edges`), so a third
named group moves none of them. The reader takes the Serves line's prefix from the head it walks, since
the `binding` row it is handed carries none.
