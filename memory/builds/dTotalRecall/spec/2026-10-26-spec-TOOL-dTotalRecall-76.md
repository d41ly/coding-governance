### The blob probe

Each string is a Python literal inside a heredoc whose delimiter is quoted, so bash expands nothing
in it. Each revision is a literal, resolved to a commit by `git rev-parse --verify` before it is read,
since `git show` of an empty revision reads the index blob at exit 0. `check=True` makes a failed
resolve or read raise, a red, never a 0. This is the bridge from a blob to the count that the audited
unit 70 never spelled (ids 2 and 25), in the form units 71, 72 and 74 use.

```bash
# run from memory/builds/dTotalRecall/spec/ ; one line per string: the sha read, the unit, the count
python - <<'PROBE'
import re, subprocess
ROWS = [('<revision>', '<unit number>', '<string>')]
def read(*argv):
    return subprocess.run(['git', *argv], capture_output=True, check=True).stdout.decode('utf-8')
for rev, n, s in ROWS:
    sha = read('rev-parse', '--verify', '--quiet', rev + '^{commit}').strip()
    text = re.sub(r'\s+', ' ', read('show', sha + ':./2026-10-26-spec-TOOL-dTotalRecall-%s.md' % n))
    print(sha[:12], n, text.count(s), s)
PROBE
```
