## 4. Design

### The read, at the close

```bash
b=$(bash -c '. tools/unattended/lib-unattended.sh; extract_run_facts' < memory/builds/dPlacedRequest/RUN.md \
      | sed -n 's/^base:[[:space:]]*//p' | head -1 | tr -d '\r')
# then the block of TOOL-dPlacedRequest-56's §4, "The oracle the close runs", with "$b" as its one argument
```

In the build run, every first-parent merge on HEAD before `--prepare` is an ancestor of that run's
BASE, the spec run's landing included, so the block refuses; after `--prepare` the prepared merge is
not, so it is walked. The read is the working file's, which at the close is the committed one.
