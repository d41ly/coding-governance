### The placed race, per attempt, as this unit leaves it

```
for pr_n in 1 2 3:
  rm -rf "$pr_h/once" "$pr_h/held" "$pr_h/release"
  any of the three present -> pr_dirty=$pr_n; stop the attempts          (S2, this unit's line)
  a.md, b.md carry zq-race-marker-48-$pr_n; pr_e0 = health.log lines
  A in background; wait for $pr_h/held (30 s bound), else "request race never placed", stop

  else -> discard this attempt
```
