## 1. Goal

The flow's router becomes five declared items in the loop definition: `entry.orient`, the three placing
items `entry.place`, `entry.place-check` and `entry.place-owner`, and `entry.claim`, each with its
actor, needs, closed outcomes, witness and routes as flow-steps' `[entry]` table states them, and each
naming as its body the verb a sibling unit of this build ships (PM-9). Today none of the five exists
as a row, `item.entry.claim` is only a stand-in row of the transition tables, and kickoff's Step 1
orders a session to re-derive the git state its card already printed, a median 6 calls per session
(`gap-orient-04`). The rows are the last unit of this build, so every verb they name has landed.

## 5. Production-readiness checklist

- security — the rows only declare; every write is a sibling's verb behind its own boundary, and the
  owner row's record is written by the record factory.
- perf / scale — five rows composed with about seventy others; Step 1 drops from five git reads to
