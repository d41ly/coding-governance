## 4. Design

### The section form, as unit 59 defines it (S1)

`sec <file> <prefix>` in `### The criterion readers` of unit 59's §4 opens on the line whose start
is the fixed prefix and prints every line after it up to the next line matching `/^##+ /`. The
prefix is matched by `index($0, h) == 1`, so an apostrophe or a regex character in it needs no
escape, and `/^##+ /` needs two or more `#`, so a bash comment inside a fenced block stays in the
section. A prefix that opens no heading prints nothing, which fails the clause reading it.
