## 1. Goal

A placed `new`, `patch` or `repeat` request becomes a build by one act, `entry.claim`: its slug claimed on the
remote by a compare-and-swap create, and for a patch or a repeat its lease taken and its derived plan record
written, the patch's held for the owner when `patch.ratify` says `owner`. Every refusal on the way routes by its
cause, so a terminal tombstone is never retried however lenient `leases` is, and a live holder is waited for
within `flow.wait-ceiling`. Today a slug is checked against local history only (`check_slug_claimed`,
`tools/memory-tree/gen_build_index.py:3940`), no claims namespace exists, and no patch or playbook run has a
plan record or a ratification (scout B's row for this unit).

## 4. Design

### The act, in order

```
--entry-claim <slug> --request <key>
  lines   := placement.py record --request <key>            # refuses unless new|patch|repeat
  slug shape                                                # as cmd_new_build
  repeat && --pieces not a positive integer -> one line; exit 2   # before any read or write
  held    := observe_remote ls-remote refs/gov/claims/<slug>; fetch; read_claim_body
             own claimant-key -> resume at the first of S2..S7 not witnessed; no pre-check
             another key      -> --request-draw route-back item.entry.claim; exit 5
             no answer        -> leases.offline (unit 1); no folder written
             no ref           -> check_slug_claimed         # local pre-check, a fresh claim only
  claim   := write_gov_ref refs/gov/claims/<slug> "" $(build_gov_commit "" <render_claim_body(lines)>)
             1 -> own claimant-key ? claimed : --request-draw route-back item.entry.claim; exit 5
             2 -> leases.offline (unit 1); no folder written
  patch|repeat:
    lease  := unit 1 --lease acquire build <slug>           # refusal -> route_claim_refusal
    index staged beyond the scaffold's own paths -> refuse
    record := gen_build_index.py --placed-build <slug> …    # repeat: --playbook <path> --pieces <n>; stages README + registry
    commit := the staged scaffold, in a commit of its own   # before any transition record
    patch && patch.ratify == owner -> print owner item
  facts   := the claim's facts + disposition=<disposition>
  write_transition none, witness HEAD, facts, no scenario field   # the writer derives the scenario
    new    -> item.entry.claim claimed  -> planning         # B1
    repeat -> item.entry.claim claimed  -> designing        # B3
    patch  -> item.plan.dedupe patch    -> designing        # B2, stand-in dRankedPlan, gated by check_patch_ratified
```

### Resume

and resumes at the first that is not.
