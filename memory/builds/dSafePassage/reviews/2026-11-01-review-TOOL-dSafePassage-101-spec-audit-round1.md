- **Where:** §6 AC13 (and AC12), and the third and fourth §7 New arm lines.
- **What is wrong:** AC13 does `import selftest` without `-B` and does not clear `tools/govkit/__pycache__`. Its staged red edits selftest.py. - **Consequence:** a staged red can read ok when it should red, or a restored file can read red. The staged reds are manual and not measured, so the effect is a misread probe, not shipped behaviour.
- **Fix (skeptic judged it sound):** write AC13's command as `python -B -c ...`. AC12's command can also take `python -B` for uniformity. Have each New arm line remove `tools/govkit/__pycache__` before its staged red runs, and match the red to the `[dSP-92]` or `grader · release-engine` line it targets, never to the exit status alone, per memory/gotchas/staged-break-runs-stale-bytecode.md.
- **Left-shift:** class `staged-break-runs-stale-bytecode`. The gotcha exists, so add a gate that flags staged reds on imported Python run without `-B`.
