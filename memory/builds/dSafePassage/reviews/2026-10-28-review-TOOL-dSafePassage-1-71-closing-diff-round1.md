## HIGH

### H1 · `check_contained` reads a path only as POSIX, so a Windows path climbs out (id 1)

- **Where:** `tools/govkit/upgrade_steps.py:1040-1045` (`check_contained`). It is relied on by `read_image_paths` (`:1918`) and `write_from_before_image` (`:1129-1144`).
- **What is wrong:** The check tests only `PurePosixPath(rel).parts` for `..`, is_absolute and `:`. It never turns backslashes into slashes and never applies `ntpath.isabs`. So `..\ESCAPED.txt`, `\Windows\x` and `\\server\share\x` all pass, and `pathlib.Path(target) / rel` resolves outside the target. `govkit.py:1244` `demand_contained_dest` already answers the same question correctly, so this is two answers to one question.
- **Consequence:** `update --rollback` writes a before-image's `before` bytes to whatever path the image lists. The image under `.governance/steps/<entry>/<slug>.before.json` is committed adopter content. Anyone who can land a commit that edits it can make the next rollback on a Windows node create arbitrary files outside the repository. An image entry with `after: null` and an absent destination meets the precondition. Probe: an image listing `..\ESCAPED.txt` put `pwned\n` next to the scratch target.
- **Grade:** The finder graded this blocker and the skeptic bound it high, because the exploit needs a tampered committed image and then a rollback on Windows.
- **Fix (judged SOUND by the skeptic):** Route `check_contained` through `demand_contained_dest`, or apply the same normalisation: replace backslashes, run `posixpath.normpath`, then refuse a `..` prefix, `posixpath.isabs`, `ntpath.isabs` and any drive colon. Then also assert `(target/rel).resolve().is_relative_to(target.resolve())`.
- **Left-shift gate:** Add a selftest arm that feeds `read_image_paths` and `write_from_before_image` a backslash climb, a rooted `\x` and a UNC path. It requires a Refusal and nothing written outside the scratch target. Class: two-answers-to-one-question. Also add a checklist row: every containment test in govkit routes through the one helper.

### H2 · The before-image read and restore follow links out of the target (id 2)
