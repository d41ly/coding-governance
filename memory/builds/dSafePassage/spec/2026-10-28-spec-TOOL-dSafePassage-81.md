`core.longpaths` is needed on this host: without it the checkout fails on the build folders' long
record names. The join reads only the `--list` block that precedes the first `lexicon:` line. That
block is every offender, waived or not (`tools/lexicon/lexicon.py:3268-3270`). The over-pin block
after it is a capped re-print (`:3281-3287`) and is not read. It keys each offender by file and name
as a multiset, so two definitions of one name in one file count twice:

```python
import collections, re
pat = re.compile(r"^  (?:waived )?(\S+?):(\d+): (P1 verb|P2 suffix): (\S+) — (.*)$")
def load(p):
    rows = []
    for ln in open(p, encoding="utf-8"):
        if ln.startswith("lexicon:"):
            break
        m = pat.match(ln.rstrip("\n"))
        if m:
            rows.append(m.groups())
    return rows
base, head = load("list-base.txt"), load("list-head.txt")
key = lambda rows: collections.Counter((r[0], r[3]) for r in rows)
changed = set(open("changed.txt", encoding="utf-8").read().split())
for (path, name), n in sorted((key(head) - key(base)).items()):
    print("CHANGED" if path in changed else "UNCHANGED", path, name, n)
```

### The population

Seventy introduced definitions, as of `83817478f`. The line numbers will drift as the siblings land,
so the builder locates each by its scope and name. `Verdict` is the lexicon's own: DEBT names a canon
spelling and `--suggest` answers its target, while UNRULED is "no canon cluster holds" the leading
token, and `--suggest` answers "a SCOPING question, not a spelling one". `Scope` is the function the
definition is nested in, or `module` or `file`. `Refs` counts the `ast.Name` loads of the name inside
that scope, the definition excluded. For the two shell functions it counts call sites. Every target
answered `OK — <target> leads with <verb>, which the declaration carries` from `--suggest <target>
--as py.function`, or `--as sh.function` for rows 69 and 70, at the head on 2026-10-28.

The UNRULED targets are this writer's choice, made by reading each body against the declared glosses,
and F2 asks the owner to rule on them. The rule applied: `run` for a helper that spawns a process,
`read` or `load` for one that returns bytes or a parsed store, `check` for a predicate or an
assertion that records a miss, `build` for one that makes and returns a value, `write` for one that
persists, `render` for one that returns text, `parse` or `extract` for one that takes structure out
of text, and `set` for a closure that assigns. All seven `expect` helpers are one shape,
`if not ok: fails.append(what)`, and take one name, `check_ok`.

### Collisions

Each target was checked against its own scope and the module's top-level bindings, by AST over the
head's files. None is already bound in the scope it enters, and no scope rebinds an old name as a
parameter or an assignment, so every rename is a scope-local substitution of one binding. Three
cases needed a look:

- `git` in `check_inherited_config` (`tools/govkit/fixture_target.py:110`) cannot become `run_git`.
  The module already binds `run_git`, and the same scope calls it, so `run_env_git` is the target.
- `write` in `tools/govkit/fixtures/release-0/arms/arm_step.py` meets the attribute `fh.write` inside
  its own body, which is not a binding. No other `write` exists in that file.
- `fn` at `tools/govkit/selftest.py:4682` and `:4715` are the two closures `at` and `split_row`
  return. The parameters named `fn` of `plant` and `refused` in the same function are other
  bindings, and they keep their name. Inside `split_row`'s closure, the self-reference
  `fn.path, fn.oid = ...` moves with the binding.

`--suggest` is a spelling answer and not a semantic one. It maps `walk` to `scan` and `persist` and
`put` to `write`, and S1 takes those answers as given.

### The arithmetic

The pin is a two-sided equality (`tools/lexicon/lexicon.py:3281-3293`): a count under it reds as loudly
as one over it. The base sat exactly at 1212. Renaming all 70 introduced names leaves 1281 − 70 = 1211,
because the build also drained one base offender, `make_target`. So after this unit's renames the leg
prints `verb offenders 1211 UNDER pin 1212` and stays red until the declaration records the drain.
The owner ruled on F1 that this pass records it, which is S6. If a sibling of order 16 drains or adds
a base offender, the figure moves by that amount, so it is DERIVED by `--measure` at this pass's tip.

### The pin
