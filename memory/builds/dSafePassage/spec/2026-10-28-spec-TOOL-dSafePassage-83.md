### The ledger grammar the pass writes to

`check-memory-hygiene.sh:3350` reads a journal record's ledger. A block opens at a line
`**Evidences:** <id>` inside a record whose `**Serves:**` kind is `journal`. Any line starting `#`
closes it. A line `- AC<n>`, bold or not, is an answer: OBSERVED when it carries a backticked token,
AMENDED when it names `amended rev-<n>`, and a finding otherwise. The first record read for a label
wins. A criterion's tokens are read per line of the spec's §6 bullet, each backtick paired within its
line (`altoks`, `:3451`). An answer shares a token when one, case-folded, contains the other
(`:3508`). A token a criterion wraps across a line break is therefore read as the text between
the wrong pair of backticks. That is TOOL-dSafePassage-16 AC2's case.

### The probes

`ledger_check.py`, for AC3 and AC4, re-derives check 23's three readings with the grammar above. It
runs from the repository root and imports nothing of the gate's:

```python
import pathlib, re, subprocess
TOK = re.compile(r"`[^`]+`")
toks = lambda s: [t[1:-1] for t in TOK.findall(s)]
ls = lambda *g: subprocess.run(["git", "ls-files", *g], capture_output=True, text=True, encoding="utf-8").stdout.split()
form, tokof = {}, {}
for f in ls("memory/builds/*/build/*.md", "memory/builds/*/reviews/*.md"):
    j, u, cur = False, "", None
    for line in pathlib.Path(f).read_text(encoding="utf-8").splitlines():
        if line.startswith("**Serves:**"):
            j = bool(re.match(r"\*\*Serves:\*\* *journal", line))
        if line.startswith("**Evidences:** "):
            u, cur = (line.split()[1] if j else ""), None
            continue
        if line.startswith("#"):
            u, cur = "", None
            continue
        m = re.match(r"- *(\*\*)?AC(\d+)", line)
        if u and m:
            cur = (u, "AC" + m.group(2))
            if cur not in form:
                form[cur] = "obs" if TOK.search(line) else ("amd" if re.search(r"amended rev-\d+", line) else "bad")
                tokof[cur] = toks(line)
            else:
                cur = None
            continue
        if cur and line.strip():
            tokof[cur] += toks(line)
gap, bad, notok = [], [], []
for f in ls("memory/builds/dSafePassage/spec/*.md"):
    text = pathlib.Path(f).read_text(encoding="utf-8")
    head = "\n".join(text.splitlines()[:6])
    if " CLOSED " not in head or "Tier-2" not in head:
        continue
    uid = re.search(r"(?m)^# (\S+) ", text).group(1)
    sec = re.search(r"(?ms)^## \d+\. Acceptance criteria[ \t]*\n(.*?)(?=^## )", text)
    labs = {}
    for line in (sec.group(1) if sec else "").splitlines():
        m = re.match(r"([ \t]*[-*][ \t]*)?(\*\*)?(AC\d+[a-z]?)(\*\*)?([^A-Za-z0-9]|$)", line)
        if m:
            lab = m.group(3); labs[lab] = toks(line)
        elif labs and line.strip():
            labs[lab] += toks(line)
    for lab, ct in labs.items():
        k = (uid, lab)
        if k not in form:
            gap.append(f"{uid}/{lab}"); continue
        if form[k] == "bad":
            bad.append(f"{uid}/{lab}")
        if form[k] != "amd" and ct and tokof[k] and not any(
                a.lower() in c.lower() or c.lower() in a.lower() for a in tokof[k] for c in ct):
            notok.append(f"{uid}/{lab}")
print("gap", len(gap), sorted({g.split('/')[0] for g in gap}))
print("bad", bad)
print("notok", sorted(notok))
```
