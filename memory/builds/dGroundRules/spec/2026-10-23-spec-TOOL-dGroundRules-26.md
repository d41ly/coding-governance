## 1. Goal

The round-1 spec audit of units 22 to 25
(`memory/builds/dGroundRules/reviews/2026-10-23-review-TOOL-dGroundRules-22-25-spec-audit-round1.md`)
exited CONVERGED with finding **id 1 at HIGH**, which shares item **H1** with id 7
(`TOOL-dGroundRules-27`) and id 23 (`TOOL-dGroundRules-28`). This unit is id 1's promotion. It
repairs `TOOL-dGroundRules-24`, which sits at order 3, so it builds at order 4.

`TOOL-dGroundRules-24` S1 runs `govkit.py apply` from the source tree, and `apply` lands the bytes of
the source's HEAD commit, never of its working tree. On a bar run before a commit the case therefore
grades the last committed policy kit while the gate runner records its green against the working
tree, and a kit file that exists only in the working tree makes `apply` refuse. This unit installs
from a commit of the tree under test, made in a scratch clone, so the case grades the bytes the bar
says it graded.

## 2. Scope (IN)

- **S1** — The snapshot. `build_source_snapshot(source_root)` in `tools/policy/check_policy.py`
  returns the root of a scratch clone whose HEAD commits the source's working tree. In order:
  `git clone --quiet --shared --no-checkout <source> <s>` under the case's temporary directory; a
  temporary index under `<s>/.git`, started as a copy of the source's own index
  (`git -C <source> rev-parse --git-path index`); `git add -A` with that index, `GIT_DIR` set to
  `<s>/.git` and `GIT_WORK_TREE` to the source, so the source's ignore rules decide what counts and
  every new object lands in the clone's store; `write-tree`; `commit-tree -p HEAD` under a fixed
  `-c user.name` and `-c user.email`; `checkout --detach` of that commit in the clone with its own
  index. Every git call runs with `GIT_ENV_LEAKS` stripped from its environment first. A failed step
  fails the case naming the step and git's first stderr line. Observed by AC2, AC3, AC4.
- **S2** — The install from the snapshot. `adopter-fresh-target` runs
  `<s>/<tool root>/govkit/govkit.py apply`, the tool root derived as `TOOL-dGroundRules-24` S4
  derives it, and the target descriptor's `gov_source` names `<s>`. The receipt's `gov_commit` is then
  the snapshot commit. Observed by AC1, AC2, AC3.
- **S3** — The revision named. The case prints one line before `apply`:
  `adopter-fresh-target: installing from snapshot <sha8> of the working tree over HEAD <sha8>`.
  Observed by AC1.

## 4. Design

### Evidence

Every line below was read at base `3708a705` on 2026-10-23.

- `_cmd_apply` sets `commit = git(root, "rev-parse", "HEAD").strip()`
  (`tools/govkit/govkit.py:7533`) and reads each source through `blob_at(root, commit, w["src"])`,
  failing `does not resolve at <sha8>` when that returns `None` (`:7882-7884`).
- `blob_at` runs `git show <commit>:<path>`, documented "never from the working tree"
  (`tools/govkit/govkit.py:6706-6716`).
- The registry and every descriptor are read from the working tree (`load_registry` at
  `tools/govkit/govkit.py:247-255`, `read_descriptors` at `:13238-13253`), so a descriptor that names
  a file only the working tree holds resolves, and that file's bytes then fail at HEAD.
- `root` is the checkout `govkit.py` lives in, found by walking up to the nearest `.git`
  (`repo_root`, `tools/govkit/govkit.py:126-150`), so running a clone's own `govkit.py` installs the
  clone's HEAD.
- `demand_published_vintage` is called only from `update` (`tools/govkit/govkit.py:9232`), so a
  snapshot commit no ref contains is not refused by `apply`.
- `GIT_ENV_LEAKS` (`tools/memory-tree/tree_lib.py:262-275`) lists the location and pathspec
  variables a hook exports; the policy kit reaches `tree_lib` as `TOOL-dGroundRules-21` S26 states.
- The tree holds 5873 tracked files (`git ls-files | wc -l`, PINNED, measured 2026-10-23).

## 5. Production-readiness checklist

- security — the snapshot reads the source and writes only under the case's temporary directory;
  `--shared` reads the source's objects through alternates and adds none to its store (AC4).
- perf / scale — one shared clone and one `add -A` over a copied index, so files whose stat matches
  the source's index are not re-hashed; a few seconds over the PINNED 5873 files.
- error / empty / loading states — each failed git step fails the case naming the step and git's
  first stderr line, never a fallback to the source's HEAD.
- observability — the snapshot line names both commits, so a log says which bytes were graded.
- risks — an ambient `GIT_INDEX_FILE` or `GIT_DIR` would retarget the snapshot; both are stripped
  before every call.
- testing — `adopter-fresh-target` under `--fixture`, with AC1 to AC4.
- migration — none.
- user docs — N/A: a gov-only case.

## 6. Acceptance criteria

Every command runs from the repository root. The criteria spell the kit's files by bare name,
`check_policy.py`, `adopt-policy.sh` and `policy.py` under the kit, as `TOOL-dGroundRules-5` §6 does.

- **AC1** — When `python check_policy.py --fixture adopter-fresh-target` runs on the built tree, it
  prints `installing from snapshot` naming the source's `git rev-parse HEAD` as the commit it sits
  over, and the target's receipt records the snapshot commit as `gov_commit`.
  Red when: the case installs from the source's HEAD and names no snapshot.
- **AC2** — When a scratch clone of the built tree carries a one-byte syntax break in its kit's
  `adopt-policy.sh`, left uncommitted, and `python check_policy.py --fixture adopter-fresh-target`
  runs from that clone, it prints `WRONG`; with the break reverted, it does not.
  Red when: an uncommitted break in the tree under test reads green.
- **AC3** — When a scratch clone commits the deletion of its kit's `policy.py`, restores the file
  uncommitted, and runs the same case, the case prints no `does not resolve at` and its target holds
  the installed `policy.py`.
  Red when: a kit file present only in the working tree makes `apply` refuse.
- **AC4** — When `git count-objects -v` runs over the source before and after the case on a tree
  carrying one uncommitted edit, its `count` and `size` lines are equal.
  Red when: the snapshot writes objects into the tree under test.
