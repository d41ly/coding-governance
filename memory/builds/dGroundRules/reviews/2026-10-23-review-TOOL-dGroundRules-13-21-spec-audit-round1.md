## High

### H1. The census arm's home rule reds a default adopter on two enforcer shapes (ids 10, 38)

- **Where:** spec-17 §2 S5 and §4 "The census in an adopter" (home derivation).
- **What is wrong:** the rule reads "`home` is the enforcer's first segment below `{prefix}`, and a root-level enforcer is located at the tool root itself". Two census enforcers do not fit it:
  - `check-line-length.sh` sits at the tool root and ships through the conditional, non-default `check-line-length` entry (`home = "."`). It is not `[[exempt]]`, so its row keeps `ships = true`.
  - `skills/session-kickoff/manifest-check.sh` is outside `{prefix}`. The default `kickoff-manifest` kit installs it at `{prefix}/manifest-check.sh`, so the census path has no segment below `{prefix}` and names a place no install writes.
- **Consequence:** the tool root always resolves, so in any adopter without `check-line-length` the line-length row reads "kit resolves, enforcer absent" and is a finding. That reds the shipped `policy check` leg, spec-17 AC4 and spec-16 AC1, which is the install-day red this unit exists to remove. The manifest rows either red every default adopter or are silently never graded. Spec-16's fresh target installs only the policy kit and its `requires`, so it never sees the kickoff case.
- **Fix (both proposals REJECTED; the skeptics' corrected fix):**
  - Give each `[[cap]]` row in caps.toml a static `installed` field: the `{prefix}`-relative destination its kit installs to (`manifest-check.sh` -> `{prefix}/manifest-check.sh`). Give it a `kit` (registry entry) id too, used only to word the announce line.
  - Grade presence at that destination. When the file is absent and `ships` is true for a conditional kit such as `check-line-length`, announce `kit <id> not installed`.
  - Do not read the registry at runtime in an adopter: registry.toml:294-296 exempts `{prefix}/govkit`, so an adopter has no registry.
  - Extend S6's gov-only `budgets-ships-join` case so it asserts each row's `installed` and `kit` equal the registry's `[[entry]]` / `[[files]] to` claims.
  - Add a case that installs the registry default selection plus policy, and assert that the line-length and manifest rows are announced or graded, never reported as findings. Give AC4 rows for a conditional root-level enforcer and for `manifest-check.sh`, both in a target without those entries and on gov's tree.
- **Left-shift gate:** the `budgets-ships-join` extension above, which reds any census row whose recorded destination differs from the registry's `[[files]] to`.
- **See also:** M4 (id 4) is the same defect at a binding medium grade.
