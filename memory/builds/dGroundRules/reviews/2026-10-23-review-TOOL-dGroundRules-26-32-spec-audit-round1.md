## Medium

### M1 — The snapshot's `git add -A` ignores the source's `info/exclude` (ids 2, 10, 22, 31)

- **Where:** spec 26, §2 S1 ("so the source's ignore rules decide what counts"), §5 perf/scale and risks.
- **What is wrong:** S1 runs `git add -A` with `GIT_DIR=<s>/.git`, so git reads the clone's template `info/exclude` and never the source's. In gov's main checkout, `.claude/worktrees/`, `.claude/scheduled_tasks.lock`, `.claude/mailbox/`, `.claude/checkpoints`, `.claude/agent-registry.json` and `/sidechain-logs/` are ignored only by `.git/info/exclude`. `.gitignore` holds only `__pycache__/` and `*.pyc`.
- **Consequence:** Run from the main checkout, the snapshot commits each of the 16 linked worktrees as an embedded-repo gitlink, plus lock, mailbox and registry files. The snapshot is then not the tree that `git status` describes. A worktree with no commit checked out, or a lock held open on Windows, can make `add` fail, so the case reds for reasons unrelated to the policy kit. Hashing the extra files also undercuts the perf claim. This is the known class in `memory/gotchas/a-gate-that-walks-the-repo-root-reads-other-worktrees.md`. The graded kit bytes are unaffected, so the harm is contained.
- **Fix (judged sound by the skeptic):** Before `add -A`, copy `$(git -C <source> rev-parse --path-format=absolute --git-path info/exclude)` into `<s>/.git/info/exclude`, or pass `-c core.excludesFile=<that path>`. A third option builds the list in the source with `git -C <source> ls-files -z --cached --others --exclude-standard` and feeds it to `git update-index --add --remove -z --stdin` under the snapshot's `GIT_DIR`. Correct the S1 sentence to match. Add a criterion: in a scratch clone, an untracked file matched only by `.git/info/exclude` is absent from `git -C <s> ls-tree -r HEAD`. A stronger form: `ls-tree -r --name-only HEAD` equals `git -C <source> ls-files -co --exclude-standard`. That probe needs a write, so the build must run it.
- **Left-shift gate:** add a checklist entry. Any git call that runs with `GIT_DIR` redirected names which repository's ignore rules, index and config it reads.
