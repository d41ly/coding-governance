## 1. Goal

gap-mem-23 (`memory/builds/dClosedLoop/build/2026-10-14-build-PLAY-dClosedLoop-1-gap-register.md:206`):
the map's touch-drop is wired to nothing. `--drop-affordance-exempt` has no caller in `tools/`,
`.claude/`, `.github/` or `.githooks/`; its one invocation is advice in `WIRE-INTO-PROJECT.md:555`,

installed" (H5, `memory/builds/dClosedLoop/build/2026-10-18-build-PLAY-dClosedLoop-1-recut.md:145`).

This unit builds the join's frame in TOOL-dScopedBuild-3's host: the hunk set (I9), the join called

## 4. Design

### Evidence

- `drop_touched_exemptions(exempt, touched)` is `frozenset(exempt) - set(touched)`
  (`map_lib.py:1373-1383`), called only by `_drop_affordance_exempt` (`map_diff.py:107-125`) and the
  map's self-test; the CLI flag runs it after a range's attribution (`map_diff.py:366-367`).
- `map_diff.py` exits 2 at a root carrying no `.codebase-map.conf` (`:33-35`, `require_adopted_root` at `map_lib.py:156`),
  and resolves its root from `CODEBASE_MAP_ROOT` before its own directory (`map_lib.py:114-119`).
- "A kit may not import a sibling kit" (`memory/builds/dGroundRules/spec/2026-10-23-spec-TOOL-dGroundRules-1.md:113`),
  and the legacy slot reads the ledger by subprocess for that reason
  (`memory/builds/dFurnishedOrders/spec/2026-10-26-spec-TOOL-dFurnishedOrders-11.md`, §4).
- The leg's one log pass reads `--no-renames --name-only` (`routed_commits.py:233`), so it carries no
  hunk; S1 is its own pass.
- `git diff-tree --stdin -U0 --no-merges -M -r -p` over one merge and one non-merge sha printed the
  non-merge's sha and hunks and nothing for the merge, probed at `5f0b11f12`.
- gov's grace list is empty (`memory/map/affordance-exempt.toml`, `exempt = []`), so every red case
  here is planted.

### The lines

```
routed-commits: touch · TOOL-tFix-1 · 3 commit(s) · 4 path(s), 9 hunk(s) · build.scope refuse
routed-commits: touch · TOOL-tFix-1 · claim · feat · touched and still graced — the Build exit's point.map-writers adapter writes it
routed-commits: touch · TOOL-tFix-1 · claim · not-installed: no .codebase-map.conf
routed-commits: touch off — no arm is installed: no .codebase-map.conf, and TOOL-dScopedBuild-8's drain reads no ledger
```

At the Build exit a written shrink prints
`routed-commits: touch · TOOL-tFix-1 · claim · feat · grace shrunk by point.map-writers affordance-exempt`.

### The map's check mode

The claim arm's call, and the adapter's `argv` without its last flag:

```
python3 <codebase-map>/map_diff.py --paths-from - --drop-affordance-exempt --check     # the arm, S3
["python3", "{prefix}/codebase-map/map_diff.py", "--paths-from", "-", "--drop-affordance-exempt"]   # the adapter, S5
```

`--paths-from -` reads one path per line, CR stripped, and refuses beside a range or `--tree`.
`--check` prints only `would-shrink <feature>` lines and exits 0, or 2 on a refusal, so the join reads
lines and never an exit code that also means "git failed" (`map_diff.py:31`). The writer's own
output, `# affordance-exempt: dropped [...]`, is unchanged without `--check`. `{prefix}` resolves as
every gate-leg argv's does, to the tool root.

### What it does not check

Whether a touched feature's dossier then carries its affordance block, which the map's gate grades;
a hunk's line after a later commit shifts it, since each pair is in its own commit's post-image, the
union the design names; a feature touched only by a merge's resolution; and a tree whose map conf
names a `MAP_ROOT` the kit cannot read, which `map_diff.py` refuses and S6 prints.

## 5. Production-readiness checklist

- security — paths reach `map_diff.py` on stdin, never on argv or through a shell; the adapter argv
  is read from a tracked registry and run as a list; `CODEBASE_MAP_ROOT` is the graded tree's path.
- perf / scale — one `diff-tree` spawn and one `map_diff.py` subprocess per graded unit, none when
  off.
- error / empty / loading states — `not-installed: <why>` per arm; `touch off` with no arm; a
  `map_diff.py` exit outside 0 and 2 is a Refusal, exit 2, naming its stderr.
- observability — one line per touched graced feature, naming the adapter that writes it.
- risks — the shrink lands at the exit, so a push between a unit's last pass and its exit warns on
  a feature the exit then writes.
- testing — the hunk reader on a rename, a deletion and a merge; the core-only tree; a planted
  graced feature touched under each value; the exit's write; the map's `--check`.
- migration — none.
- user docs — `help/build-scope.md` and `WIRE-INTO-PROJECT.md` (S7).
