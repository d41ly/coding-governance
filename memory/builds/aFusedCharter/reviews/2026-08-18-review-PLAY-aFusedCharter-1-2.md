## Refuted — not carried

- **`TOOL-1` S10 landed without an acceptance criterion.** AC9 asserts every leg green under `GATE_FULL=1` and §7 names `drift-audit records` explicitly; the `empty by declaration` literal is deliberately `PLAY-3` AC4's, and `PLAY-3` S4 states the split in terms. Round-1 B3's fold reproduces exactly against source (`HANDKEPT` is a one-row list, `DECLARED_EMPTY` is a signal-name set, `drift_report.py:876` prints the literal).
- **`PLAY-2` S8 introduces a third, unspecified HTML-comment namespace.** `parallel-coding-governance.template.md:12` already carries `<!-- governance-template: v2.10 -->` and `WIRE-INTO-PROJECT.md:85` requires it survive a deploy verbatim, so comment passthrough outside the renderer's declared namespaces is already load-bearing; `DEPL-1` S4's refusal is keyed on the NAME inside a recognised namespace, which a fence pair is not.
- **`BUILD`'s `<done>/<total>` violates the grammar its own spec states.** S1 already legislates glued-versus-spaced for the colon ("a colon survives only glued to a value, as a port"); `up`'s slash is space-delimited and `BUILD`'s is glued, like `<old>..<new>`. No verdict changes.
- **The fifth marker-contract reader has no declared interface and `testsuite counts` is missing from `DEPL-1` §7.** §7 names `testsuite counts`; `tools/memory-tree/marker-contract.test.sh` is row 16 of `memory/project/testsuite-count-waivers.txt`, prints `PASS ($ncase cases x 4 readers…)` and carries no floor, so adding a reader moves nothing. The interface gap is already inside R2-11.
