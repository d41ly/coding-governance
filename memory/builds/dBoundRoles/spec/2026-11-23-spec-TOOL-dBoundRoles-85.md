## 1. Goal

`check_unit_row` holds an `adopter-rule`, the one statement type that carries free prose, to a level-0
`repo` unit. A role's house text moved into the overlay as a level-5 unit selecting its role is prose,
so the up of `TOOL-dBoundRoles-19` S2 (its §8 F4) would write a row the grammar refuses. This unit lets
an `adopter-rule` type a level-5 `repo` unit under `budget = "block"`, declares the levels it types in
one table, and names a refused row's level.

## 2. Scope (IN)

- **S1** — The table. `ADOPTER_RULE_LEVELS` in `tools/playbook/instruction_units.py` maps each level an
  `adopter-rule` may sit at to the budget class it owes there: level 0 to none, any budget, and the
  `role` level, `LEVELS.index("role")`, to `block`, a key of `BUDGET_BYTES`

- **S2** — The row check. `check_unit_row` (`tools/playbook/instruction_units.py#check_unit_row`) admits

  the class owed there. A row of another namespace, or at a level the table lacks, reds `type`, naming
  its namespace or its level and the levels the table holds; a level-5 row under a budget other than
  `block`, or none, reds `budget`, naming the class it owes. Observed by AC1, AC2 and AC3.

### The check

```python
ADOPTER_RULE_LEVELS = {0: None, LEVELS.index("role"): "block"}

if unit.type == ADOPTER_RULE:
    owed = ADOPTER_RULE_LEVELS.get(unit.level, "-")
    if ns != "repo" or owed == "-":
        add_red("type", f"{unit.type!r} types a `repo` unit at level {held}; this is a `{ns}` unit at level "
                        f"{unit.level}", ...)
    elif owed and unit.budget != owed:
        add_red("budget", f"an {unit.type} at level {unit.level} owes budget {owed!r}, not "
                          f"{unit.budget or 'line'!r}", f"give it budget = {owed!r}")
```
