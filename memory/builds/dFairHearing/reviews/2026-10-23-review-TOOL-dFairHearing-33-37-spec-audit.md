### M7 — The per-arm step's temp path, log path and orchestrating commit are unguarded (ids 15, 38)

- **Where:** spec 37, section 2 S8 and S12; section 4 The per-arm step.
- **What:** The no-cygpath fallback `c="$TEMP/f<r><a><n>"` has no default. On POSIX hosts `$TEMP` is normally unset (the variable there is TMPDIR), so the path becomes `/f1s1` and `test ! -e` passes. `$SCRATCH` is never checked either, so an unset value sends the log to `/run.log`. S8 makes this README procedure the single source for every later replay, so the defect reaches any non-Windows node in this multi-machine repo.
- **Fix (skeptic: sound):** Spell the fallback as `c="${TEMP:-${TMPDIR:-/tmp}}/f<r><a><n>"`, or open the block with `: "${TEMP:?}" "${SCRATCH:?}"`, and state in S8 which variable the README reads on each platform. - **Gate:** checklist entry: a shell procedure checks every environment variable it builds a path from, and no `$(...)` whose failure matters sits inside an `echo`.
