### H1 — The version-line probe diffs four directories, while the rule it certifies covers every file the build writes (ids 22, 31)

- **Where:** spec 31, section 2 S3; section 4 The check (the `git diff` pathspec and the hits regex); section 6 AC1.
- **What:** The probe diffs only tools/hooks, tools/roles, .claude/skills/build and tools/workflows, using the regex `KIT_[A-Z_]+_VERSION = |gov:kit [a-z-]+@`. The rule it observes is unit 27 S15: "no commit of this build changes the value of an existing version line". That rule covers the whole build, and the build writes version carriers outside those four directories. Unit 16 edits tools/check-wiring.sh (`KIT_CHECK_WIRING_VERSION=1.34   # gov:kit check-wiring@1.34` at :51). Unit 23 edits tools/memory-tree/HYGIENE.template.md (`<!-- gov:kit memory-tree@2.152 -->` at :1). Units 15, 30 and 32 edit gotchas.py in the memory-tree kit. Units 15 and 23 edit coding-governance-agents.template.md, whose `governance-template: v4.4` marker the regex cannot match even inside the scope. The shell form `KIT_X_VERSION=` without spaces is not matched either.
- **Consequence:** A hand bump in any of those files exits 0, and the probe reports "no version line changed" for the whole build. The kit epoch leg pushes builders to bump exactly these kits once their shipped bytes move, so a hand bump is the likely case. It slips through the check that unit 31 exists to make non-vacuous.
- **Fix (skeptic: sound):** Derive the pathspec and the pattern from the version carriers themselves, not from four typed directories. Read every `version_from` in tools/*/kit.toml and tools/govkit/entries/*.kit.toml, and diff each declared file against its own `pattern`, adding `gov:kit [a-z-]+@` for marker comments such as HYGIENE.template.md:1. The simpler alternative is to diff the whole tree, or the union of every unit's Files-touched list, with a pattern that also covers `^KIT_[A-Z_]+_VERSION=` and `governance-template: v`. Add an AC3 sibling: a fixture whose branch rewrites a shell-form `KIT_X_VERSION=1.0` outside the four old directories must print the line and exit 1.
- **Gate:** bug-class checklist entry (instance-list-where-class-meant): a probe that certifies a build-wide rule must take its scope from the build's write set or the carrier manifest, never from a typed directory list.

### H2 — Unit 30's replay has no attempt cap and no rule for which attempt is scored (id 32)

- **Where:** spec 30, section 2 S3, S4, S5; section 5 risks.
- **What:** S3 allows a re-run of any record and arm "for any cause" with no cap, and S5 records every attempt.
