## 1. Goal

The round-4 spec audit's finding id 32 (item H2, HIGH,
`memory/builds/dFairHearing/reviews/2026-10-23-review-TOOL-dFairHearing-28-32-spec-audit.md`) is
closed. `TOOL-dFairHearing-30` S3 allows a re-run of any record and arm for any cause, S5 records every

therefore rest on whichever attempt the runner prefers. The cap and the dead-run rule were written

in unit 30 S9 and here, before the runs (unit 25 §8 F2). This unit takes the scoring
and the decision from unit 30 and scores by one rule written now, before any run: refused attempts
count for nothing, the first completed attempt that is not void is scored, only the first two
completed attempts are eligible, and a record and arm with no eligible attempt ends the replay with no
decision. The choice of attempt then depends on attempt numbers and void reasons alone, never on a
figure.

## 4. Design

### Why a scoring rule and not a run rule

Unit 30's runs happen at order 23 and this unit sits at order 24. A rule that a run must obey, placed
after the run, is the defect id 32 names. A scoring rule placed after the runs is not: it decides only
which attempt is read, and it is written before any run happens, so a runner knows at order 23 that a
re-run of an attempt that was not void is never read. What the rule removes is the choice; what it
does not bound is the agents a needless re-run spends.

### The checker

```python
# attempts.py <record> — unit 15's replay: the scored attempt of each record and arm, by rule
import re, sys
ROW = re.compile(r"^\|\s*([1-4])\s*\|\s*(selected|ungated)\s*\|\s*(\d+)\s*\|\s*(\S+)\s*\|"
                 r"\s*(refused|completed|failed)\s*\|\s*(.*?)\s*\|\s*$")
OPENS = re.compile(r"^\|\s*[1-4]\s*\|\s*(selected|ungated)\s*\|", re.I)
HEADER = re.compile(r"^\|\s*record\s*\|\s*arm\s*\|", re.I)
rows, seen, inside = {}, set(), False
for no, line in enumerate(open(sys.argv[1], encoding="utf-8"), 1):
    if HEADER.match(line):
        inside = True
        continue
    if inside and not line.startswith("|"):
        inside = False
    if not inside or not OPENS.match(line):
        continue
    m = ROW.match(line)
    if not m:
        sys.exit(f"attempts: line {no} opens an attempt row and does not parse: {line.strip()}")
    r, a, n, clone, outcome, void = m.groups()
    if not void:
        sys.exit(f"attempts: line {no} has an empty last cell")
    if (r, a, int(n)) in seen:
        sys.exit(f"attempts: attempt {n} of record {r} {a} is listed twice")
    seen.add((r, a, int(n)))
    rows.setdefault((r, a), []).append((int(n), clone, outcome, void))
pairs = [(r, a) for r in "1234" for a in ("selected", "ungated")]
if sorted(rows) != sorted(pairs):
    sys.exit(f"attempts: {len(rows)} of the 8 record and arm pairs are listed")
capped = []
for key in pairs:
    tries = sorted(rows[key])
    if [t[0] for t in tries] != list(range(1, len(tries) + 1)):
        sys.exit(f"attempts: record {key[0]} {key[1]} does not number its attempts from 1")
    done = [t for t in tries if t[2] in ("completed", "failed")]
    scored = next((t for t in done[:2] if t[2] == "completed" and t[3] == "-"), None)
    if scored:
        print(f"scored {key[0]} {key[1]} {scored[0]} {scored[1]}")
    else:
        capped.append(key)
        print(f"void after cap {key[0]} {key[1]}")
    for t in done:
        if t is not scored and not (t in done[:2] and (t[2] == "failed" or t[3] != "-")):
            print(f"unscored {key[0]} {key[1]} {t[0]}")
sys.exit(3 if capped else 0)
```

The table opens with the header row `| record | arm | attempt | clone | outcome | void |`, and its
rows are `| <record 1-4> | <arm> | <attempt> | <clone> | refused, completed or failed | <void reason
or -> |`. For a refused attempt the last column holds the refusal's reason, and for a `failed` one
what came back instead of a report. The grammar is unit 40 §4's correction (S7), carried here so the
checker that scores is the corrected one. The pass writes the checker with its file-writing tool under
its scratch directory. Measured on 2026-10-23 over a scratch table: a record whose attempts read
refused, void, completed and completed scored attempt 3 and listed 4 `unscored`; with attempt 3 void
as well it printed `void after cap` and exited 3. Measured on 2026-11-03 with this grammar: the same
two tables print the same lines; failed then completed prints `scored 4 selected 2`; failed, failed,
completed prints `void after cap 4 selected` and exits 3; a `Completed` row, a `Selected` row and an
empty last cell each exit 1 naming line 10; a second table's `| 1 | selected |` row is not read.
