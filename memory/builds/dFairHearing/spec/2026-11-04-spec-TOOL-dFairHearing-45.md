### Install-prefix: the render (S2)

`tools/workflows/tier2-review.js` left the render rule when unit 13 added `{{LENS_SLOTS}}`. That token
fills five sites with different lines, and the rule reads a token as one line, the same text at each
repeat. Graded as an ordinary file, the render shows `tools/gate-legs.json` twice,
`tools/memory-tree/gotchas.py` and `tools/gotchas.py`, each a correct render of `{{TOOL_ROOT}}`.

```python
def build_render_rx(src):
    """<src>, a template, as one regex a render of it matches WHOLE: each `{{TOKEN}}` one line of
    any text, a repeated token the same text as its first occurrence, the rest literal. A token
    alone on its line is a BLOCK: any number of whole lines, its own text at each site."""
    out, seen, pos = [], set(), 0
    for m in TOKEN.finditer(src):
        out.append(re.escape(src[pos:m.start()]))
        pos = m.end()
        if src[m.start() - 1:m.start()] in ("", "\n") and src[pos:pos + 1] == "\n":
            out.append(r"(?:[^\n]*\n)*?")
            pos += 1
            continue
        name = m.group(1)
        out.append("(?P=%s)" % name if name in seen else "(?P<%s>[^\n]*?)" % name)
        seen.add(name)
    out.append(re.escape(src[pos:]))
    return re.compile("".join(out))
```

The existing arm, "a token value spanning a newline does not match", stays green: its token sits
inside a line. Four tracked templates hold a block token. The renders of the other three,
