# TOOL-aWindowedPass-6 — acceptance ledger

**Serves:** journal TOOL-aWindowedPass-6

`--check-commit` keeps each dispatch row's tag, open or reopened because its pass commit is HEAD, and
refuses an amend's undeclared path as a committed pass, with no `--dispatch` widening the close would
not honour. The observations are the main loop's, on a slice of `unattended.test.sh` holding its
prologue and the `--check-commit` block, 48 arms at exit 0. A break run followed, with the closed-pass
branch and the subject-only row guard each staged out, and the driver was restored byte-identical
before the pass commit.

  `--dispatch tRun` line; with the closed-pass branch staged out it printed the open-pass refusal and
  its `--dispatch` command.

  0; with the subject-only branch reading reopened rows the records commit exited 1.
