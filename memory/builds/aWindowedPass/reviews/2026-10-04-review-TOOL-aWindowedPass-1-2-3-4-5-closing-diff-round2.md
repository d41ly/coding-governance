## HIGH

### H1. An amend of a pass commit is told to widen its declaration with `--dispatch`, but check 23 does not honour that widening (id 8)

- **Where:** `tools/unattended/unattended.sh:9738` (the M4 `O`-row reopening in `verb_check_commit`).
- **Defect:** Take `git commit --amend` on pass commit P, which is HEAD, where the amend stages an undeclared path y. The amend sees an `O` row, and `--check-commit` prints "the pass has not committed" together with `--dispatch ... --writes x --writes y`. `verb_dispatch` anchors the new row at `rev-parse --short=8 HEAD`, which is P. P is the commit the amend is about to replace. On the retry, the new row is open and covers y, so the amend lands as P'. At the close, P is no longer an ancestor of HEAD. Check 23 therefore skips the new row on the report channel only (`check-unattended.sh:3701`). It then grades the original row against P', and P' writes y outside that row's declaration. If a sibling pass overlaps, that is an undeclared write and the run's own branch fails. The commit-time hook said the repair worked, and the close disagrees about the same commit.
- **Fix:** the finder's fix was **REJECTED** by the skeptic. The skeptic's corrected fix: for an `O` row, refuse without suggesting `--dispatch`. Say that an amend cannot widen a committed pass. Tell the user to drop y from the amend, or to commit it as a new commit carrying `Pass: <unit>` after a fresh `--dispatch` made at the kept pass commit. Add an arm that amends with an undeclared path, follows the printed instruction, and runs check 23 bound to the run.
- **Grade note:** the binding grade is HIGH, from the seams finder and the skeptic, who called it "narrow, so high". Id 4 is the same defect from the correctness lens and is bound at MEDIUM, because the close still catches the write and so the final verdict is not wrong. Under the rubric I would grade this MEDIUM as well, since the consequence is a misleading commit-time forgiveness and not a wrong final result. It is still HIGH under "a defect that will mislead the next change": the hook's own printed repair is the misleading part. The binding grade stands.
- **Left-shift gate:** the arm above, run in an end-to-end fixture of amend, follow the printed repair, then check 23. Pair it with a structural assertion that no refusal message for an `O` row contains the string `--dispatch`.

### M2. Selfcheck 6c grades `[[generated]]` rows through tomllib, but the shell reader is a column-0, double-quote-only awk (ids 6, 9, 13, 23)

Refuse unless it yields exactly tomllib's `[[generated]]` rows, with the same path, generator and when per row. ### L2. The printed `--dispatch` repair splits and globs staged paths, and its quoting has no discriminating arm (ids 3, 12, 20)
