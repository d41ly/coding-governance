#### H1. RANGE mode kills brief-recorded's built-before-its-run exemption (id 7)

- **Defect:** the exemption probe now runs `build_commit "$base $HR_EXCL"`. In RANGE mode `HR_EXCL` is `^<advertised tip>`, and the run's base is always an ancestor of that tip, so the walk is empty and `_pre` is always empty. A unit an earlier landed run built, and that this run repairs without a brief row, reaches `add_violation`.
- **Repro:** run 1 builds unit U with a brief row and lands at T. Run 2 preflights at base T and commits `fix(S): U - ...` touching `tools/` with no brief row for U. Spec 17's inventory row prescribes this token, so the spec carries the same defect.

It is an EXEMPTION that looks behind BASE, and everything behind BASE is on the tip by construction. Keep `^<tip>` only on the in-range walk. The same token in `check-pass-order.sh:412` is harmless and should stay, because that probe detects violations rather than exempting them.
