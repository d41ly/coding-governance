## High

### H1. Under `git blame --porcelain --root`, a grafted commit prints no `boundary` mark, so unit 28's graft refusal never fires (ids 1, 11, 23)

- **Where:** spec-28 §2 S2 and S3, §4 "The join, bounded" (pseudocode line 82), §6 AC3; inherited by spec-29 S42's shared `read_blame_lines`.
- **What is wrong:** S2 runs blame with `--root` and treats a printed `boundary` mark as the sign of a grafted or truncated history. `--root` is exactly what stops git marking a parentless commit as a boundary, and a commit grafted onto no parent is parentless. Reproduced on git 2.54: after `git replace --graft <c2>`, `--root` blame printed no `boundary` line, plain blame printed one, and `--is-shallow-repository` printed `false`. S3's `git diff-tree --root` then lists the graft commit's whole tree as added.
- **Consequence:** In a grafted or replace-truncated history, every suppression row blamed to the graft point is judged against a commit that "adds" the entire tree, so any row whose record exists anywhere passes. That is the wrong green on provenance this unit exists to remove. AC3 (graft fixture expects `history boundary`) cannot pass on a correct build, so the builder either stalls or weakens the criterion.
- **Fix (judged SOUND by the skeptic, all three findings):** Stop relying on the porcelain boundary mark under `--root`. Before trusting a parentless blamed commit, confirm it is a true root with replace objects ignored: it must appear in `git --no-replace-objects rev-list --max-parents=0 HEAD`, and `git replace -l` (and `.git/info/grafts`, `.git/shallow`) must not cover it. Alternatively drop `--root` and accept a boundary only when the commit is a true root. Otherwise red `cannot judge provenance — history boundary`. Restate S2 and rewrite AC3 so the graft fixture is observed red under the shipped command. Carry the same rule into spec-29 S42's `read_blame_lines`.
- **Left-shift gate:** a lexicon selftest arm that builds a `git replace --graft` fixture and requires every history reader that trusts a root (provenance, drift blame) to red on it; plus a bug-class checklist entry "`--root` hides the boundary mark a graft check reads".
