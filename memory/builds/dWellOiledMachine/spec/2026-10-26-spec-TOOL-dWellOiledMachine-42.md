## 1. Goal

`gov-session` hands work to another session as a prose prompt file, a role that acts in no item and
whose prompt no prompt writer frames (the night pass two's contradiction 2). This unit retires it
with an upgrade step: a hand-off to another session becomes an `intake` message, or a unit offered at
placement, and the receiving session's prompt writer renders the work order the prose prompt was.
Its readers are inventoried by value and each re-pointed in the same unit, and a planted leftover
reference to its agent file is seen red (the owner's NT-21).

### A hand-off, before and after

| Before | After |
|---|---|
| `handoff.py render --role gov-session --build <slug> --input question=<f>` writes a prose prompt under `prompts/` | `handoff.py send --to <target> --build <slug> --input question=<f>` posts an `intake` message |
| the receiving session reads the prose prompt | the receiving driver frames the message through `gov-prompt-writer`, and the work order is rendered |
| a unit's work is described in prose | `unit_holder.py offer <slug> <unit> --to <target>` |
