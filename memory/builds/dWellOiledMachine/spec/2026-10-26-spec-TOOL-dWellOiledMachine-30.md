## 1. Goal

No role could run an experiment that writes, and the one experiment-shaped harness gov ships runs
unbound and hands its record back unwritten (`tools/workflows/orient-counterfactual.js:15-20`; night
pass `[p2-testing]`). The night pass gives Runtime "act binding for an experiment's acts" and Memory
"an experiment's shape-run rows" (night-pass instruments :685). This unit binds an experiment act to
its frozen corpus, variants and reruns through the shape digest, reconciles each variant run the act
started against that table, writes one shape-run row per variant and level it ran, and hands the
rows' rerun counts to the experiment kind's harness, so a re-launched experiment runs only the reruns
still owed (dBoundRoles-16 S4: `reruns` keyed by variant and effort).

## 2. Scope (IN)

- **S1** — The experiment's shape. For a workflow entry whose `kind` is `experiment`
  (TOOL-dBoundRoles-16 S2, S4), `derive_shape_digest` (TOOL-dWellOiledMachine-19 S1) adds a fourth
  part, `experiment`, holding the blob id of the cases file at HEAD and the table's `fan`, `reruns`
  and `variants`, from the entry's `[workflow.experiment]` table, so the frozen corpus, the
  variants and the reruns are bound into the act's `shape`. Observed by AC1.
- **S2** — The rerun counts. `measure_experiment_runs(root, build, workflow)` in
  `tools/runtime/shape.py` returns `{"<variant>.<level>": n}`, each `n` the sum of `Rerun` over the
  build's tracked act-form shape-run records whose `Workflow` is the entry and whose `Variant` and
  `Effort` name the key (S4). `write_named_call` (TOOL-dWellOiledMachine-7 S1) adds them to the args it
  returns as `done` for an experiment act, so they are inside `args-sha` and the call is bound to them.
  A table whose every key is spent makes `write_named_call` refuse, exit 3,
  `experiment — <workflow> · reruns spent`, and no act is launched. Observed by AC2.
- **S3** — Read at the experiment kind's harness. The contract of `point.role-harnesses`
  (TOOL-dWellOiledMachine-19 S3) gains, for a harness an `experiment` entry names: it reads `args.done`
  and starts at most `reruns[key] - done[key]` runs of each key, and labels each `agent()` call
  `<variant>.<level>#<n>`, `<n>` counting from `done[key] + 1`. `check_role_harness_rows` reds an
  experiment harness row with no `labels = "variant.level#n"` field. Observed by AC3.
- **S4** — The reconcile against the table. For an experiment act, the reconcile
  (TOOL-dWellOiledMachine-7 S7, -19 S5) reads each started agent's label through `load_run_journal`
  (`tools/roles/handoff.py:686`) and its effort through `load_agent_transcript` (`:626`), and answers
  `void` for an agent whose label does not parse, whose variant is not in `variants`, whose
  `<variant>.<level>` is no `reruns` key, whose effort is not `<level>`, or whose `<n>` exceeds the
  key's `reruns`; and for a cases file whose blob at the act's end differs from the named one, a moved
  corpus. Under `roles.shape-enforce` `record` the act stands and the row names what differs.
  Observed by AC4.
- **S5** — The rows. The reconcile's last step for an experiment act writes, through `shape.py row`,
  one act-form shape-run record per `<variant>.<level>` the run started (§8 F2 of
  TOOL-dWellOiledMachine-19): `Kind` `act`, `Workflow`, `Shape`, `Shape-match`, `Variant`, `Effort`
  (the level), `Rerun` (the runs of that key this act started), `Agents`, `Out-tokens` (those agents'
  `tokens`) and `Caused-by` (the act id). The next act's `done` is their sum. Observed by AC5.
- **S6** — `help/runtime.md` gains the experiment act: the bound corpus, `done`, the label grammar and
  the rows. Observed by AC6.

## 4. Design

### Evidence

- `[workflow.experiment]` holds `cases`, `variants`, `fan`, exactly one of `scorer` and `judge`, and
  `reruns` keyed `<variant>.<level>` (TOOL-dBoundRoles-16 §4 "The experiment"); gov ships no entry of
  the kind.
- `orient-counterfactual.js` returns its record and writes nothing (`:15-20`), and runs its two
  kickoffs as the loop shape `agent-cap.js` admits (`:9-13`).
- A Workflow run's `journal.jsonl` names each agent's `label`, and its transcript its effort (measured
  on this node on 2026-10-26, run `wf_7c0507f0-43d`; `tools/roles/handoff.py:626-640`).

### Worked

A table `variants = ["base", "house-index"]`, `reruns = {"base.medium" = 3, "house-index.medium" = 3}`,
`fan = 4`. The first act has `done = {}` and starts six runs, `base.medium#1` to `#3` and
`house-index.medium#1` to `#3`; killed after four returned, its rows read `Rerun` 2 and 2. The second
act has `done = {"base.medium": 2, "house-index.medium": 2}` and starts `#3` of each. Illustrative, not
measured.

### Alternatives rejected

- **One act per variant run.** A fan of `n` would launch `n` act sessions where the kind's harness
  already bounds the fan inside one call (dBoundRoles-16 §4).
- **The harness counting its own earlier runs.** A workflow script reads no file, so the counts reach
  it only as args.

## 5. Production-readiness checklist

- security — no new write path: the rows go through the door; a moved corpus voids the act.
- perf / scale — one `git ls-files` over the build's `build/` folder per experiment launch.
- error / empty / loading states — no rows reads `done = {}`; every key spent launches nothing, named.
- observability — the reconcile names each label, effort or blob that differs; each row carries
  `Shape-match`.
- risks — a harness that labels runs another way is voided by S4, so an experiment harness written
  before this unit cannot run as an act until it adopts S3's label grammar.
- testing — the fixture cases of §6 and the arm of §7.
- migration — none: gov ships no experiment entry.
- user docs — `help/runtime.md`.

## 6. Acceptance criteria

The fixture is `python shape.py --fixture --plant <case>`: a scratch copy of `tools/roles/` whose
`workflows.toml` adds an `experiment` entry with the worked table and a stub harness, a tracked cases
file, and act-form rows planted under a scratch build folder.

- **AC1** — When `--plant experiment-digest` computes the entry's shape, then edits one line of the
  cases file, the digest changes; with `reruns` changed, it changes again.
  Red when: the digest leaves the experiment table out.
- **AC2** — When `--plant done` plants rows of `Rerun` 2 for `base.medium`, the named call's args carry
  `done` `{"base.medium": 2}` and its `args-sha` differs from the same call with `done` empty; with
  rows of `Rerun` 3 for both keys, `write_named_call` exits 3 naming `reruns spent`.
  Red when: a spent experiment launches, or `done` is outside the hash.
- **AC3** — When `python shape.py --check-rows` runs over a scratch experiment harness row with no
  `labels` field, it exits 1 naming the row.
  Red when: the row passes.
- **AC4** — When `--plant reconcile-experiment` plants a run with `base.medium#3` at `done` 2 it prints
  `clean`; a `base.medium#4`, a `base.high#1`, an agent labelled `base.medium#1` at effort `high`, and a
  cases blob changed before the end each print `void` naming the cause.
  Red when: a run past its reruns or over a moved corpus leaves the witness standing.
- **AC5** — When `--plant rows` reconciles a clean run of two `base.medium` and one
  `house-index.medium` agents, the stubbed door receives two `new shape-run --act` calls with `Rerun`
  2 and 1 and the right `Variant` and `Effort`; `measure_experiment_runs` over them returns those counts.
  Red when: one row is written per act instead of per key, or the counts do not round-trip.
- **AC6** — When `grep -n "experiment" runtime.md` runs over the help page, the bound corpus and `done`
  are named.
  Red when: the page omits the experiment act.
