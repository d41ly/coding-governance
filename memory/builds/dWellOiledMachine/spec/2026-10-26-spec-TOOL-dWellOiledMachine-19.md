## 1. Goal

The spawn guard admits any agent-true role in any stage at any effort (gap-rt-21): `checkHarnessCall`
holds `args.roles` to a non-empty object of agent-true roles and reads no stage, effort or fan
(`tools/hooks/agent-cap.js:1735-1760`). This unit binds an act's Workflow call to the digest of its
workflow's resolved shape, refusing or recording a call whose roles, efforts or fan differ as
`roles.shape-enforce` says, reconciles the agents the run started against the same shape, and writes a
shape-run row for every non-review act, the half of the shape-run kind whose other writer is the review
harness's own line (systems `[design-role-shapes]`, Binding and The metric).

## 2. Scope (IN)

- **S1** — The shape digest (I26, refined here as its owner). `derive_shape_digest(harness, workflow)`
  in `tools/roles/handoff.py`, printed by `python handoff.py shape-digest <harness> <workflow>`: the
  first 12 hex of the SHA-256, `derive_section_sha`'s rule (`:307`), of the compact sorted JSON
  `{"efforts": E, "fan": F, "roles": R}`, where `R` is the map `harness-args <harness>` prints
  (`print_harness_args`, `:453`), `E` the map `stage-efforts <workflow>` prints (`print_stage_efforts`,
  `:474`), and `F` each stage key's `fan` from the workflow's stage rows (TOOL-dBoundRoles-22 S1).
  The token `shape-digest` names both the verb and the value. Observed by AC1.
- **S2** — The named call carries the shape. `write_named_call` (TOOL-dWellOiledMachine-7 S1) adds
  `shape`, S1's digest, and `shape-parts`, its JSON, for a `Workflow` act. Observed by AC1.
- **S3** — `point.role-harnesses` (`[extend]`'s role-harness point). Its `[[point]]` row in
  `tools/runtime/points.toml`: purpose "a harness script a role act calls, with the most agents it
  spawns at each stage", contract this item. One `[[adapter]]` row per harness script
  `tools/roles/workflows.toml` names, three at this base: `tier2-review`, `unattended-build` and
  `unattended-unit`, each with `script` (its path from the kit root), `fan` (a map of stage key to the
  integer its script spawns at most), and a `grant` whose `service` is `local`, `scopes` empty and `secret` `anonymous`,
  `tenancy = "local"`, `retention = "none"`, `region = "local"` (I4,
  TOOL-dWellOiledMachine-17 S1). `check_role_harness_rows()` in the new `tools/runtime/shape.py`,
  run as `python shape.py --check-rows`, reds a declared harness with no row, a row naming no declared
  harness, and a row whose `fan` differs from a stage row's default `fan` for the same key, the stage
  rows read through the roles verb TOOL-dWellOiledMachine-43 §8 F3 asks dBoundRoles for, run as a
  bounded subprocess, never `load_workflows` in process, since `shape.py` is the runtime kit's and a
  kit imports no sibling kit (PLAY-dOrderedCharter-7, oc7:202-205). Observed by AC2.
- **S4** — The call compared with the shape. After TOOL-dWellOiledMachine-7 S4's fourth rule matches
  the named call, `resolveActCall` hashes the call's `args.roles`, `args.efforts` and its harness row's
  `fan` by S1's rule. A digest equal to `shape` admits. A different one, under `roles.shape-enforce`
  (`tools/policy/catalogue.toml:1380`, `refuse` or `record`, default `refuse`), read by spawning
  `node <policy kit>/policy-mirror.js get roles.shape-enforce --repo <repo>`, `node` being
  `process.execPath`, under a bounded timeout; `act-binding.js` never `require`s the policy kit's
  module (TOOL-dKeptSession-8 S5) and finds `policy-mirror.js` in the policy kit beside its own kit by
  path join, as TOOL-dWellOiledMachine-10 S6's dispatcher does. A `get` that exits non-zero, times out
  or fails to spawn, or no helper found, reads `refuse`, the default. `refuse` denies with
  `BLOCKED by act-binding: shape · <act> · <roles|efforts|fan> differ`, naming each part that differs; `record`
  admits and writes `<act>.shape-mismatch.json` beside the named call, naming the parts. Observed by
  AC3, AC4.
- **S5** — The run reconciled against the shape. TOOL-dWellOiledMachine-7 S7's reconcile gains, for an
  act whose named call carries `shape`: each agent's `effort`, as the roles kit's
  `load_agent_transcript` (`tools/roles/handoff.py:626`) reads it, reached through the roles-kit verb
  TOOL-dWellOiledMachine-30 §8 F3 asks dBoundRoles for (`handoff.py agents --run <run-id> --session
  <file> --json`), run as a bounded subprocess found through the inline `resolve_kit_dir` block and
  never imported, since a kit imports no sibling kit (TOOL-dOrderedCharter-7, `:202-205`). A refused
  read, or no roles kit found, answers `void`, naming it, under either value of `roles.shape-enforce`,
  since nothing was compared. The effort must be the level `E` gives a stage whose role is the agent's type,
  and a role's agents must not outnumber the sum of `F` over its stages. A difference prints
  `reconcile — <act> · shape <part> differs`; under `refuse` it voids the witness as S7 does, under
  `record` it stands and is carried by S6's row. Observed by AC5.
- **S6** — Each non-review act's shape-run row. A non-review act is one whose workflow's `kind`
  (TOOL-dBoundRoles-16 S1) is not `panel`, the kind whose harness writes the `review-shape` line

  `python shape.py row <act>`, which calls `gov_record.py new shape-run --act <act>` with `Kind` `act`, `Workflow`, `Shape`,

  agents' `tokens`, from S5's read through the same verb) and `Caused-by` (the act id, I15). The act form is an ask to dTotalRecall

  Observed by AC6.
- **S7** — `help/runtime.md` gains the shape digest, `roles.shape-enforce`'s two values, the
  role-harness rows and the shape-run row. Observed by AC7.

## 4. Design

### Evidence

- A harness call carries `roles` from `harness-args` and `efforts` from `stage-efforts`
  (`tools/roles/SKILL.template.md:66-67`); both print sorted compact JSON (`handoff.py:453-488`).
- No call carries a fan: each harness spawns to a literal, `MAX_VERIFIERS = 5`
  (`tools/workflows/tier2-review.template.js:1354`), its lens list (`:842`) and `SPEC_WRITERS`
  (`tools/workflows/unattended-build.template.js:942`), which TOOL-dBoundRoles-16 §3 leaves pinned
  until the role-harness point binds them.
- A Workflow agent's `effort` is read from its transcript by `load_agent_transcript`
  (`tools/roles/handoff.py:626-640`), and its type from `.meta.json` (measured on this node on
  2026-10-26, run `wf_7c0507f0-43d`).
- TOOL-dTotalRecall-11's kind holds review fields only: `Kind` is `diff-review` or `spec-audit`, and
  `Round`, `Intensity` and `At` are required (its §4 "The grammar", "The row").
