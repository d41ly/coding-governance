## 1. Goal

Attendance changes the driver today: an attended `/build` drives the build harness from the owner's
session and loses five of the driver's checks (`tools/workflows/unattended-build.js:49-61`), and a
model session decides every next act (gap-rt-22, gap-rt-01). The night pass makes the supervisor the
driver in every mode, the owner's session its client; that session hosts the driver only before this
build lands or if the platform spike fails, under its owner binding, each role act it hosts bound to
that act's epoch
(`memory/builds/dClosedLoop/build/2026-10-18-build-PLAY-dClosedLoop-1-night-pass.md:91-95`). This unit
ships `run <build>`, which takes the build lease and hands the build to the node's supervisor,
following it as a client; derives from the spike's measured rows whether the supervisor can drive, and
otherwise hosts the driver in the session with every hosted act bound; holds one driver per build;
declares the actor kinds the supervisor alone handles; and reduces `/build` to a client of `run` in
the same unit.
