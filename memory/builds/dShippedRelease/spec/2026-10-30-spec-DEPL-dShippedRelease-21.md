## 1. Goal

A project map cannot say what a kit is for, because no descriptor carries a purpose, and two tool
directories have no descriptor at all: `tools/lib` and `tools/govkit`, each a registry `[[exempt]]`
row. This unit gives the kit factory its `purpose` field, reviews today's kits into it, writes a
`kit.toml` for both directories marked not installable, and has every reader of a descriptor name
how it treats one. It also closes `gap-tool-04`: lib's descriptor declares the inline primitives, and
`regen.py` generates each copy instead of a test comparing hand-kept ones.

### Alternatives rejected

- **Both stay `[[exempt]]`, each with an unregistered descriptor.** Tested against the consumers
  table: `check-hook-destinations.sh` and `render_playbook.py` read the registry, so neither would
  ever meet one and "each consumer's leg" would run over nothing for those two, an empty population.
- **A new `selectable` value.** `:908` tests inequality with `conditional`, so the value reads as
  selectable until each site is changed: fail-open by construction.
- **Generating copies in govkit's copy-install.** Rejected: the copies are tracked and graded in gov
  today, and research-distribution-b's "in-tree by a regen stage, tracked and drift-gated" is the form
  the design chose (layer-expansions:119).

## 5. Production-readiness checklist

- security — no new surface; `inline_blocks.py --write` rewrites only between a row's markers in a
  tracked file, and no argv comes from a descriptor it did not read from the tree.
- perf / scale — `--check` is one `git grep` per stem over tracked files, the cost of the parity arm
  it replaces, moved into the bar's regen stage.
- error / empty / loading states — a stem with no copy and a canonical with no block each refuse.
- observability — `--check` names the drifted file and block ordinal; `regen.py --list` names the row.
- risks — a canonical edit landed without `--write` is rewritten by the lander's regen after the mint
  (`tools/push-main.sh:902`, `:911`), moving a kit's shipped bytes undated; the version check reds at
  the push, the same class every rendered file already has, and `--check`'s remedy line names
  `--write` so a branch does it first.
- testing — the plants of §6 and the arms of §7.
- migration — none for an adopter beyond two refused rows.
- user docs — `help/kits.md`.
