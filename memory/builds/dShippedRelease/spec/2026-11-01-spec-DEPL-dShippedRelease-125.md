## 4. Design

### Why one unit and not two

M4 admits two batches only when the minors split into two disjoint write sets by M6. They do not. A loop
half and a deployer half both write `tools/gate-legs.json` (S37, S38), and moving S38 to the deployer half
makes both write `tools/loop/kit.toml`'s rows (S21, S38), which fails clause 1. With every leg row in the
loop half, the deployer half writes `tools/integrations/kit.toml` (S1, S25), a generator input
`leg_factory.py --write` reads, which fails clause 2. The batch builds after every other unit, so a second
unit buys no concurrency.

### What an order-34 batch cannot reach

S19 needs a verb at order 11, and M4 forbids a fold, so unit 59's and unit 69's §3 edges carry the mint and
this item observes it. S13, S23 and S28 carry the same note on their units' edges, for the same reason.
Every other item is a repair of built code at this pass, and the builder re-reads it against source.
