## 4. Design

### Why one unit and not two

M4 admits two batches only when the minors split into two disjoint write sets by M6. The natural cut puts ids 8, 15,
16, 17's moved cases, 19, 20, 24, 25, 31, 32, 48, 49, 50 and 51 on `tools/govkit/matrix.py`, `tools/govkit/govkit.py`,
`tools/govkit/registry.toml`, `tools/gate-legs.json` and `tools/push-main.test.sh`, and every other id on `tools/loop/`,
`tools/integrations/release.py` and `help/`. It passes clause 1 and fails clause 2. `build_mint_clone` overlays every
modified path under the install prefix, and `mint` walks every descriptor, so the second half's writes are the first
half's acceptance input, and a half-written kit moves the very lines the arm reads. Ids 1, 2, 18, 30 and 51 write the
manifest the second half's kit is graded against, so no other cut serves either. The batch builds last, so a second
unit buys little.
