## 1. Goal

`TOOL-aEvidencedLens-3` S3 puts each spec finding's `evidence` on its skeptic line, folded "by the
existing `renderCell`", and tells the skeptic to RE-RUN the command it names. The round-1 spec audit
confirmed finding 36 at HIGH: `renderCell` (`tools/workflows/tier2-review.template.js:1061-1063`)
folds line breaks AND rewrites every `|` to `\|`, because it was built for a markdown table cell. An
evidence command such as `git ls-files | grep x` reaches the skeptic as `git ls-files \| grep x`,
which prints something else when run as written. Refutation case (3) then refutes a TRUE finding as
evidence that does not reproduce. This unit folds evidence with a line-break-only fold, so the
skeptic reads the command byte for byte, and proves it with a pipe-bearing case. It closes finding
36 (HIGH) of the round-1 spec audit.

## 4. Design

### Evidence

Read at `b3950dc7` on 2026-10-05, whose `tools/` tree equals BASE `028b5cac`:
`git diff --stat 028b5cac b3950dc7 -- tools/` prints nothing. Line numbers are PINNED to that read
and move as units 1 to 3 land first; the identifiers do not.

- `renderCell` at `:1061-1063` returns `-` for an absent value, else
  `String(v).replace(/[\r\n\x0b\x0c\x1c-\x1e\x85\u2028\u2029]+/g, ' ').replace(/\|/g, '\\|')`. Its
  comment says it exists so "no claim or reason can forge or cut a row in the table".
- Its only caller at BASE is `renderAppendix` (`:1069`). Unit 3 would make the skeptic line its
  second caller.
- The finder's evidence form is "the command you ran and what it printed" (`TOOL-aEvidencedLens-2`
  §4 "The finding line and the schema"), so a pipeline is an expected value, not an edge case.

### The fold

```js
function renderPromptLine(v) {
  if (v === null || v === undefined) return '-'
  const s = String(v).replace(/[\r\n\x0b\x0c\x1c-\x1e\x85\u2028\u2029]+/g, ' ')
  return s.trim() === '' ? '-' : s
}
function renderCell(v) {
  return renderPromptLine(v).replace(/\|/g, '\\|')
}
```

`renderCell`'s output is unchanged for every input but one class: the absent case returns `-`,
which carries no pipe, and every non-blank value takes the same two replaces in the same order. A
BLANK value, one whose folded form trims to nothing, moves from blank or spaces to `-`. That is
deliberate: a whitespace-only appendix cell said nothing, and `review_replay.py` strips cells
(`:105`, `:150`), so it reads `-` where it read an empty string. No diff-kind arg set the
comparison of AC2 runs carries a blank field, so AC2 is unaffected.

- **Unescaping `\|` in the skeptic prompt's instructions.** It asks every skeptic to undo an
  encoding nobody needed, and a skeptic that forgets runs the wrong command.
- **A sibling one-liner beside `renderCell` that repeats its character class.** Two spellings of one
  line-break class drift; deriving `renderCell` from the new function keeps one.
- **Folding the fix in unit 3's spec.** The finding is HIGH, and the method promotes a HIGH to a unit
  whose mechanism closes it rather than folding it as text.
