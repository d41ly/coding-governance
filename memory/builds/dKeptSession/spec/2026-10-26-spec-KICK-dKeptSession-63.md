### The ack chain

```
--mail ack <slug> a a b c        tip T at depth n; one read, a and b open, c acked
  dedupe -> a b c; skip c        stderr: mail — already acked c
  check a, check b               -> any refusal: exit 2, nothing built
  write_mail_ref <ref> T <ack a, seq n+1> <ack b, seq n+2>
    c_a := build_gov_commit T   <ack a>
    c_b := build_gov_commit c_a <ack b>
    write_gov_ref <ref> T c_b c_a  -> rc 0: feed c_a, then c_b; rc 1 or 2: nothing
```
