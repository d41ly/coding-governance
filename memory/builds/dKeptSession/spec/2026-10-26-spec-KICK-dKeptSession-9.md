## 1. Goal

Each session's and agent's calls and tokens before its first item action are reported per stage of
its build, derived from the transcripts the node already holds, and the report is held as
`orient.budget` says: `record-only` reports and warns nothing, `warn-at-evidence-ceiling` warns on a
row past a ceiling derived from the recorded population, and `owner-ceiling` warns past the owner's
own cap. Strict's value is `warn-at-evidence-ceiling` (v2:1503), so a strict-named repository sees the
warn (orientation OR-8; the whole-design audit's C2-F11; gap-orient-06).

## 2. Scope (IN)

- **S1** — The measurement, `measure_orient_tree(root, repo, slug)` in `tools/runlog/extract.py`, beside
  `measure_ready_tree` (`tools/runlog/extract.py:1204`). Its population is the sessions the two
  attributions `extract` already offers name for `<slug>`: `scan_preflights` (`:991`, heuristic) and
  `read_session_ids` (`:972`, driver), each row carrying its attribution. Per session it reads the
  main file and each agent file of `build_session_tree` (`:238`) as one row each. Observed by AC1.
- **S2** — The row: `sid`, `source` (`main` or the agent file's stem), `stage`, `action` (the class of
  the first tool event of class `edit`, `write` or `git-commit`, or `none`), `calls` (tool events before
  it), `tokens` (the sum of `in`, `out`, `cache_read` and `cache_write` over usage events before it) and
  `context` (`derive_context_fill(ev)` of the last main-source usage event before it, exported beside
  `measure_context_fill` by KICK-dKeptSession-14's I13).
  A row whose action is `none` is reported and never joins a ceiling's population. Observed by AC1.
- **S3** — The stage: the step tag (`step.plan` to `step.deploy`, TOOL-dDeclaredLoop-1 S2) whose
  `state` the build entered at the newest transition at or before the session's first timed record,
  read through TOOL-dDeclaredLoop-3 S7's `read_transitions(build, repo)` and TOOL-dDeclaredLoop-1 S3's
  `read_steps(kit_dir)`; `none` when no transition precedes it. Observed by AC2.
- **S4** — The hold, `orient.budget` read once per run through the Python reader of I8,
  `python <prefix>/policy/policy.py get orient.budget` run in `repo`, the catalogue default
  `record-only` with one NOTE when the reader refuses or is absent:
  - `record-only` prints the rows and the per-stage quartiles and warns nothing;
  - `warn-at-evidence-ceiling` also prints one `orient WARN` line per row whose `calls` exceed its
    stage's evidence ceiling (S5);
  - `owner-ceiling` prints one per row whose `calls` exceed the cap `budgets.orient-calls` (S6).
  The report exits 0 under every value; the one exception is S6's cap when `budgets.enforce` or
  `budgets.pinned` makes it refuse, where a breach prints `orient REFUSED` and exits 1.
  Observed by AC3, AC4, AC5.
- **S5** — The evidence ceiling: per stage, the nearest-rank 90th percentile of `calls` over that
  stage's rows with an action, the research's percentile rule
  (`research-orientation-cost.md` §3), DERIVED at every run. A stage with fewer than
  `ORIENT_CEILING_FLOOR` (20) such rows has no ceiling and prints
  `orient — no ceiling · <stage> · n=<k> under 20`, warning nothing. Observed by AC3, AC6.
- **S6** — The owner's number: a `[[cap]]` row `orient-calls` in TOOL-dGroundRules-9 S1's census
  `tools/policy/caps.toml` (class `switch`, unit `count`, enforcer `{prefix}/runlog/runlog.py`, home
  `constant:{prefix}/runlog/runlog.py:ORIENT_OWNER_CALLS`, `family` false), resolved through that
  unit's `python <prefix>/policy/budgets.py resolve orient-calls=default:0` and judged by its
  `check_cap`, so `budgets.enforce` decides whether a breach warns or refuses there as for every cap.
  `ORIENT_OWNER_CALLS` is 0, and a resolved 0 means no owner number: `owner-ceiling` then prints one
  NOTE naming `budgets.orient-calls` and reads as `record-only`. Observed by AC5.
- **S7** — The verb, `python tools/runlog/runlog.py extract --orient <projects dir> --slug <slug>
  [--repo <dir>]`, writing nothing, one of `extract`'s modes beside `--ready`; a projects dir with no
  session for the slug is `runlog: orient DEAD PROBE`, exit 2, as `--ready` does (`runlog.py:220`).
  Observed by AC1, AC6.
- **S8** — The documentation: `tools/runlog/README.md` gains `--orient` beside `--ready`
  (`tools/runlog/README.md:194`), the row, the three values and what the measurement cannot see.
  Observed by AC7.
