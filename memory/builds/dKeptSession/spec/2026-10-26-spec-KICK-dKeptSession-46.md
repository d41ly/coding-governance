## 4. Design

### Evidence

- `build_arm_env(base)` copies `os.environ` and aims every `DECOY_VARS` root at the arm's scratch
  (`tools/runlog/selftest.py#build_arm_env`, `tools/runlog/selftest.py#DECOY_VARS`), so a reader that
  resolves its own root inside an arm reads that scratch, never the arm's fixture.
- `runlog.py`'s transcript verbs each resolve `resolve_projects_root(override=args.transcripts)` once
  per call and pass the root down (`tools/runlog/runlog.py#cmd_prose`,
  `tools/runlog/runlog.py#cmd_narration`): a reader takes a root it was given, never one of its own.
- Units 14, 30 and 9 landed at orders 12 and 13. A `git grep` of `derive_context_fill(` over `tools/`,
  `skills/` and `help/` at the run's tree of 2026-11-22 finds its definition and three callers
  (DERIVED): `tools/runlog/extract.py#measure_context_fill` and
  `tools/runlog/extract.py#measure_orient_tree`, each passing a window by position, and the liveness
  check of `tools/runlog/selftest.py#test_extract_context_fill`, passing neither, which would raise
  under S1. S1 and S2 rewrite all three. No page under `help/` names it; the `context` paragraph of
  `tools/runlog/README.md` names `derive_context_fill(ev, window=None)` and its default-root fallback.
- `measure_orient_tree` derives each model's window once per run into a dict and divides each row's
  last main usage by it (`tools/runlog/extract.py#measure_orient_tree`), so S2 gives that call a root
  and leaves its count to `KICK-dKeptSession-56`.
- `_build_events` appends usage events after every other kind and sorts by `t` alone, a stable sort
  (`tools/runlog/extract.py#_build_events`): a usage sorts after the tool event of its own record,
  and the store's tool-use records carry a `usage` (`tools/runlog/fixtures/transcripts.json`), so
  a fixture's edit record holding one would become the transcript's last main usage.
- Unit 9's arm (`tools/runlog/selftest.py#test_extract_orient`) pins `context=30%`. Its sessions'
  requests read 60010 of context each (DERIVED, `tools/runlog/selftest.py#build_orient_transcript`),
  so its `--orient` dir and the arm's empty scratch both derive the 200000 rung and S2 moves no share
  it pins.
- No import is added: `record.py`, which the `policy fixtures` leg's runlog-record plant imports,
  imports `extract` at module level (`tools/runlog/record.py`).
