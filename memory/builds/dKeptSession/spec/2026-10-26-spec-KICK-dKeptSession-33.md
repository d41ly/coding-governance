## 1. Goal

The round-1 spec audit of this build's spec set
(`memory/builds/dKeptSession/reviews/2026-10-26-review-KICK-dKeptSession-1-spec-audit.md`)
confirmed finding **id 17 at HIGH**, report item **H2**. Id 2 is the same defect, found by the
coherence lens, and shares the item; it is promoted as `KICK-dKeptSession-34`. The two units split
the item's one fix: this unit is the store's rule, and unit 34 is the reader's answer for a row the
store leaves unassigned.

Eight presettable rows have a derived default, and v2's preset table spells their cells as prose
such as "the role's effort", which `check_value` refuses. `KICK-dKeptSession-1` at its rev-5 leaves
every row whose default is derived out of its completeness and standard-equals-default rules and
seeds no cell on one, so its store is green alone. This unit names the eight rows and gives the
store its rule for them: unassigned where v2 restates the default, literal where a preset differs.
It builds one step after unit 1 (order 2).

## 2. Scope (IN)

- **S1** — id 17. The eight rows, named: `roles.effort.<role>`, `roles.effort.<workflow>.<stage>`,
  `roles.effort.default`, `roles.model.<role>.<harness>`, `maintain.fixes`, `review.<stage>`,
  `review.<stage>.effort` and `budgets.*`, each a catalogue row whose `default` is a
  `{derived = …}` table and which the store's `never` list does not name. The class is computed,
  never typed: `derive_derived_rows(rows, never)` in `tools/policy/presets.py` returns the rows
  `check_derived` flags (`tools/policy/policy.py#check_derived`) less those `never` names. Observed by
  AC1.
- **S2** — id 17. Unassigned where v2 restates the default. A row whose v2 cell is the same prose in
  all four presets, restating its derived default, is assigned in no preset:
  `roles.effort.<role>`, `roles.effort.<workflow>.<stage>`, `roles.effort.default`,
  `roles.model.<role>.<harness>`, `review.<stage>.effort` and `budgets.*`. `review.<stage>` is a
  pattern row whose concrete keys `review.design` and `review.build` carry literal cells, so the
  store assigns those two keys in every preset, as v2 spells them, and never the pattern. Observed by
  AC1 and AC2.
- **S3** — id 17. Literal where a preset differs. `maintain.fixes` is the one derived row whose
  presets differ: each preset assigns a literal set `check_value` admits, the catalogue default's six
  named fixes, split on `, `, for `velocity`, `standard` and `guarded`, and `["reap", "regenerate
  stale"]` for `strict`. Observed by AC3.
- **S4** — id 17. The check. `check_presets` brings `maintain.fixes` back into the completeness rule,
  and judges its `standard` value against its default's named members. It refuses any S2 row a preset
  assigns, and a string value, or a set member, equal to a derived row's `derived` text. `presets.py
  check` prints the unassigned count beside the assigned one, both derived from that rule. Observed
  by AC1, AC2 and AC3.
