**Where specs and source disagree, and gaps that matter to this group:**

2. **cl-0504 against dPlacedRequest-1 S8.** Under `progress`, only a `Gov-Transition` commit is a witness. A declared wait writes no transition, so the lease stops renewing and lapses at `leases.expiry-hours` (24 h) before `flow.wait-ceiling` (72 h). cl-0504 requires the wait itself to renew. The witness set needs a "declared wait on an open `question`" member, filed as an ask in dPlacedRequest's `BACKLOG.md`. Otherwise the clause's own red case ("lease lapses while it waits") cannot turn green.
3. **The cross-ref duplicate race.** Per-ref CAS cannot stop two sessions posting the same id to two different refs at the same moment. The reader must collapse duplicate ids, keeping the earliest sighting, as well as the writer refusing them.
4. **The census does not cover every write.** dPlacedRequest-13 S9 inspects only `--force-with-lease` lines, so a planted plain `git push … refs/gov/mail/…` escapes it. KICK-23's red case has to plant the force-with-lease shape, or ask for a wider census.
