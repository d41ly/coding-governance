## 4. Design

### The glob rows, after this unit

```
rows    := unit 54 S1's resolved `govkit selftest` rows of legs
globs   := [g for g in rows.guard if cst.GLOB_MAGIC.search(g)]          S1
print "guard coverage: <n> path(s) required, <m> uncovered, <u> unevaluated"   S3 (u = len(globs))
for g in globs: print "guard coverage: unevaluated <g>"                  S2
```

  not evaluate the row, and stops there.
