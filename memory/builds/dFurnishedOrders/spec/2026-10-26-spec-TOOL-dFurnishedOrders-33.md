### Why a turn still counts when the posture cannot be read

An owner turn after the run's start is presence the run can see, whatever the posture says; reading
away over it would decide a fork for an owner who just typed. The posture only adds presence the
owner declared without typing, so when it cannot be read the run falls back to the turns alone.
