## 1. Goal

Every document an agent loads is composed from gov's units and the repository's, in one place: the
repository's level-0 units as the charter's project block and its level-3 to level-5 units in a marked
part of their documents, every unit counted against its budget, nothing truncated, every harness file
rendered from the same composition, and an update that says what became of each gov unit. Gov's own
rules leave the set it ships, by a census of today's practices. Today the repository's rules render
inside the charter's one block (`[charter] adopter_rules`, `.governance/deploy.toml:59-70`, through
`read_charter_table`, `tools/playbook/render_playbook.py:809`), the Codex limit is only announced
(`print_size_note`, `tools/agent-instructions/adopt-agent-instructions.sh:64-68`), a copy-mode alias
goes stale (`:138`), and an adopter's seeded template is graded `reseed-available` and never moves
(`tools/govkit/govkit.py:9989-9990`). It closes `gap-found-19`, `gap-found-30` and `gap-found-31` with
units 31 and 32.

## 4. Design

### The composition, in the renderer

`render()` (`tools/playbook/render_playbook.py:979-1051`) gains one composition step per document after
gov's text is resolved:

1. Read the overlay's units through unit 32's reader, keep those whose `select` and `when` hold.
2. Level 0: their `text` lines, in overlay order, become the project block's body, the part unit 2
   places; until the overlay holds a level-0 unit, the block renders `[charter] adopter_rules` as
   unit 2 does.
3. Levels 3 to 5: each document's units render between the marked pair, appended after gov's text.
   An existing pair is rewritten in place; a document with no repository unit carries no pair.
4. Measure: per load point, the document's composed bytes; per origin (`gov:<kit>`, `repository`),
   the bytes each contributes, largest first.

The marked pair reuses the region-marker shape `REGION_OPEN` and `REGION_CLOSE` already give
`<!-- gov:playbook -->` (`:121-123`), so the one-line and region checks read it, and
`check_one_line_regions` (`:667`) runs over the composed text.

### Budgets and harness limits

```text
budget   AGENTS.md            21311 > 20480 (budgets.agents-md) · warn · largest: gov:playbook 17920 · repository 2391 · gov:roles 1000
REFUSED  AGENTS.md            33210 > 32768 (CODEX_MAX, codex) · refused under any budgets.enforce · largest: gov:playbook 17920 · repository 14290 · gov:roles 1000
```

The cap's key is the load point's key under `budgets.*` as unit 11 names it; the harness limit is the
value unit 6's check reads from `CODEX_MAX`, so the gate and the render read one fact. Under `refuse`
a budget breach exits 1 and writes nothing; a harness-limit breach exits 1 and writes nothing under
either value.

### The harness files

The harness files are the aliases today's wiring writes (`claude`, `gemini`, `copilot`, `cursor`,
`windsurf`, `tools/agent-instructions/adopt-agent-instructions.sh:49-58`), absorbed into the renderer by
unit 20. `--check` reads each: an `@AGENTS.md` import line, a symlink to `AGENTS.md`, or bytes equal to
the composition pass; anything else reds naming the file. The render writes a copy-mode alias as the
composition's bytes in the same run that writes `AGENTS.md`, so it never trails it.

### The delta report

S22's six states are `unchanged`, `amended`, `replaced`, `excluded`, `stale` and `orphaned`; a widening
prints under the word `widening`.

```text
  unchanged          [gov:playbook ] practice.yagni
  amended            [repository   ] practice.cost
  excluded           [gov:roles    ] role.scout
  widening           [repository   ] fixture.alpha grants add write (gov: read)
```

The state word and the bracketed origin use `cmd_update`'s `{v:<18} [{role:<13}] {path}` widths
(`tools/govkit/govkit.py:10010`). `update` already runs the playbook-render kit's `[[regenerate]]`
(`tools/playbook/kit.toml`, `adopt-playbook.sh --target .`) through `run_target_argv`
(`tools/govkit/govkit.py:11363`); it gains a relay of the regenerate's stdout lines whose state word is
one of S22's six or `widening`, printed under one `govkit update — composition` heading after its tally
line (`:10033`), and prints nothing else of the adopter's output.

### The census predicate

A row of the catalogue rules `gov-only` when all four hold, and `ship` otherwise:

1. its `line` names at least one repository path in backticks, or a leg names its tag in `enforces`
   (unit 7's key on `tools/gate-legs.json` rows), so the ruling rests on evidence;
2. every path it names is shipped by no registry entry: no entry's descriptor `home` holds it and no
   entry's `claims` list names it (`tools/govkit/registry.toml` and the descriptors it points at), or
   it is an `[[exempt]]` path there;
3. every leg naming its tag in `enforces` is an `[[exempt_leg]]` of `tools/govkit/registry.toml`, a leg
   gov runs and ships to no adopter;
4. no role definition the roles kit ships cites its short name in `rules:` (the join `roles_lib.py`
   reads), so moving it breaks no role render.

A `{{HELP_DIR}}`-style placeholder in a line is an adopter's path and counts as shipped. Each row
prints its tag, each named path with `shipped by <entry>` or `gov-only`, each enforcing leg with its
class, and the ruling.

### Alternatives rejected

- **The marked part as a `kit:` or `when:` fence** (`OPEN_RE`, `:118`): those fences mean "drop this
  span when the kit or property is absent", and a repository part is never dropped, so reusing them
  would let `drop_blocks` delete a repository's units.
- **Truncating at the budget**: the clause and the night pass two, point 5, refuse it; a truncated
  charter loses its last lines silently.
- **A typed Codex limit in the renderer**: a second spelling of `CODEX_MAX`, which unit 6's check
  already reads; the two would drift.
- **Delta lines written to a report file `update` reads back**: a new artifact with its own staleness,
  where the regenerate already runs inside `update`.

## 5. Production-readiness checklist

- security: no new write path; the composition writes only the documents the renderer already writes,
  and the census moves rows through unit 32's guarded route. The relay prints only lines matching the
  report's state words, so an adopter's regenerate cannot inject arbitrary text into update's verdict.
- perf / scale: one overlay read per render, one byte count per document and origin.
- error / empty / loading states: an overlay with no repository unit composes gov's text alone and
  prints every gov unit `unchanged`; a repository unit at a level it may not write refuses naming it;
  a missing cap reads as no budget and says so on one line.
- observability: every overflow names its contributors; every update prints the composition heading
  and its lines, a zero count included.
- risks: the census predicate rules a row `gov-only` that an adopter relied on by default
  (deviation 341); the owner's walk of the departures report is the turn that reverses it. Edits to
  `render()` share one long function with the template path (`a-new-local-collides-in-a-long-function`,
  `memory/gotchas/a-new-local-collides-in-a-long-function.md`).
- testing: the fixture plants of §6, and the self-test arm of §7.
- migration: §4 "### Migration".
- user docs: `help/composition.md` and its index line (S9).
