## 1. Goal

The charter's 36 practices are one-line rules typed into the template's section 1
(`coding-governance-agents.template.md:13-54`), with no reach and no way for an adopter to choose them
except the one `when:cross-os` fence (gap-found-02). This unit moves them into a shipped catalogue,
`tools/playbook/practices.toml`, where each practice is a tag, a one-line rule and its reach per step
(foundations R1, F1-3 "Catalogue with reach"), and makes the active set a policy, `charter.practices`,
that the renderer reads to write the charter's practice lines (v2:1143, P14).

## 4. Design

### Data model

```toml
foundation = ["practice.yagni", "practice.reuse", "..."]   # the default of charter.practices

[[practice]]
tag = "practice.yagni"
line = "YAGNI: build what this unit needs now, never scaffolding for later, and delete rather than disable."
[practice.reach]
plan = "no build for a speculative need"
design = "no extension point, option or layer the unit does not use"
build = "delete rather than disable"
test = "no test for a path that is not built"
review = "speculative generality is a finding"

[[practice]]
tag = "practice.roles"
kit = "roles"
line = "Spec writing and review, building and the closing review run in role agents ..."
```

The `practice.yagni` reach is foundations R1's own example (foundations:72-76). Every other row carries
at least one reach entry, written by the builder from the rule's text; a step key is the flow's step
name, lowercase (P20: plan, design, build, test, deploy), plus `review` for the review breakpoint.

### Flow

`render()` reads the catalogue beside itself, resolves the active set, and replaces the one
`{{PRACTICES}}` line before `PLACEHOLDER_RE.findall` runs, so no second placeholder pass is needed. The
probe table `PROBES` (`render_playbook.py:565`) is not used: a probe's value is substituted after the
placeholder set is collected, and a practice line carries placeholders of its own.

### Inventory

Minted: the file `tools/playbook/practices.toml`; its `[[practice]]` row and `foundation` key; the
optional `kit` field; the functions `read_practice_catalogue` and `resolve_active_practices`; the
placeholder `PRACTICES`; three tags `practice.solid`, `practice.dry`, `practice.tdd`; the template
marker `v4.5`; the page `help/charter.md`. The policy key `charter.practices` is v2's.

### Migration

A seeded template older than `v4.5` keeps its literal section-1 lines and renders as today, and the
render's `legacy` note asks for a reseed, the path `TEMPLATE_MARKER_RE` already takes
(`render_playbook.py:344`). Gov's own template is the source and moves at once.

### Rollout

Live at landing; gov's `AGENTS.md` practice lines do not change.

- `tools/playbook/instruction_units.py`

### Alternatives rejected

- **Practices as `[[unit]]` rows in a kit's `instructions.toml`.** S15 fixes a catalogue file of its own,
  and a practice carries reach, which a unit row has no field for.
- **A `PROBES` entry.** Rejected in the flow above: its value lands after the placeholder set is read.
- **`foundation = true` on each row.** A census moving a row out of the set would then edit the row; one
  list keeps the default one fact.
