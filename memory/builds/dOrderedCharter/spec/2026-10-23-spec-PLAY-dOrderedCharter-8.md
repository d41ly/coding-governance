## 1. Goal

The orientation card reaches a session today only as hook output, a system reminder at the hook
point, never in the charter's instruction slot; subagents under `omitClaudeMd: true` get only its
route; and another harness gets nothing (`gap-orient-13`). This unit delivers the build's card at
level 1 of the ladder (layer-instruction R-G, "1 the build's card"): rendered into a per-worktree,
git-ignored `.claude/orientation-card.md` (S19) by every session-start hook in the session's own
tree, imported by the charter's entry file as a second `@` line, and sliced to subagents through
the brief and the subagent-start hook. The entry-file wiring stands in for the Runtime harness
adapters until dWellOiledMachine lands them (the whole-design audit's C1-F20), and no override file
is ever written; since unit 20 that wiring is the renderer's `entry-files` scope, where
`PLAY-dOrderedCharter-43` builds the import (the fork record's F6). The import is wired only after the
primary-to-worktree compaction fixture passes, as the clause orders.

## 4. Design

### The card file

`write_card_file` renders, from the stored card `$CARD_FILE`:

```
[.claude/orientation-card.md · Level 1 · the build's card: where this session stands; level 0 outranks it]
<the stored card's bytes>
[/.claude/orientation-card.md]
```

The two envelope lines come from `render_envelope_sh`, the S8 inline copy, called with S9's row
values, in PLAY-dOrderedCharter-3's form: the document's repo-relative path, then `Level <n>`, then
the direction, and a closer naming the path. The file is written to a temp beside it and renamed into place, so a reader never sees half a
card (the `shell hygiene (a fixed-name temp renamed into place)` leg grades the temp's name). The
session tree is resolved once:

- `read_session_id` (`skills/session-kickoff/manifest-check.sh:293`) reads stdin once into a
  variable and takes both `session_id` and `cwd` from it; `--session` still suppresses the read.
- `CARD_TREE` is `git -C "$cwd" rev-parse --show-toplevel` when `cwd` is given and inside a git
  repository, else `$ROOT`.

A failure to write the file prints one `card-file — skipped: <why>` line and never changes the
verb's exit: the stored card is the record and the file is its render.

### The ignore line

`git -C "$CARD_TREE" check-ignore -q .claude/orientation-card.md` exits 0 → nothing. Else the line
`/.claude/orientation-card.md` is appended to `$(git rev-parse --git-common-dir)/info/exclude`, the
directory created if absent, and the probe re-run; a second miss is a `skipped:` line and no file
is written. One exclude line covers every worktree of the clone.

### The wiring stand-in

`PLAY-dOrderedCharter-43` builds this table at the renderer's `entry-files` scope, behind a `--card`
switch that is off by default; this unit builds none of it, and states it here because that unit reads
it (the fork record's F6). Under the switch:

| Alias | Pointer mode | `--check --card` |
|---|---|---|
| `claude` | `CLAUDE.md` = `@AGENTS.md` then `@.claude/orientation-card.md` | fails when either line is absent |
| `gemini` | a new `.gemini/settings.json` lists both files; an existing one gets today's merge-by-hand failure naming the array | fails when the list lacks the card |
| `copilot`, `cursor`, `windsurf` | unchanged copy | prints `card — not delivered: <alias> has no native import` |
| Codex | reads `AGENTS.md` itself, no alias | prints `card — not delivered: codex has no import, and an override file would replace the charter` |

`is_import` (`tools/agent-instructions/adopt-agent-instructions.sh:62`) was the adopter's pointer test at
this spec's base. Unit 20 moved the pointer and copy logic into the renderer, and the adopter now hands
`--render-scope entry-files` and `--check-render --scope entry-files` to `tools/playbook/render_playbook.py`,
whose `entry-files` compare and `tools/playbook/render_playbook.py#check_gemini_configured` unit 43 extends.
Without `--card`, behaviour is today's byte for byte.

### The subagent slice

`renderRouteContext` (`tools/hooks/scratch-guard.js:1470`) keeps its one evaluation order and its
card source. After it builds its text, it reads `<toplevel>/.claude/orientation-card.md` from the
same session directory it already resolved; when the file exists, its first and last lines wrap the
text, counted inside `ROUTE_CONTEXT_CAP` (`:1456`). The module types no envelope: it copies two
lines. With no file, the text is today's.

### The brief slice

`render_handoff` (`tools/roles/handoff.py:312`, now `tools/roles/handoff.py#render_handoff`) already
takes `card_arg`. When the card file exists
in `root`, it adds `## Card` holding the file's first line, its `## route` section and its last line.
Its place among the blocks is PLAY-dOrderedCharter-5's ranked order, level 1 after the level-0
practices-at-step block, both inside the `## Task` section. With no file, nothing is added.

### The fixture

`card-compaction.fixture.sh <scratch-dir>` builds, under a short path the caller names (a clone
under the run's scratch path fails with "Filename too long" on Windows):

1. a repository with `AGENTS.md`, `CLAUDE.md` holding the two import lines, and one worktree;
2. a card file in each tree, nonce `P-<rand>` in the primary and `W-<rand>` in the worktree;
3. session A, `claude -p` started in the primary tree, told to enter the worktree, then `/compact`
   on resume, then asked to print the nonce its loaded card file carries;
4. session B, started in a tree whose card file is absent, asked to print `ok`.

It exits 0 when A's answer carries `W-` and not `P-` and B prints `ok`; 1 naming the failed limb;
2 when `claude` is absent. It writes nothing outside the scratch directory it is given.

### Alternatives rejected

- **An unscoped `.claude/rules/` file instead of an import.** It would be Claude-only, and the
  preserve research found the hooks ran in the primary tree, the same risk the fixture measures, with
  no wiring kit to stand in for other harnesses.
- **A tracked `.gitignore` line.** Gov's `.gitignore` holds two lines and an adopter's is its own;
  the clone-wide `info/exclude` line needs no adopter step and covers every worktree.
- **Typing the envelope in JavaScript.** A third copy of S16's format; the hook copies the file's
  own lines instead.

## 5. Production-readiness checklist

- security: the card holds no secret; the writer joins only a toplevel git resolves into a path,
  and the session id keeps its existing refusal of separators and `..`. `info/exclude` gains one
  fixed line. No override file is written.
- perf / scale: one extra file write and one `check-ignore` per SessionStart; the subagent hook reads
  one small file.
- error / empty / loading states: every failure is one `skipped:` line; an absent card file leaves
  the hook and the brief as today.
- observability: the `card-file —` line names where the file was written or why not.
