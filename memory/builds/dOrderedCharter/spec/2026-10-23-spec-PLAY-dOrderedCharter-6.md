## 1. Goal

The charter says what each tool answers and never how an agent starts or advances the loop for its
role, so every agent re-derives that from many files (gap-found-05). This unit gives each kit's
descriptor a drive table, composes the charter's drive section from the adopted kits' rows alone,
checks the two both ways, repeats each subagent's role line in its handoff, and holds the rendered
charter inside the smallest harness's limit, 32 KiB, against the caps it has today (foundations R3, R6,
F1-6, F1-7; v2:961-965 P15).

## 4. Design

### Data model

```toml
[[drive]]
stage = "start"
role = "main"
command = "/session-kickoff"
when = "a new task from the owner"

[[drive]]
stage = "build"
role = "gov-builder"
command = "python <prefix>/roles/handoff.py render --role builder"
when = "a unit whose spec is READY"
```

Rendered: ``- build · gov-builder — a unit whose spec is READY: `python <prefix>/roles/handoff.py render --role builder` ``,
one line each, under the one-line cap.

### Inventory

Minted: the `[[drive]]` row and its four fields; the stage value `start`; the role value `main`;
the template section `## Drive — how to start and advance the loop`; the placeholder `DRIVE`; the CLI verb
`drive`; the handoff heading `### Drive`; the size check's new number in `check-template-size.sh`; the
`root_relative` `[[files]]` rules in `tools/playbook/kit.toml`; the `budgets.py` verb `home`, the
function `read_cap_home` and the case `budgets-home`. `python tools/lexicon/lexicon.py --suggest
read_cap_home --as py.function` answered OK on 2026-10-25; the lexicon declares no CLI-verb cell, so
`home` is graded by no cell, and it names what the verb prints, as `resolve` and `check` do.

### Migration

A seeded adopter template without `{{DRIVE}}` renders without the section, and the render notes the
template's vintage as it does today. A kit without rows contributes nothing.

### Rollout

`budgets."AGENTS.md"` (20480), and a cap the section would cross is raised only in the minimal guard's
one admitted shape (TOOL-dGroundRules-6 S3), under the four conditions above `[budgets]`.
