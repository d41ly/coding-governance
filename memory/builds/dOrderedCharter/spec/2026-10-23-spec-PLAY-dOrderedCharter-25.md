## 1. Goal

Orienting on one feature, `roles`, took about 42 calls and 734 KB read whole (night pass, point 4). With one
grammar, one index and one resolver in place (unit 19) and one closed edge set declared at its sites (units 24
and 28), `gov tag bundle <tag>` answers that in one call: the node, then every inbound edge grouped by type,
each row a range to pull, folded past `tags.bundle-rows` and, by flag as `tags.bundle` allows, with content
inlined under the byte budget the call names (NP-14). Two checks keep the edges a bundle walks honest: every
edge's type is registered, and every target resolves, each seen red.

## 2. Scope (IN)

- **S1** — The verb. `python tools/playbook/gov_tag.py bundle <address>` (S5) resolves `<address>` through
  unit 19's resolver, then prints the node first and every inbound edge `gov tag refs` returns for it,
  grouped by edge type in the registry's order (`tools/playbook/edges.toml`, S6). Each row is one range,
  its text form `path:span · type · bytes`, `span` the extent the index holds for the source node or the
  whole file where it holds none, and `bytes` the size of that range. The three named sections are views
  of the rows: members are the `part-of` rows, instructions the `instructs` rows, and regions every row
  that carries a span. Observed by AC1.
- **S2** — The fold. Past `tags.bundle-rows` rows (`20`, `40` or `80`, default `40`), rows fold by their
  source's kit directory (`tools/<kit>/`, else the path's first segment), the group with the most rows
  first, one group at a time, until the count is within the budget; a fold row reads
  `<dir>/ · type · <n> rows · bytes` and `--under <dir>` lists that group's rows unfolded. A bundle still
  over budget after every group folds prints as folded with a line saying so, never cut. Observed by AC2
  and AC3.
- **S3** — Inline content. `--inline --bytes <n>` inlines each row's content in manifest order while the
  running total stays within `<n>`; the first row that would pass it, and every row after, stays a manifest
  row. No content is truncated mid-range. Observed by AC4.
- **S4** — `tags.bundle`. `manifest` refuses `--inline`, exit 2, naming the key; `inline` inlines every
  call and refuses one without `--bytes`, naming the missing budget; `both`, the default, prints the
  manifest and inlines on `--inline`. Both keys are read through dGroundRules' one reader
  (`cl-dClosedLoop-0008`) once it lands, and until then with v2's catalogue defaults, `both` and `40`
  (v2:1353-1354). Observed by AC5 and AC3.
- **S5** — The type-registered check. `python tools/playbook/gov_tag.py check --only type-registered` reds every
  edge the index holds whose type is not a row of `tools/playbook/edges.toml`, naming the declaring site
  and the type; `cites`, derived, is never declared and never graded. Observed by AC6.
- **S6** — The target-resolves check. `python tools/playbook/gov_tag.py check --only target-resolves` reds every
  declared edge whose target the resolver cannot resolve, naming the site, the type and the target; each
  address form resolves by the per-form rule unit 28 ships. Observed by AC7.
- **S7** — Empty sections. A section with no rows renders one of S20's slot states: `searched-empty` when
  its population exists and holds nothing for this tag, and `not-installed: <fallback>` when no extractor
  feeds it, the regions section naming dTotalRecall's span extractors and the whole-file range as its
  fallback. Observed by AC8.
- **S8** — The legs and plants. The two checks run inside unit 19's `tags (the resolver's checks)` leg,
  which runs `gov_tag.py check`; this unit adds one leg, `tags bundle selftest`, with `"pack": "tags"`
  (S21) in `tools/gate-legs.json`. The plants extend unit 19's fixture, `python tools/playbook/gov_tag.py
  --fixture --plant bundle-<case> [--set <key>=<value>]`, its scratch repository given the case's sites
  and edges, and `--set` honoured under `--fixture` only. Observed by AC1 to AC8.

## 4. Design

### Data model

```
bundle  := node-row  ( type-header  row* )*
row     := <path>:<span> · <type> · <bytes>          span := <first>-<last> | whole
fold    := <dir>/ · <type> · <n> rows · <bytes>
```

The bundle is assembled from two existing reads, never a third query path: `show <address>` for the node
and `refs <address>` for its inbound edges. The output is text, every line opening `tags:` as unit 19's
verbs print, or JSON with `--json`, the row fields `path`, `span`, `type` and `bytes`.

### Inventory

Minted: the verb `bundle` with the flags `--inline`, `--bytes` and `--under`; the `check` flag `--only <arm>` and its arms
`type-registered` and `target-resolves`; the modules `tools/playbook/tag_bundle.py` and
`tools/playbook/edge_checks.py`; the `bundle-*` fixture cases; the leg `tags bundle selftest`. No conf key; the two policy keys are this unit's owned nodes.

### Migration

None. The checks run over the edges units 24 and 28 declared, which are clean at their landing.

### Rollout

Live at landing, at order 10, after units 19 (order 4), 24 (order 7) and 28 (order 8).

### Files touched (estimate)

- `tools/playbook/gov_tag.py`
- `tools/playbook/tag_bundle.py`
- `tools/playbook/edge_checks.py`
- `tools/gate-legs.json`

### Alternatives rejected

- **Content always inlined.** NP-14's `manifest` and `both` options exist because a feature's bundle runs
  about 44 rows; the owner chose `both`.
- **Cutting rows past the row budget.** A cut row is unreachable; a fold row with `--under` keeps every row
  one call away.
- **Truncating the range that crosses the byte budget.** A half range reads as the whole; it stays a
  manifest row instead.

## 5. Production-readiness checklist

- security: read-only over the index and the working tree; `--under` is matched against row paths and
  never joined to a filesystem path.
- perf / scale: two index reads and one blob read per inlined row; the `roles` bundle measured about 44 rows
  (night pass, point 4).
- error / empty / loading states: an unresolvable address exits 1 naming it; empty sections render S7's
  slot states, never a blank.
- observability: each fold row names its group and the `--under` call that opens it.
- risks: a fold by directory can hide one important row in a big group; `--under` reaches it.
- testing: S8's plants in both directions.
- migration: none.
- user docs: N/A — unit 37 renders the verb's reference page from its rows.

## 6. Acceptance criteria

- **AC1** — When `python gov_tag.py --fixture --plant bundle-manifest` runs, `gov_tag.py bundle
  doc.fixture` prints the node first, then rows grouped by type in `edges.toml`'s order, each
  `path:span · type · bytes`, its `part-of` rows under members and its `instructs` rows under instructions.
  Red when: the node is not first, or a row lacks its span or bytes.
- **AC2** — When `python gov_tag.py --fixture --plant bundle-fold` runs with 50 inbound rows,
  `bundle` prints at most 40 rows, folding the largest directory group first, and `bundle --under
  tools/alpha/` lists that group's rows unfolded.
  Red when: rows past the budget are cut, or a fold row cannot be opened.
- **AC3** — When `python gov_tag.py --fixture --plant bundle-rows-values` runs a 45-row bundle with
  `tags.bundle-rows` at `20`, `40` and `80`, it folds under the first two and not under the third.
  Red when: any value is ignored.
- **AC4** — When `python gov_tag.py --fixture --plant bundle-inline` runs `bundle --inline --bytes
  200`, whole rows are inlined in manifest order within 200 bytes, the row that would pass it stays a
  manifest row, and no inlined range is shorter than its span.
  Red when: the budget is exceeded or a range is truncated.
- **AC5** — When `python gov_tag.py --fixture --plant bundle-mode-values` runs, `--inline` under
  `manifest` exits 2 naming `tags.bundle`, a call without `--bytes` under `inline` exits 2 naming the
  budget, and under `both` a bare call prints the manifest and `--inline` inlines.
  Red when: a value admits what it refuses.
- **AC6** — When `python gov_tag.py --fixture --plant bundle-unregistered-type` plants
  `**Edges:** relates-to=doc.fixture`, `gov_tag.py check --only type-registered` exits 1 naming the site and
  `relates-to`, and exits 0 once the line reads `part-of=doc.fixture`.
  Red when: an unregistered type passes.
- **AC7** — When `python gov_tag.py --fixture --plant bundle-dangling-target` plants
  `instructs=doc.nosuch`, `gov_tag.py check --only target-resolves` exits 1 naming the site, the type and
  `doc.nosuch`, and exits 0 once the target is `doc.fixture`.
  Red when: a dangling target passes.
- **AC8** — When `python gov_tag.py --fixture --plant bundle-empty-sections` runs on a tag with no
  `instructs` row and no span extractor, the instructions section reads `searched-empty` and the regions
  section reads `not-installed:` naming its fallback.
  Red when: an empty section renders blank.
