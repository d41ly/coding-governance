## 4. Design

### The remote literal

`tools/check-remote-literals.sh` builds its third shape's call-argument arm as a comma, optional space, the quoted
name, optional space and `)`. Line 157 of `tools/playbook/instruction_units.py` ends `, "origin")`, so it matches,
and a probe of all eleven general patterns and the shell-only pattern over the gate's population at base finds no
other uncommented hit. The probe's other matches are `*.js` comment lines, which the gate's own filter skips.

With the name first, no shape reads the line: the call-argument arm needs a comma before the name, the list arm
needs a `[`, and the assignment arm needs the quote straight after `=`, where `(` now sits. The order carries no
meaning. `tools/playbook/instruction_units.py#check_unit_row` is the constant's only reader, tracked anywhere outside
`memory/`, and it reads it once, as `key in DERIVED_UNIT_KEYS`, a membership test that ignores order.

### The leg ceiling

`tools/run-gates/derive-ceilings.py#cmd_check` takes `floor` and `frac` from `tools/run-gates/ceiling-margin.txt`,
which declares `120` and `1.0`. It computes `need = max(floor, frac * max)` and reds a ceiling when
`ceiling < max + need`. The evidence row for this leg in `tools/run-gates/ceiling-evidence.txt` records a 3.6s
maximum and carries an out-of-band source, so the check's REACHED branch, which grades runner rows only, cannot
fire on it. The bound is 3.6 + max(120, 3.6) = 123.6s, and `ceiling` must be an integer, so 124 is the smallest
value the check accepts. 123 stays short by 0.6s.

The figure is DERIVED from the two tracked files at base, and `derive-ceilings.py --check` re-derives it. A later
reading above 4s would raise the bound again, and that is the check working, not this unit failing.

No other tracked file carries this row's ceiling. `tools/govkit/registry.toml` and `tools/govkit/subject-pins.tsv`
name the leg but not its bound.

### The stamp

`skills/session-kickoff/manifest-check.sh` fails check 5 when the newest commit touching a `watch:` path is not an
ancestor of the newest commit that changed the block's `last-audit` value. The new value is
`<ISO-8601 datetime with offset> @ <full 40-hex sha>`, the sha being HEAD on the branch at stamping, per the
script's own stamp rule. The builder re-reads each claim the manifest derives from `tools/gate-legs.json` before
stamping. A ceiling moves no such claim.
