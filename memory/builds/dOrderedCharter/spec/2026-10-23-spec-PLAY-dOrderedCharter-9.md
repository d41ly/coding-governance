## 1. Goal

Instructions map to almost nothing below them (gap-found-09): sections carry tags, only the roles kit's
`rules:` key joins a role to the charter, checklist items are numbered, and no registry joins an
instruction to the step, item, policy or layer it serves, so no loader can select an agent's instructions by
its item. R-A makes the unit the atom and every document a rendering of units. This unit lands the registry
(S10): one `[[unit]]` row per unit in each kit's `instructions.toml`, carrying the fields the clause lists,
`required-by` among them (C1-F1), one reader every consumer reads rows through, and the selection and
per-unit rendering a document is assembled from.

## 2. Scope (IN)

- **S1** — The row, `<kit>/instructions.toml`, one `[[unit]]` table per unit, with S10's fields:

  | Field | Holds |
  |---|---|
  | `tag` | the unit's tag in the `unit` namespace, `unit.<seg>[.<seg>]` |
  | `level` | an S8 level, read through `parse_level` |
  | `type` | an S9 statement type, one of `STATEMENT_TYPES` |
  | `scope` | the selector tags that load it, `reader.every` for every reader; the field's one spelling (§8 F4) |
  | `trigger` | the condition under which it loads, a tag or `always` |
  | `budget` | its budget class, `line` (at most 200 bytes) or `block` (at most 600 bytes) |
  | `text` | its typed text, one line, for the four typed statement types |
  | `source` | where a derived unit's value comes from, `policy:<key>`, `probe:<name>` or `cmd:<command>` |
  | `owner` | the chain build that owns it |
  | `usage` | how a user invokes it, on a user-facing unit |
  | `help` | its rationale, which never loads |
  | `required-by` | the role and item tags that require it |
  | `enforced-by` | what refuses a bypass, spelled as `tools/roles/workflows.toml` spells it for `check_roles.py`: a list of descriptions, a hook's entry opening with its `.js` file name, or the one string `none — <why>` |
  | `class` | `fixed` or `open` |
  | `edges` | S6 edge strings, `type=target[,target]` |

  Observed by AC1.
- **S2** — The one reader, in `tools/playbook/instruction_units.py`, with a text entry and a tree entry.
  `parse_unit_rows(text, path, origin=None)` reads one manifest's text, a working-tree file or a blob at
  any revision, and returns `(units, faults)`: a `Unit` per readable `[[unit]]` table in row order, and one
  `UnitRowError` per row it cannot read, naming the file and the row's index or tag: a TOML error (every
  row), a `[[unit]]` that is not a table or sits under no `[[unit]]` header, a field of the wrong TOML
  type, an unparseable level. It reads `class` as `fixed` where a row declares none and an omitted field
  as `None` or `()`; `level` through `parse_level`; `enforced-by` as a tuple of descriptions or the one
  string `none — <why>`; and `edges` as the row's strings, whose grammar the edge check holds (S3). Each
  `Unit` carries `line`, its `[[unit]]` header's line, and `body`, its text from that header to the next
  table header. `derive_manifest_kind(path, prefix)` is the one population predicate: `kit` for
  `<prefix>/<dir>/instructions.toml`, `<prefix>` the parent of the module's own kit directory (`tools/`
  in gov); `overlay` for `.governance/instructions.toml`; else `None`. `read_units(root)` returns the
  Units of every `kit` manifest in path then row order, `origin` the kit's descriptor `id` (unit 55),
  and raises one `UnitRowError` naming every fault. Field rules beyond that (required fields, known keys,
  closed sets, sizes) are unit 20's schema check, which reads rows through this reader. Observed by AC2,
  AC3 and AC6.

## 4. Design

### Data model

```toml
# tools/<kit>/instructions.toml
[[unit]]
tag = "unit.reuse-first"
level = 3
type = "directive"
scope = ["reader.every"]
trigger = "always"
budget = "line"

Every tag the example names is in a namespace `tools/playbook/namespaces.toml` registers: `reader.every`
is `tools/playbook/readers.toml:7`, `layer.instruction` is `tools/playbook/layers.toml:20`.

class Unit:
    tag: str | None; level: int | None; type: str | None; scope: tuple; trigger: str | None
    budget: str | None; text: str | None; source: str | None; origin: str | None; owner: str | None
    usage: str | None; help: str | None; required_by: tuple; enforced_by: tuple | str
    klass: str; edges: tuple; path: str; index: int; line: int; body: str
```
