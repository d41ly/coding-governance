- Fixing a red that one of this branch's legs prints over bytes main brought in, or that one of
  main's legs prints over this branch's bytes. Each is a fix unit of its own, added at the close.

- Any edit to the memory-tree kit's closing-review `[[drive]]` row. F1 resolved to keep it.

- A hook refusal at either commit is never bypassed. On one, or on a hunk whose two intents this
  spec cannot hold together, the pass runs `git merge --abort`, leaves the branch at its pre-merge
  tip, and returns the refusal or the hunk to the main loop.
