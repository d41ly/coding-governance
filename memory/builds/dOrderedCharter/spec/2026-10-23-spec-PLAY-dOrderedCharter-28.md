## 1. Goal

The closed edge set cannot carry the cycle the owner asked for: a record serving a unit, who made a
thing, the instruction an act followed, a return answering its work order, an act's session, what a
landing carried, a pin, an item's reads and writes and a promotion have no type, so five of twelve
hops on one feature need prose or search (`gap-mem-35`). This unit registers the twelve new edge
types with their namespaces, `carries-clause` among them, widens `decides` and `after`, registers the
native-id mechanism with its two classes, registers the two pinned address forms, and applies
PLAY-dOrderedCharter-24's grammar and parser at every site the memory plan names that exists in this
tree, each malformed or unresolvable edge seen red and the checks joined to the `tags` leg pack (P33,
P34; the owner's FK-1-2; memory-plan `[frame]`, `[sites]`, `[edges]`).

## 4. Design

### Data model

```toml
# tools/playbook/namespaces.toml, beside the [[namespace]] rows
[[native]]
class = "family-id"
owner = "dOrderedCharter"
pattern = "id_grammar:grammar_for"
resolver = "corpus_ids:--print-defined-ids"

[[native]]
class = "clause-id"
owner = "dTrueNorth"
pattern = "design_lib:_CL"
resolver = "design_lib:read_design_view"
```

```toml
# tools/playbook/edges.toml, one of the twelve
[[edge]]
type = "carries-clause"
inverse = "carried-in"
from = ["family-id"]
to = ["clause-id"]
pin = "clause"
status = "declared"
declared-at = "the spec's **Carries:** line"
```

Trailer keys sit in one table, `[[trailer]] key = "Gov-Unit" type = "serves"`, in `edges.toml`, so a
key is registered once and the commit adapter reads the table.

### The pin reds

| Plant | What it holds | Red as |
|---|---|---|
| `pin-no-at` | `amends=practice.land:1a2b3c4d` | a pin is written `@<hash8>` |
| `pin-bad-hash` | `amends=practice.land@1a2b3c` | the hash is not eight hex digits |
| `pin-no-text` | `amends=unit.x@00000000`, a unit whose text never hashed so | matches no text in its unit's history |
| `clause-no-rev` | `carries-clause=cl-dAlpha-0001@00000000` | matches no revision of its clause |
| `pin-other-type` | `part-of=kit.x@1a2b3c4d` | a pin on a type whose row admits none |

A unit's text history is its source file's committed revisions, read with `read_blobs_at`, each
revision's unit text extracted by the unit registry's reader (shared interface S10) and hashed by
`derive_pin_hash`. Until PLAY-dOrderedCharter-9 lands rows, the fixture's unit file stands in.

### The resolve plants

`resolve-tag` (`layer=layer.memory`), `resolve-pinned-tag`, `resolve-section`
(`implements=doc.build-method#m5-recall-and-reuse`), `resolve-family`
(`serves=PLAY-dOrderedCharter-28`), `resolve-clause` and `resolve-pinned-clause`, each exiting 0
with its target's row; `bad-section` (`doc.build-method#`), `bad-block` (two types on one line
under a heading) and `bad-note-refs` (`gov:note layer.memory — x → y refs=a b`), each exiting 1.
