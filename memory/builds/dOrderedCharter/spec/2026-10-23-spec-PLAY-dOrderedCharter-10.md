## 1. Goal

Instructions map to almost nothing below them (`gap-found-09`), whole populations carry no tag and
spellings collide, `build.scope` being an item and a policy (`gap-found-21`). Of R-B's twelve
namespaces this build registers `reader`, `level`, `layer`, `practice`, `principle`, `kind` and `kit`,
and `repo`, the repository's own, each a row of PLAY-dOrderedCharter-19's registry; joins each both
ways over a population it asserts is non-empty; and checks every tag's name in the core against the
grammar the systems record states, with the namespace words read from the registry and handed to the
lexicon at the name-check point. Each later namespace's join is armed by the build that registers it:
`step`, `item` and `policy` by dDeclaredLoop, `role` by dBoundRoles, `record` by dTotalRecall (M5; the
owner's tag-grammar answers).

### The shape check

```
reason = None
if ns not in words:                         reason = "namespace not registered"
elif not all(SEG.fullmatch(s) for s in segs): reason = "segment outside seg"
elif len(tag.encode()) > TAG_MAX_BYTES:     reason = "over 64 bytes"
elif segs[0] in words:                      reason = "first segment is a namespace word"
```

The words come from `read_namespaces`; each is first checked against `seg`, so a malformed registry
row is a red naming the row rather than a pattern that matches by accident, the validate-before-splice
rule `tools/memory-tree/backlog.py:174-178` (`FAMILY_SHAPE`, `build_grammar`) follows for families.

### The joins

`compute_coverage({ns: members}, {"cited": {ns: cited}}, {ns: ()})` gives the cited-but-undeclared
set as stale claims; the declared-but-unused selector set is the inventory less the unit rows'
selector fields, read from the index's `unit` rows. A descriptor namespace's unused members are
printed, not red, since a descriptor never selects.
