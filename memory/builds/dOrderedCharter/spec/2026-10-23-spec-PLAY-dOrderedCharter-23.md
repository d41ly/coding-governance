its terminal state with no owner turn but those `autonomy` places (v2's P4; the night pass, point 1).
The charter says the opposite twice today. Its `[land]` practice asks for "an explicit ask or the
unattended protocol" (`coding-governance-agents.template.md:30`), so landing reads as the owner's by
default; and its tool lines present `/unattended` as one tool beside an attended `/build`

a build runs unattended by default from its request, and rewrites `[land]` so the merge and the push
read the request's mandate. At this build the request's mandate is the build README the unattended
driver authorizes at its pinned BASE (`check_authorization`, `tools/unattended/unattended.sh:3927`),
the stand-in until a placed request exists.
