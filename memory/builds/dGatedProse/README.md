# dGatedProse — the owner's rulings on dLoggedFlight's parked decisions, built only where a dry run earned it

## The problem this build exists to solve

`dLoggedFlight` parked four decisions its own run could not take, and the owner ruled on all four
after it landed, recorded as `TOOL-dLoggedFlight-31` to `-34`. Three of the rulings wire a predicate
over spec PROSE, and the owner made each conditional on a dry run over the live corpus first. That dry
run then refuted most of what was approved: the retirement predicate passes the very spec whose
inventory missed three readers, the suite-naming predicate is cleared by its own exemption on the
blocker that motivated it, and the replacement predicate is dominated by an arm that already exists.
This build implements what survived, and the owner re-ruled the rest.

## Expected improvements

- A retirement answers for its readers in a gradeable shape, so the class behind three audit blockers
  is asked at authoring time rather than remembered.
- A spec claiming what the map cannot hold reds, instead of shipping a leg that grades nothing.
- The guide cap stops being a figure one axis makes inert, and the protocol's debt row goes.
- The promotion chain is bounded by the signal that degraded, so a later run inherits the judgement
  `dLoggedFlight` made at round 7.

## Detriments if this is not built

- The reader-inventory class recurs with nothing but a reviewer's memory against it, and it has
  already cost four audit rounds and the units they promoted.
- The line axis of the guide cap reds in about eighteen days at the measured rate, and the debt row
  that records the breach reads as the remedy rather than as the debt.
- Every later run re-derives the promotion bound alone, under a limit it discovers by exhausting it.

## Build-level rules

Dry run before wiring (owner, 2026-09-20). No predicate over spec prose lands until it has run over
every live spec and printed hits AND near-misses, and a predicate whose hits are mostly innocent
comes back to the owner rather than into a gate. The dry runs for all four rulings are recorded in
this folder's research record, with the skeptic that re-derived each count.

A check this build adds grades SHAPE, never completeness, and its own header says so.

## Parked decisions

Checks A and B of `TOOL-dLoggedFlight-32` are DROPPED by owner ruling of 2026-09-20, on the dry run's
evidence: A cannot separate its motivating blocker from two innocent criteria of the same spec, since
`New arm:` names a module rather than a criterion, and its exemption is absent from 22 of the 24 live
specs; B is strictly dominated by the existing scope-join arm, which already reds ten of the eleven
items B finds, and the corpus does not use the vocabulary the ruling named.

`TOOL-dLoggedFlight-35` is answered by `TOOL-dGatedProse-4`: the owner ruled on 2026-09-21 that the
build method's size budget stands and moves, and on 2026-09-22 set it at 30720 bytes and 400 lines.
