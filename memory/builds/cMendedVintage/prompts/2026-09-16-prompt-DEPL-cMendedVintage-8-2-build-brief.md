# Build brief — DEPL-cMendedVintage-8

**Serves:** journal DEPL-cMendedVintage-8

This unit closes the render class by gating it: a descriptor shipping `rendered` rows and declaring
no `[[regenerate]]` becomes a selfcheck refusal. Read the spec whole first.

*Standing note: briefs in this build have carried claims measurement disproved — a bytes-on-disk
claim, a conjunction claim, a missing-`eol` claim, and a count of two env-strip sites that was
actually four. Anything below I have not run is marked UNVERIFIED. Measure.*

## Why the current arm cannot see the thing it is about

Arm 7l opens by skipping every descriptor with no `[[regenerate]]`. So its population is the kits
that ALREADY have the block, and what it grades is their prose. The kits that need one are exactly
the ones it skips. That is the vacuous-selector shape stated one level up: a predicate whose
population excludes every instance of the defect it names.

Inverting it costs no new declaration and no new file — the descriptors already carry both facts.

## Your precondition is met, and I verified it rather than assuming

This gate would red this repo until every rendered-row kit declared a regenerate. That is now true:
six kits ship `rendered` rows — drift-audit, lexicon, memory-recall, memory-tree, unattended,
workflows — and all six declare one. I checked each descriptor directly after
`TOOL-cMendedVintage-1` landed memory-tree's `--render`, which was the last missing one.

So the gate should go green on this tree the moment you wire it. **If it reds, do not relax it** —
that means a seventh kit exists, or a declaration regressed, and the gate has found something real
on its first run. Report that rather than widening the predicate to fit.

## The arm has to be seen failing

Stage a descriptor with a `rendered` row and no regenerate, observe the refusal naming that kit, then
unstage. A gate whose red you have never seen is an assertion about nothing, and that rule has
already caught a real inert fixture in this build: a unit staged a condition git did not actually
refuse and the arm would have graded an ordinary run.

Do not stage the break by editing a real kit's descriptor and leaving it — build the fixture.

## Bounds

Do not touch arm 7l's existing prose-grading half; this unit adds a population, it does not replace
one. Do not add a new leg — the meta-gate class says a check inside an existing gate is far cheaper,
and `selfcheck` is already on the bar.

## Standing bans, each tripped once here

Lead any new function with a declared verb from `.lexicon.conf` — the offender pin is a two-sided
equality and one bad name reds an unguarded leg. Spell no `tools/<kit>/…` path in shipped prose — the
carried-prefix arm is a BAN where a count may fall and never rise. Re-declare with `--dispatch`
before committing if your write set grows.
