# aNimbleMend — a red leg is fixed inline with its record written after, and every pass runs a budgeted list of fast legs

## The problem this build exists to solve

A red gate leg is seen only at the close's full bar, about two hours on a shared node, because a
unit pass runs no gate leg. Its fix then needs a spec first, about ninety minutes for a one-line
change. The dOrderedCharter close paid that three times: three bars and three fix units, each fix
turning a neighbouring leg red for the next bar to find. The owner wants two switches, on by
default in every repository: a red fixed inline with its record written afterwards, and a short
list of fast legs run after every pass. The prompt is recorded under `prompts/`.

## Expected improvements

- A red bar leg or pass leg is fixed with no spec, and a typed record follows it.
- Every other product write still needs its specced unit.
- Each pass runs the declared fast legs inside 600 s, 690 s at most. <!-- PINNED 2026-11-12 -->
- The list is derived from the gate ledger by a recorded rule, and a gate reds one over budget.
- Either switch off restores today's behaviour.

## Detriments if this is not built

- A one-line red fix keeps costing a spec writer, a builder and a records commit.
- A red a pass caused keeps surfacing one full bar later, and each fix can add another.
- A close keeps running several two-hour bars where one would do.

## Build-level rules

- **Classification (M2)**: twelve units at open, each MISSING, each Tier-2: every one writes a
  shipped kit file. The roster is provisional until the specs are written.
- **Stands alone, outside the chain.** A chain row is joined both ways with the design view, and
  this build is no row of that design. Its policy keys join the catalogue as dFoldedAudit's did,
  owned by this build. `verdict.red-route` stays dWitnessedBar's and is neither read nor changed.
- **Pass legs run at the main loop**, after the builder's commit. A role agent's pass stays
  gate-free, since the scratch guard's refusal there is what keeps a pass cheap.
- Order: 1 first. Then 2, 4, 3, 5, 6 and 7 for the pass legs, and 8, 9 and 10 for the lane. 11 and
  12 come last. Units 5 and 8 both read the pass-leg run record, so 8 follows 5.
- Key names are provisional until `/lexicon` and the policy kit's key grammar decide them.
- Kit versions move through the lander's `mint`, once, after the last unit.
- No spec audit: none is declared.

## Parked decisions

None.
