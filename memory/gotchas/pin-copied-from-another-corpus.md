# Every pin is a measurement of a specific corpus

## Symptom

A ported gate is either always green — its pin far above anything this tree will reach — or always
red, its pin below what this tree already holds. Both look like the gate working.

## The rule

Every PIN, FLOOR, CEILING and CUTOFF is MEASURED at adoption and written by the adopt script, never
inherited. `tools/memory-tree/corpus_ids.py --measure` prints them, `.memory-tree.conf` holds them,
and the build journal records what was measured — so the first raise is an argument against a
recorded figure rather than a guess.

A blank pin disables its check, which is the honest outcome when a measurement shows the whole
population is waived.

Gated by `tools/memory-tree/corpus_ids.py`, which reads each pin from the conf and compares it
against a fresh measurement on every run.
