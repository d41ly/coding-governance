# substitution-fed-loops.txt — the sites that PREDATE the `shell hygiene (a loop fed by a command
# substitution)` leg. TOOL-aLeakedHandle-1.
#
# A row is `<path> TAB <delimiter> TAB <count> TAB <reason>`. The key is the file and the REDIRECT
# DELIMITER — a heredoc tag, or the literal `<<<` for a here-string — and NEVER a line number. A
# line-keyed registry reds on an unrelated edit above the waived line, and a gate whose steady state
# is red gets bypassed; this repo has already paid two cycles for one. The count is how many sites
# in that file carry that delimiter, which is what makes `EOF` keyable in a file holding several.
#
# SET EQUALITY IN BOTH DIRECTIONS, and the counts too. A measured site with no row fails, a row the
# scan no longer finds fails, and a count that no longer matches fails. So draining a site FORCES
# its row out in the same commit instead of leaving a widened exemption behind, and the count can
# only fall with the sites.
#
# WHY THE ROWS BELOW ARE CARRIED RATHER THAN DRAINED — and the count is the rows, never a number
# written in this paragraph. The unit that wired this leg fixed the ONE
# site that had actually deadlocked — `pass_commit`, which held a merge-bar leg at zero CPU for 63
# minutes on 2026-09-10. The rest are the rows below, spread across two kits and the tool root, none
# of which has been observed to hang, and draining them is a bigger and riskier diff than the
# deadlock it closes. The drain is a backlog row against the tooling family; see the build's §8
# fork B. Nothing here says these are SAFE — only that they are known, counted, and cannot grow.
#
# THE POPULATION GREW ON 2026-09-18 BECAUSE THE PREDICATE DID, not because anybody wrote a new site.
# The leg used to read only a body holding a substitution DIRECTLY, and a body spelled `$var` where
# `var` was assigned from one on an earlier line was graded a near miss. A live instance sat in that
# blind spot for a whole run — the reader `pass_commit` calls once per commit, which stopped
# completing at all and took four attempts of its own driver with it. The predicate now follows ONE
# assignment, and the rows carrying the widening's reason are the sites it can now see. They were
# always there and they are counted now, which is the point. Every one was checked against the
# assignment it follows: all are file-level values assigned from a substitution and read by a loop
# below, and none was a name re-used across a scope boundary. NONE has been observed to hang; the one
# that did is repaired and holds no row, because a repaired site is an absence and not an exception.
# The drain is the same backlog row the paragraph above names, now larger and no more urgent.
