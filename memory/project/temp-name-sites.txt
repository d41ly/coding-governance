# temp-name-sites.txt — the sites the `shell hygiene (a fixed-name temp renamed into place)` leg carries.
# TOOL-dRedressedBar-24.
#
# A row is `<path> TAB <class> TAB <count> TAB <reason>`. The key is the file and the one CLASS,
# `fixed-temp`, and NEVER a line number, because a line-keyed registry reds on an unrelated edit above
# the site. The count is how many `mv` commands in that file rename a temp whose name anyone can know
# before the write creates it: a fixed name, or one suffixed with the writer's pid.
#
# SET EQUALITY IN BOTH DIRECTIONS, and the counts too: a measured path with no row fails, a row the
# scan no longer finds fails, and a count that no longer matches fails, so fixing a site forces its
# count down in the same commit. The leg grades the tracked product shell sources, less the suites and
# the memory tree, so a suite's scratch temps are not rows here.
#
# Every row predates the lint. A `health_log_sh` row is the trim of the one block four kits carry
# byte-identically under a parity table, with a Python twin; its fix is open ask TOOL-aPairedSlots-10,
# and it writes the git common dir, which a process confined to the temp dir cannot write. The leg
# prints every row's reason on every run, green included. No total is written here: the scanner
# derives them.
