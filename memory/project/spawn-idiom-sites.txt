# spawn-idiom-sites.txt — the sites the `shell hygiene (a fork spent on builtin work)` leg carries.
# TOOL-aSparedSpawn-8.
#
# A row is `<path> TAB <class> TAB <count> TAB <reason>`. The key is the file and the CLASS — one of
# `pure-fn-subst`, `printf-subst`, `cat-file`, `path-subst`, `date-fmt` or `var-pipe` — and NEVER a
# line number, because a line-keyed registry reds on an unrelated edit above the site. The count is
# how many sites of that class the file carries. The three BANNED classes, `epoch-date`, `cat-heredoc`
# and `redirected-read`, take no row: the scanner refuses one rather than honouring it.
#
# SET EQUALITY IN BOTH DIRECTIONS, and the counts too: a measured (path, class) with no row fails, a
# row the scan no longer finds fails, and a count that no longer matches fails, so converting a site
# forces its count down in the same commit. The suites are rows here as well: the registry classes
# count every tracked `*.test.sh`, so a suite site is carried rather than unseen.
#
# A `pure-fn-subst` row's reason names the callees it carries. A callee that keeps its substitution
# says why — a side effect the caller's shell must not take, or a gate that reads the spelling —
# and the rest are named as outside the reader set the landing unit converted. The leg prints every
# row's reason on every run, green included. No total is written here: the scanner derives them.
