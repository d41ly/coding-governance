# readme-contract.txt - which build READMEs the heading canon and the slot budgets BIND.
# TOOL-dFramedEntrypoint-3. Asserted in BOTH directions by `gen_build_index.py --check-format`:
#   FORWARD  a tracked memory/builds/*/README.md named by no row at all is a REFUSAL, so a new build
#            cannot silently escape the contract.
#   REVERSE  a row naming a path that is not a tracked build README is a REFUSAL, so a stale row
#            cannot silently widen the surface it was written to narrow.
#
# TWO ROW KINDS. A bare path is BOUND. A path prefixed `!` is EXEMPT and carries its reason on the
# same line after ` - `, because an exemption whose reason lives elsewhere is one nobody can drain.
#
# THE PIN IS AN EQUALITY, not a ceiling. `exempt-pin: <n>` must equal the measured exempt count, in
# BOTH directions: a pin left above the count after a drain is permanent slack, which is how a
# shrink-only list stops shrinking without anyone noticing. This repo's own drift audit reports three
# of five such lists out of tolerance today, which is the evidence for making this one an equality.
#
# THIS FILE IS NOT curation-debt.txt. A row here declares which rule BINDS a file. It silences
# nothing: every other check grades every build README exactly as before.
#
# TERMINAL BUILDS ARE PERMANENTLY EXEMPT, and the reason is recorded once here rather than on each of
# their rows. Their two judgement slots - the expected improvements and the detriments of not
# building - cannot be honestly authored after the build closed, and authoring them anyway is the
# same fault the review-verdict cutoff in this tree was set forward-only to avoid.
#
# SEEDED at TOOL-dFramedEntrypoint-3 with every tracked build README EXEMPT and none bound. That is
# the honest starting state: the contract binds nothing on the day it lands and the leg SAYS so on
# every run. TOOL-dFramedEntrypoint-7 converts rows to bound, one build at a time, and lowers the pin
# in the same commit as the file it describes.
