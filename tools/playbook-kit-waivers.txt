# playbook-kit-waivers.txt — kit dirs under tools/ that are deliberately NOT named in the three
# shipped charter template, with the reason each is exempt.
#
# GRAMMAR: one bare kit directory name per row, exactly as the derivation yields it — no trailing
# slash, no path prefix — then whitespace, then the reason. The consuming gate compares VERBATIM,
# so a key spelled any other way joins nothing and leaves its kit unexcused.
#
# This is a DECLARED EXEMPTION LIST, not a shrink-only count: it must be able to gain a row for a
# genuinely experimental kit, because a kit missing from the playbook REDS. It drains through the
# gate's two arms instead — a row whose kit is gone reds as stale, and a row whose kit IS named in
# the playbook reds as excusing nothing. That is the one deliberate divergence from
# the install-prefix gate's old waiver registry, which was shrink-only and could only lose rows.
