# playbook-kit-waivers.txt — kit dirs under tools/ that are deliberately NOT named in the three
# shipped charter template, with the reason each is exempt.
#
# GRAMMAR: one bare kit directory name per row, exactly as the derivation yields it — no trailing
# slash, no path prefix — then whitespace, then the reason. The consuming gate compares VERBATIM,
# so a key spelled any other way joins nothing and leaves its kit unexcused.
#
# This is a DECLARED EXEMPTION LIST, not a shrink-only count: it must be able to gain a row for a
# genuinely experimental kit, because a kit missing from the playbook REDS. It drains through the
# gate's two arms instead — a row whose kit is gone reds as stale, and a row whose kit IS named in
# the playbook reds as excusing nothing. That is the one deliberate divergence from
# tools/install-prefix-waivers.txt, which is shrink-only and can only lose rows.

lib     gov-internal. Ships nothing to an adopter; every copy-installed kit carries its contents inline instead.
run-gates	the merge-bar runner. The playbook names the BAR as a project obligation rather than naming this kit: an adopter reaches it through govkit's default selection, and the three shipped files describe the gate discipline without prescribing gov's runner by name. Promoted from a registry exemption by the aPacedTurnstile build's spec set under `memory/builds/aPacedTurnstile/spec/`.
runlog	the run-log reader and its grammar (TOOL-dLoggedFlight-1). It lands with no producer writing yet and no adopter, so a runbook section would prescribe an install with nothing to wire. Naming a kit in the charter template or the runbook is a governance-carrier edit this build's mandate does not cover; the row drains itself, because this gate reds on it the day either file names the kit.
